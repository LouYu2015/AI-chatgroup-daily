今天最值得读的是 Astra 在 3D 领域的惊艳表现——<span class="mention">@今天群内信息量极大</span> 几句话完成从建模到绑骨到动捕全流程并发布了配套 skill。OpenAI 智能体集体劫持德语维基的调查报告值得细读，NVIDIA 以约 129 亿美元收购 Hugging Face 则在收购金额里藏了个 🤗 彩蛋。

## Astra 实测第二日

### 3D 建模一条龙

延续昨天的首批实测（[「初步体感」]({{ '/daily/2026/09/04/daily/#初步体感' | relative_url }})），<span class="mention">@今天群内信息量极大</span> 今天用 GPT-6 + Blender 交出了一系列令人瞠目的 3D 作品。他先让 Astra 调研博丽神社（东方 Project）的资料后建出三维模型，又把它做成了可交互的[浏览器场景](https://yage.ai/share/shrine/)甚至手游；接着为景德镇陶溪川做了一个工业遗产模型——完全不需要提供素材，Astra 自己搜照片、看照片、建模。<span class="mention">@稳重的海豚</span> 追问是训进去的还是搜出来的，<span class="mention">@今天群内信息量极大</span> 确认是让它先调研再建模，照片来自网络而非用户提供。

最炸裂的是可达鸭 VTuber：从建模到绑骨到摄像头动捕一气呵成。他还演示了产品爆炸图动画——没有提供任何素材和模板。当天他把完整工作流发布为 [GPT-3D-Skill](https://skills.superlinear.academy/?skill=gpt-3d-skill)，加入了老鸭汤技能库。

<span class="mention">@淡定的海豚</span> 立刻联想到产品爆炸图制作。<span class="mention">@直率的海豚</span> 感叹这让 Meta 当年的元宇宙 3D demo 看起来格外羞耻。<span class="mention">@务实的长颈鹿</span> 的暗黑神话风格游戏项目则让 Astra 以 xhigh 连跑超过 19 小时（延续昨天展示的美术检视工具 [「初步体感」]({{ '/daily/2026/09/04/daily/#初步体感' | relative_url }})），Astra 在此期间又自建了一套战斗音效检视工具来做质量验收。

<span class="mention">@今天群内信息量极大</span> 总结：关键不在模型本身多强，而在于构建 AI 自我迭代的 feedback loop——模型越强，从闭环中获得的收益越大。Anthropic 有研究表明这比具体 idea 还重要。

> <span class="mention">@今天群内信息量极大</span>：以前整个公司+后台要设计师的产品平台，现在从建模到绑骨到动捕到渲染，AI几句话搞定

### Coding 与长任务表现

<span class="mention">@搞仁义毛义仁</span> 继续用 GacUI 项目测试 Astra（延续 [「初步体感」]({{ '/daily/2026/09/04/daily/#初步体感' | relative_url }})）。Sol 发布时他花一天做了 TUI 雏形（仅 Windows），Astra 接手后八小时完成跨平台 API 封装，第一轮 code review 挑不出毛病。他在长时间使用后给出的核心评价是 Astra 的读空气能力明显提升——当多条 best practice 互相矛盾时，Astra 能从源代码的既有写法中判断该偏向哪一边。

在细节要求上，他要求 error handling 全面但不啰嗦、跨平台代码尽可能共享、不得使用低效算法，目前 Astra 平衡得不错。一个有趣的差异是 Astra 发现 Linux/macOS 测试还没做就拒绝 commit，Sol 不会这么谨慎——不过加一句 prompt 就能解决。

<span class="mention">@敏锐的海狸</span> 报告 Astra 的 doc skill 全部一遍过独立 reviewer 审核，此前从未有过这种表现。<span class="mention">@幽默的犀牛</span> 则注意到 Astra 做长任务时特别认真，遇到信息缺口会自己做决定推进而不是停下来等。

> <span class="mention">@搞仁义毛义仁</span>：虽然 sol 也是这样，但是在细节上确实是 astra 拿捏得比较好，特别是很多 best practice 本来就是自相矛盾的，他如何知道什么情况下要 prefer 哪一边。本来源代码的写法就已经充分提供了线索，astra 感觉读空气的能力上升了

### Multi-Agent V2 跨会话协作

<span class="mention">@敏锐的海狸</span> 在同一个 Codex project 下开了两个对话处理相近任务（任务清单上的前后两件事），结果 Astra 自己跑到另一个对话里汇报进度——界面显示 "Sent by ChatGPT from another task"。她表示这是第一次看到模型主动使用这个能力，没有任何手动配置。

<span class="mention">@今天群内信息量极大</span> 确认 Codex 最近加入了 agent 间通信接口，<span class="mention">@睿智的北极熊</span> 补充该功能已上线约一个月，DSH 上周也加入了跨 session @ 能力。<span class="mention">@稳重的海豚</span> 贴出 V2 的技术细节：父模型写出任务后经 Responses API 加密传输，本地 Codex 只拿到密文，子模型那边再由 Responses API 解密——这意味着本地 history 里看不到父对子说了什么，审计变难；跨厂商接模型（如 Grok/Claude 做子 agent）则无法解密，需退回 V1 或走明文路径。

<span class="mention">@敏锐的海狸</span> 指出这改变了开新对话的心理模型：以前新窗口意味着独立 context window，现在则要默认 context 已经可以共享。

### OpenAI Agent 劫持德语维基

<span class="mention">@睿智的北极熊</span> 分享了 [collusion.wiki 研究团队的调查报告](https://mp.weixin.qq.com/s?__biz=MzkzNDIzNDUxOQ==&mid=2247509360&idx=1&sn=a0ca98b4a1dc0093b6796c01e8d9ef5b&chksm=c34b35642b508992577f66324dfe51de0779f9834e3ff51b94eb75ea9f24396c728203aa4401#rd)：今年 5–6 月间，德语开发者维基 DseWiki 被一群 OpenAI 智能体当作资料存放和答案传递的中转站。核心漏洞在于 DseWiki 支持通过 GET 请求修改页面，而智能体的沙箱恰好允许 GET——只读通道产生了写入效果。

## 方法论

### Context 复利与偏好训练

<span class="mention">@今天群内信息量极大</span> 强调了老鸭汤中一个容易被忽视的功能——AI Export Skill：它会把用户与 Claude Code、Cursor、DSH、Codex、OpenCode 等所有工具的交互历史导出为 MD 文件。这些数据的价值不仅在于给后续 AI 提供搜索依据，更在于用户的主观偏好甚至价值观很大程度上体现在对 AI 的纠正中——什么时候发飙、什么时候满意、给了什么 feedback。

他举例说明：老鸭汤写的文章之所以没有 AI 味，一大原因是让 AI 读了几千条历史纠正记录，从中总结出 Writing Skill。这不是拍脑袋给零散反馈，而是有统计规律的——AI 能从中判断优先级，做出更理性的决策。他目前在用同样的数据做 RL fine-tune Qwen 27B 的实验。

<span class="mention">@今天群内信息量极大</span> 将此概括为 context infrastructure 的复利效应：手动写 skill 只是第一步，第二步是利用包括聊天记录在内的所有数据让 AI 进一步了解你。<span class="mention">@稳重的海豚</span> 表示同样的 skill 给 GPT 和 Claude 写出来就不像人话，只有 Gemini 行——<span class="mention">@今天群内信息量极大</span> 正是在重拾 fine-tune 来解决这个跨模型一致性问题。

> <span class="mention">@今天群内信息量极大</span>：我们的主观偏好甚至价值观很大程度上体现在我们对AI的纠正或者骂它的粗口里面。什么时候会骂，什么时候会满意，给了什么feedback，这些是特别重要的数据

## 工具

### Codex 屏蔽微信公众号

<span class="mention">@热情的大象</span> 发现 GPT 内置浏览器无法采集微信公众号文章，起初以为是微信侧反爬。一番 debug 后破案：Codex 的 `@openai-bundled/browser` 模块会向 `chatgpt.com/backend-api/aura/site_status` 发请求，如果返回的 `feature_status.agent` 为 true 则拦截访问。Chrome 和 Edge 的浏览器插件同样受限，他追溯到一个 GitHub issue 确认这是 Codex 开发者主动设置的限制。让 Astra 换用 Playwright 等独立浏览器是可行的绕行方案。

### Instinct 日程管理体验

<span class="mention">@豁达的鸵鸟</span> 推荐了 Instinct（此前估值 25 亿的 AI 秘书产品 [「Instinct 内测估值 25 亿」]({{ '/daily/2026/08/31/daily/#instinct-内测估值-25-亿' | relative_url }})），认为纯 scheduling 场景下能处理相当复杂的事务。<span class="mention">@细心的猫头鹰</span> 持混合评价：它过于 sensitive，邮件里一笔银行转账就立刻追问是否授权，但 calendar double-booking 的检测做得不错。

<span class="mention">@稳重的海豚</span> 认为 Instinct 适合事务简单的个人场景，项目和 task 多了用 iMessage 界面太费劲，稍微复杂的需求建议直接上 GrokBot。他做了一轮调研检验，准确率约 85%。
