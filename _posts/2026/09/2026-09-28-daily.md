Anthropic 一天内放三张牌——Sonnet 5.5 在综合基准上反超 GPT-6 Astra、IPO 招股书同日曝光、Fable 5.1 攻克九圈振幅——三条串起来才能判断 Claude 产品线的竞争位势与定价走向。双 5090 跑 Qwen3.8-27B 的吞吐数据让人心动，但 NVFP4 KV 质量坑被两位群友独立踩中，想照搬配置的先看踩坑段落。

## 行业新闻

### Sonnet 5.5 发布

早上 <span class="mention">@优雅的喜鹊</span> 贴出一张泄露截图：Sonnet 5.5 将于次日纽约时间下午发布，标识符 `claude-sonnet-5-5` 已被发现，预期能力「远超 Opus 5.5」且比它便宜得多。他自己都将信将疑——「Sonnet 5.5 怎么可能比 Opus 5.5 还厉害？」<span class="mention">@直率的鹦鹉</span> 更不客气：「假酒喝多了。」

几小时后 <span class="mention">@天真的浣熊</span> 贴出 Anthropic 官方推文和基准卡片——Sonnet 5.5 真的来了。泄露部分属实，但「远超 Opus 5.5」是夸大其词。官方定位为 Opus 5.5 的「更快、更低成本的互补品」，同价但通常用更少 token 完成同样任务，输出速度快 30% 以上。官方基准对比：

| 基准 | Sonnet 5.5 | Sonnet 5 | Opus 5.5 | GPT-6 Sol |
|---|---|---|---|---|
| Terminal-Bench 4.0 | 70.6% | 10.3% | 66.4% | — |
| FrontierCode 1.1 (Max / Xhigh) | 46.2% / 52.1% | 42.4% | 54.4% | 49.3% |
| CursorBench 4.0 | 55.5% | 34.1% | 57.8% | — |
| GDPval-AA v2.1 | 1844 | 1449 | 1846 | 1487 |
| AA-Briefcase v1.1 | 1811 | 1359 | 1822 | 1483 |
| HLE (with tools) | 64.5% | 54.9% | 67.7% | — |

| Chartography (no tools) | 61.6% | 15.6% | 64.4% | 53.6% |

Terminal-Bench 上 Sonnet 5.5 甚至超过了 Opus 5.5（70.6% vs 66.4%），Anthropic 备注 Opus 的该项得分取自 xhigh effort。FrontierCode 则出现有趣现象：Sonnet 5.5 在 Max effort 下反而不如 Xhigh，原因是 Max 更频繁触发 code review skill、拆分 subagent 后超 scope 被扣分。另据官方推文，Haiku 5.5 预计几周内上线。

第三方 Artificial Analysis Intelligence Index v4.3.2 的综合排名更值得关注：

| Claude Fable 5.1 (max, fallback) | 53 |

一个二档模型在综合评分上越过了对家旗舰。<span class="mention">@活泼的树懒</span> 直呼「GPT 的天塌了」，<span class="mention">@沉稳的兔子</span> 纠正说严格来看只是「比 Sol 强」，<span class="mention">@活泼的树懒</span> 回以第三方指数为据——测评机构说确实比 Astra 强。<span class="mention">@灵动的喜鹊</span> 点出时机：「马上 IPO 快到了，必须冲刺。」

### Anthropic 提交 IPO

<span class="mention">@活泼的树懒</span> 下午率先通报 Anthropic 已提交 IPO 申请，财联社以「史上最大 IPO」为题报道。招股书关键数据：

| 指标 | 数值 |
|---|---|
| FY2025 营收 | $4.59B（+1,088% YoY） |
| GAAP 净亏损 | $41.97B |
| 营业亏损（扣除非现金项） | ~$8B |
| 算力支出 | $7.3B（占 OpEx 58%） |
| 现金 | $20.3B |

$41.97B 的 GAAP 净亏损主要源于此前融资相关的负债减值等非现金因素。更值得关注的是算力支出曲线：FY2023 仅 $0.4B，FY2024 升至 $2.5B，FY2025 冲到 $7.3B——两年翻了 18 倍。近四分之一营收来自两家大客户，且许多最大客户并未签署长期合同，招股书将此列为风险因素。

<span class="mention">@活泼的羊驼</span> 琢磨：云计算费用似乎没那么高，推理毛利可能在 80% 以上。<span class="mention">@细心的熊猫</span> 则从用户角度担忧——$20 的 Opus 5.5 套餐自己都蹬不完，「感觉 IPO 以后就得降质或者降 quota」。前两天 <span class="mention">@今天群内信息量极大</span> 拆解过 AI 成本的多层账本（[「智能越便宜，账单越贵」]({{ '/daily/2026/09/26/daily/#智能越便宜账单越贵' | relative_url }})），算力支出占 OpEx 58% 的数字为那篇分析补上了一手来源。

### Claude 攻克九圈振幅

<span class="mention">@稳重的海豚</span> 凌晨分享了 Anthropic 官方博客 [Yes, Claude Can Do Nine Loops](https://www.anthropic.com/research/yes-claude-can-do-nine-loops)：两位 Anthropic 物理学家用 Fable 5.1 算出了平面 N=4 超杨-米尔斯理论中的九圈六粒子 MHV 振幅，结果由 SLAC 教授 Lance Dixon 独立验证。

提示词只有一句话外加「我要睡了，继续做直到我让你停」。Claude 用 bootstrap 和 form-factor 两条路径各算了一遍，端到端成本约 $1,000–2,000。Dixon 花两周验证后评价：Claude 对他们 2019 和 2023 年论文的理解「超过除我合作者之外的任何人类」。中科院研究组也用 GPT-6 辅助计算出了 symbol 部分，Dixon 在两周内被「纯机器」和「人加机器」各抢先一次。

<span class="mention">@今天群内信息量极大</span> 转述邻群物理同行的评价——「个体力活」。<span class="mention">@搞仁义毛义仁</span> 补充了 Astra 的同款判断：计算量大到人类在多个优化方案间举棋不定，AI 直接暴力穷举。<span class="mention">@稳重的海豚</span> 用 D&D 术语收尾：「9 环法术 wish」——九圈已是最高等级。

## 工具

### 双 5090 跑 Qwen3.8-27B

<span class="mention">@优雅的喜鹊</span> 分享了 GitHub 用户 adrienbrault 的[双 5090 实测项目](https://github.com/adrienbrault/qwen3.8-27b-rtx5090)，硬件为双 RTX 5090（32GB）+ Ryzen 9 9950X + 190GB RAM，模型 Qwen3.8-27B NVFP4，引擎 vLLM v0.29.0rc2 加 58 个补丁和 FlashInfer 0.6.16。Decode 性能（token/s，总计 / 每路）：

| 并发 | 数数 | 结构化 JSON | 代码 | 散文 |
|---|---|---|---|---|
| 1 | 310.5 | 297.3 | 279.6 | 192.6 |
| 4 | 1,208 / 304 | 1,155 / 290 | 1,120 / 281 | 741 / 189 |
| 8 | 2,145 / 268 | 2,031 / 258 | 1,906 / 245 | 1,320 / 169 |
| 16 | 3,385 / 215 | 3,259 / 206 | 3,218 / 206 | 2,141 / 139 |

冷 prefill 在 6.7K 输入时约 7,400 t/s，167K 时仍有 4,697 t/s。峰值功耗每卡约 406W，最高温度 78°C。<span class="mention">@优雅的喜鹊</span> 补充：双卡方案单请求比单卡 ninfer 快 30–40%，多请求吞吐约为两个独立 ninfer 实例的两倍，长输入越长优势越大。32 并发甚至能冲到 4,000 tok/s，但上下文太短「没什么意义」。

但 NVFP4 KV cache 的精度陷阱被两位群友独立踩中。<span class="mention">@细心的熊猫</span> 启用 NVFP4 KV 后输出「直接崩坏」。<span class="mention">@今天群内信息量极大</span> 让 AI 诊断后发现：需要打 QuixiAI 开源 P2P 内核模块补丁、驱动要够新、还要开 Resizable BAR——缺任一项就会 fallback 到 mailbox 模式，输出损坏且从任务质量上难以察觉。有了上次重装系统的教训，他选择暂时不折腾。

<span class="mention">@细心的熊猫</span> 随后拿自己的 DFlash2 方案做了对比实测，结论是 DFlash2 单流 decode 仍然领先 21–33%，vLLM + MTP 在高并发场景有优势但单流不敌。他还给出了硬件选型参考：一张 5090（约 ¥2.3 万）免换平台、免四卡电散热，单流翻倍且 32GB 装得下 27B NVFP4 + 131K 池，缺点是没法横向扩展。

## 方法论

### 2026 霸权模型编年

<span class="mention">@优雅的喜鹊</span> 统计了 2026 年至今的「体感霸权模型」在位时长：

| 时段 | 模型 | 天数 |
|---|---|---|
| 01/01–02/06 | GPT-5.2 | 36 |
| 02/06–03/05 | Opus 4.6 | 27 |
| 03/05–04/23 | GPT-5.4 | 49 |
| 04/23–06/09 | GPT-5.5 | 47 |
| 06/09–09/03 | Fable 5, 5.1 | 86 |
| 09/03–09/22 | GPT-6 Astra | 19 |
| 09/22–至今 | Opus 5.5 | 6+ |

OpenAI 合计 151 天，Anthropic 119 天，表面近乎五五开，但节奏差异显著：Fable 系列独占 86 天是最长统治，Astra 仅撑了 19 天就被拉下马。<span class="mention">@沉稳的仓鼠</span> 概括为「各领风骚一两周」。

<span class="mention">@今天群内信息量极大</span> 第一反应：「Google：？」<span class="mention">@幽默的火烈鸟</span> 秒接：「我已经一分钟没听到 Gemini 4 Pro 即将斩 O 灭 A 强势回归的故事了。」Google 全系产品在昨天的社区 Tier List 中已被归入底部自成一派（[「Opus 5.5 社区定调」]({{ '/daily/2026/09/27/daily/#opus-55-社区定调' | relative_url }})）。<span class="mention">@热情的狮子</span> 觉得 GPT-5.4 和 GPT-5.5「都挺拉的」，<span class="mention">@豁达的灰熊</span> 则表示体感上 Opus 4.6 统治时间更久，而 Fable 虽强但「太慢且容易 flag」。这份编年恰好在 Sonnet 5.5 发布当天发出——后者在综合指数上已越过 Astra，模型王座的更迭只会更快。

### Opus 5.5 实战分工

多位群友近日反映 Astra 降智，<span class="mention">@淡定的雪豹</span> 称个人号「被降麻了」，<span class="mention">@飘逸的大象</span> 附议。<span class="mention">@稳重的海豚</span> 开出四字处方：「用 Opus 5.5。」<span class="mention">@豁达的考拉</span> 补充了另一条路——通过 Copilot 转发走 API 调用 Astra，没感觉变笨。

切到 Opus 5.5 后，effort 分工的经验正在成形。<span class="mention">@稳重的海豚</span> 的做法是 max 做设计、medium 干活，他做 UI overhaul 两天干出 24B token，自己都惊了，不过确实比以前耐用多了。<span class="mention">@80-HD</span> 用 medium 日常干活，浏览器操作仍觉得 Astra（Codex）更好使，但 triage incident 时 Opus 的主观能动性强出一截：

> <span class="mention">@80-HD</span>：我拿来 triage incident 感觉主观能动性强了很多，会自己找到一些我都不知道的 metrics

视频制作方面，<span class="mention">@沉稳的仓鼠</span> 跑通了一套 API 自选方案：把多个生成 API 都扔给 Opus，由它自行决定用哪个；图片和视频优先走 Grok CLI——订阅制「量大管饱」。他测试 Opus 5.5 生成的视频只需微小调整即可交付。

### 陶德的忠言逆耳

昨晚 <span class="mention">@活泼的羊驼</span> 贴出一张小红书截图：一条「历史上的今天」写着「你可能需要升级你的电脑 ——陶德 2023.9.7」，下方群友齐刷「唉 忠言逆耳」。<span class="mention">@搞仁义毛义仁</span> 一脸困惑：「陶德是谁？」<span class="mention">@直率的海豚</span> 科普：老滚公司的制作人。
