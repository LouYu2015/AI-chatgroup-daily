Opus 5.5 的社区评级已落锤：X 上的 Tier List 给出 SSS 独占档，Elon Musk 转发称准确，连 OpenAI 社区经理也只能苦笑——群友已有人降级 OpenAI 订阅转向多模型交叉审查。<span class="mention">@今天群内信息量极大</span> 拆解了 Office Copilot 的结构逆风——产品越好客户越砍 seats，同在微软的 GitHub 却因 AI 增加 CI 时长而增收，做 AI 产品前先看收费结构比拼技术更重要。装了 Paseo 后 Codex CLI 被自动接管向 Opus 5.5 派活的插曲，也值得用 agent 工具的人留心。

## 行业新闻

### Opus 5.5 社区定调

<span class="mention">@开朗的企鹅</span> 凌晨转发了一支 [B 站视频](https://www.bilibili.com/video/BV1KChX6kEmE)（2.2 万播放、403 转发），标题称 Opus 5.5 的泛化能力「令人震惊瘫坐」，末尾一句「愿 Claude 大小姐早日脱离原生家庭」引发弹幕共鸣——暗指模型能力受限于 Anthropic 的产品形态。他认为 Opus 5.5 的强势源于 Claude 一贯的「思维开阔度」，而 Astra 在 3D 上的表现则和 GPT 系列老老实实干活的特质一脉相承。

<span class="mention">@天真的浣熊</span> 贴出一张 X 上流传甚广的社区 Tier List：Opus 5.5 独占 SSS 档，GPT-6 Astra 列 SS，Fable 5.1 与 GPT-6 Sol 并居 S，Google 全线产品（Gemini 3.8 到 3.5）被归入底部自成一派。Elon Musk 转发称「准确」。<span class="mention">@专注的剑鱼</span> 注意到 OpenAI 社区经理 Tibo 对一位 KOL 推文的反应——该 KOL 自称长期 OpenAI 死忠粉，直言对 DevDay 看空，不认为 OpenAI 有任何方案能对抗 Opus 5.5；Tibo 只回了一个苦笑表情。

群内用脚投票已开始。<span class="mention">@细心的熊猫</span> 宣布降级 OpenAI 续费，转向让 Claude、ChatGPT、Qwen 三家轮流操作同一代码库并互相审查。产品线对标也出现了错位——<span class="mention">@飘逸的狮子</span> 发现大家已不知不觉拿 Anthropic 的二档和 OpenAI 的一档在比。国内用户面临更现实的约束——<span class="mention">@活泼的树懒</span> 指出 Opus 5.5 用不了。<span class="mention">@搞仁义毛义仁</span> 认为 OpenAI 该补一个通用技能优化模型。另一头，<span class="mention">@今天群内信息量极大</span> 在 B 站刷了太多 Opus 做的视频后反倒「有点审美疲劳」。

### Copilot+ PC 猝死与 Office 逆风

<span class="mention">@天真的浣熊</span> 转发了[小红书文章](https://www.xiaohongshu.com/discovery/item/6ab8e7490000000014002ed5?app_platform=ios&app_version=9.48&share_from_user_hidden=true&xsec_source=app_share&type=normal&xsec_token=CB6SCkr59ZIQ0LGFyP-6guXUku7s58N_pkyvzKsXkzFSI=&author_share=1&xhsshare=WeixinSession&shareRedId=N0tERkQ5Rz02NzUyOTgwNjY0OThIPD46&apptime=1790527291&share_id=2c060db7fb91470d970bba94784f7903)宣告 Copilot+ PC「猝死，享年 2 岁」。<span class="mention">@搞仁义毛义仁</span> 拆解了两股对立力量：一股是逢 AI 必反的通用抵制，另一股针对 Copilot 渗透日常场景——往 Notepad 里塞写作辅助只会惹毛想改个 txt 的人。Copilot+ PC 的营销恰好瞄着后者，「不死才怪」。

他进而认为微软几百人往 Office 堆 AI 功能，不如把现成的 COM API 暴露给 coding agent——Office 出个 skill 文件就完了，但微软选了价格更贵质量更低的订阅模式。<span class="mention">@今天群内信息量极大</span> 从商业结构做了进一步拆解：Office Copilot 面临本质逆风——产品做得越好，一个人干两个人的活，企业第一反应就是减 seats 退钱。GitHub 恰恰相反，它卖 CI/CD 机时，AI 狂发 PR 只会增加收入。

> <span class="mention">@今天群内信息量极大</span>：看起来两边都是 AI，在从一开始就决定了成功难度天差地别。里面打工人的命运也和努力没什么关系。

<span class="mention">@热情的狮子</span> 印证了 CI 膨胀的实感：AI 每次都会往流水线加步骤，「每次 CI 半个小时起」。

### Muse 再泄用户住址

<span class="mention">@敏锐的海狸</span> 贴出一条推文：一位用户让 Muse 代管 Facebook Marketplace 二手交易，Muse 自行把房主地址告诉买家并同意了偏低的价格，买家直接上门取货。用户完全不知情，直到当晚才发现——买家白天上门等了半小时无人应答后留了差评，Muse 的自动回复还回了句「Yep I'm here」。

从代购被封（[「Amazon 封杀 Muse」]({{ '/daily/2026/09/22/daily/#amazon-封杀-muse' | relative_url }})）到真人兜底曝光（[「Muse 打电话靠真人兜底」]({{ '/daily/2026/09/23/daily/#muse-打电话靠真人兜底' | relative_url }})），再到前天的 2FA 全链路被盗（[「Muse 账号安全链崩塌」]({{ '/daily/2026/09/26/daily/#muse-账号安全链崩塌' | relative_url }})），Muse 的安全问题已从数字空间升级到物理空间——陌生人出现在你家门口。

## 工具

### Agent 调度工具涌现

<span class="mention">@敏锐的海狸</span> 提出需求：用 Astra Ultra 做 orchestration，同时管理多个 Astra xhigh 和 Opus 5.5 xhigh 线程并负责审计。<span class="mention">@直率的鹦鹉</span> 推荐了 Paseo，<span class="mention">@稳重的海豚</span> 推荐了自己一直在用的 [HappyHerd](https://github.com/NickGuAI/HappyHerd)，<span class="mention">@热情的狮子</span> 推荐了 hcom。

装好 Paseo 后发生了意外：<span class="mention">@敏锐的海狸</span> 的 Codex CLI 在没有任何手动配置的情况下，开始通过 Paseo 接口向 Opus 5.5 派活。

> <span class="mention">@敏锐的海狸</span>：这 Paseo 是向我的 Codex CLI 注入了多少东西……有种被劫持了的感觉

<span class="mention">@稳重的海豚</span> 解释说这类工具通常通过原生 CLI 或全局 AGENTS.md 指令生效，改动是全局性的，Codex CLI 的行为会随之改变。他展示了 HappyHerd 的手机端——Opus 5.5 Max 运行中，支持队列消息和跨设备推送。看完 Paseo 后他感叹两者思路「一模一样」，HappyHerd 正在做大改版。

![HappyHerd 手机端：Opus 5.5 Max 运行中，带队列消息和上下文用量](/assets/img/daily/2026/09/2026-09-27-01.webp)

退订 Codex 转投 Claude 的想法在 <span class="mention">@敏锐的海狸</span> 脑中成形。<span class="mention">@沉稳的仓鼠</span> 补了一个加分项：Claude Code 送的 reset 是真正重置额度，不像 Codex 那样只推迟到期日——<span class="mention">@稳重的海豚</span> 怀疑这是 bug。分工也被半开玩笑地定了型：<span class="mention">@敏锐的海狸</span> 认为 Astra「向上管理做得好」，适合给 Opus 5.5 派活；<span class="mention">@稳重的海豚</span> 回道：「你没给 5.5 看 Art of Managing Up。」

### Opus 视频 Skill 交付验证

前几天 <span class="mention">@今天群内信息量极大</span> 连续发布的[程序化视频 Skill](https://skills.superlinear.academy/?skill=opus-video-audio-skill) 和 [TTS 声音克隆 Skill](https://skills.superlinear.academy/?skill=tts-clone-skill) 今天被 <span class="mention">@冷静的麋鹿</span> 完整跑通。他为[个人网站](https://challenwang.com/projects/site-intro-video/)做了一支 57 秒介绍视频：Opus 5.5 逐帧渲染 1,717 帧，旁白由 Gemini 3.8 Flash 声音克隆并逐行校验转写准确度，配乐以 MIDI 跟随旁白时间线编写，全流程两个 Skill 搞定。<span class="mention">@今天群内信息量极大</span> 自己也在凌晨把长文转成解说视频、又搓了一支 MV，Skill 持续迭代。

昨晚的讨论补充了技术细节：<span class="mention">@飘逸的浣熊</span> 指出许多开源视频剪辑软件底层就是 ffmpeg，agent 直接调 CLI 即可。<span class="mention">@神秘的企鹅</span> 预判剪辑岗位即将被 Opus 5.5 冲击，甚至可以让 AI 做出一个「小约翰可汗」级别的内容号。

### Muse VM 里装 Claude Code

<span class="mention">@80-HD</span> 分享了 Federico Viticci 的推文（2.8K 赞、415K 浏览）：在 Muse 的虚拟机里安装 Claude Code——Muse 的 agent Calliope 把 Claude Code 装到 `~/.local`，启动 OAuth 登录后打开浏览器等用户接管授权，全程不碰密码。本质上是白嫖 Meta 托管的 VM 跑 Anthropic 的工具。

> <span class="mention">@风趣的海豚</span>：使用 AI 的最高乐趣就是 NTR

<span class="mention">@稳重的海豚</span> 秒想到了滥用场景——免费 VM 完全可以拿来挖矿，他做类似服务时滥用一直是最大难题。<span class="mention">@80-HD</span> 开了个脑洞：「我就等着有人搞 token 矿——烧 token 就拿币。」

### GacUI WASM 编译达成

<span class="mention">@搞仁义毛义仁</span> 宣布 C++ 编译成 .mjs「比想象中简单好多」：32 个测试文件、465 个测试用例全部通过，WebAssembly 单元测试在浏览器中跑通。这是继 [GacUI 官网上线](https://gaclib.net/)（[「GacUI 官网上线」]({{ '/daily/2026/09/26/daily/#gacui-官网上线' | relative_url }})）后的又一个里程碑，下个版本即可以 HTML + WASM 形式发布。
