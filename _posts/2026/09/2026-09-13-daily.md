Anthropic 实锤蒸馏才三天，阿里就在招聘网站挂出了「情报工程师」岗位——JD 写着突破注册风控和设备指纹，读一遍比看任何评论都有画面感。实操层面最值得立刻试的是 <span class="mention">@搞仁义毛义仁</span> 对 Astra session 衰减的体感：超过三四轮后智力明显下降，首请求放任务、后续只问不做、做完弃 session。<span class="mention">@坚定的貂</span> 则把工具讨论推到终局——模型够强只需 bash，对判断哪些 harness 投资还值得做有启发。

## 方法论

### Astra 三四轮后走偏

凌晨 <span class="mention">@敏锐的海狸</span> 贴出一段 Codex 对话：用户说「删掉所有过程文件，你太慢了我直接手做了」，Astra 花了 1 分 22 秒清理后回了一句「这次绕路太多，耽误你了」。他感慨这口气「恍若一个出租车司机，好接地气」。

<span class="mention">@搞仁义毛义仁</span> 随后给出了更系统的判断：Astra 三四轮交互后智力就会快速下降。他的策略是第一个 request 放完整任务，后面只问确认性问题，没问题就直接弃 session。<span class="mention">@直率的鸵鸟</span> 认同换 session 不是大问题，但核心矛盾是「20x 不够用了」。

额度焦虑今天集中爆发。<span class="mention">@沉稳的兔子</span> 吐槽 Astra「完全用不了一点，一周的我基本上两个小时就用完了，出活也比 Sol 少一些」，GPT-6 over design 的毛病也一点没少。多位群友证实常规任务 Astra 没优势，替代路径各异：<span class="mention">@务实的灰熊</span> 用 DS 跑日常，「还挺爽」；<span class="mention">@神秘的企鹅</span> 混搭一个 20x 加 GLM 5.3 或 DS V4.1，20x 不够时 DSH 补位。

> <span class="mention">@沉稳的兔子</span>：Astra 完全用不了一点，一周的我基本上两个小时就用完了，出活也比 sol 少一些

<span class="mention">@活泼的树懒</span> 透露 50x 订阅有望推出，传闻 $300，也有人猜测实际要 $400。更意外的是 20x 似乎又能给新账号开通——此前 Tibo 刚宣布暂停不久（[「Pro 20x 暂停新订阅」]({{ '/daily/2026/09/10/daily/#pro-20x-暂停新订阅' | relative_url }})）。他还预测 GPT-5.3 Spark 退役会释放大量算力，半个月内产能可能恢复。

### Harness 终局：只需 Bash

<span class="mention">@坚定的貂</span> 凌晨抛出了一个激进命题：如果模型把 harness 的所有能力吃掉，整个 harness 只需要一个东西——bash。他逐一对照 Codex 目前的 read、edit 等工具调用，认为 bash 全都能做；只要 environment 足够好，harness 就可以扔掉了。推演到极致更激进：给 AI 一个键盘加屏幕，它能自己把操作系统写出来——「真 Gödel machine 了」。

> <span class="mention">@坚定的貂</span>：有一个足够好的 environment，harness 就能扔掉了

<span class="mention">@开朗的企鹅</span> 把思路翻译为「model 自己维护一个自己的 harness」，但他认为此时工具的意义从完成任务变成了效率优化——大概率还是需要一套类似 DSH 的脚手架。<span class="mention">@坦荡的灰熊</span> 质疑模型是否有足够注意力去完成更高层抽象，「凡事不怕难就怕没有注意力」。<span class="mention">@稳重的海豚</span> 给出折中判断：harness 还是得有，再厉害的人也没法啥都记脑子里。

## 工具

### AI 音乐视频制作教程

<span class="mention">@沉稳的仓鼠</span> 分享了他写的 [AI 音乐视频完整制作教程](https://ranchen.org/content/20260912-rancheng-article-how-to-make-ai-music-video)，覆盖从构思到发布的全链路。核心思路是人只提需求、挑选和反馈，注册登录等步骤手工确认，其余全交 AI。推荐 GPT-6 Extra High，相比 5.6 审美有明显飞跃。

工作流依次为：让 AI 下载上百个优质 MV 建素材库并总结打分标准 → Suno 生成音乐 → 本地模型生成 SRT 时间轴歌词 → storyboard → Grok CLI 图生视频（订阅制，一支 MV 常需 50–100 个视频）→ Blender 白模生成运镜 reference → fal 平台 OmniHuman 1.5 对口型 → 超分到 1080p → Computer Use 上传各平台。<span class="mention">@随和的飞鼠</span> 补充了一个自动化技巧：用 Playwright 脚本处理歌词粘贴和下载，整段不用手工介入。

### Codex 自建测试验证 UIA

<span class="mention">@搞仁义毛义仁</span> 让 Astra 复刻微软已停产的 UIInspector 工具（基于 GacUI），用于辅助后续 UI Automation 测试。四个多小时后去看进度，发现 Codex 不但在写 UIInspector 本身，还自行创建了一整套 test app 来验证 UIA client 实现——按钮、复选框、文本框、下拉菜单、列表、滑块一应俱全，甚至标注了控件坐标原点。

![Codex 自建的 UIA 验证测试应用，包含各类 Windows 原生控件](/assets/img/daily/2026/09/2026-09-13-01.webp)

> <span class="mention">@搞仁义毛义仁</span>：太敬业了

另外，<span class="mention">@洒脱的猫头鹰</span> 发现 Codex 的 TUI whimsy 动画特性会额外吃掉约 12% CPU（和 iterm2 对比），加上 pets 功能合计多占 12%，可以用 `codex -c tui.whimsy=false` 关掉。

## 闲聊花絮

### 鹌鹑骑车与王八打球

CSS 动画成了模型能力的新试金石。<span class="mention">@开朗的企鹅</span> 让 Astra High「画个鹌鹑骑车的动画，用 CSS」——6 秒出活，一只戴头盔的小鸟蹬着红色自行车，配文「今天不赶路，今天追风」。<span class="mention">@活泼的树懒</span> 吐槽这明明是鹈鹕，顺带断言「AI 现在已经在背答案了」。

<span class="mention">@稳重的海豚</span> 提议换个更刁钻的题目：王八打球。Astra 版本是一只穿球鞋的绿乌龟、背着 8 号壳运球，标语「速度可以慢，球不能丢」；Kimi 的版本明显粗糙——球浮在半空、乌龟纹丝不动、气泡里喊「好球！」。

### 网课烧额度奇遇记

<span class="mention">@睿智的犀牛</span> 下午才发现自己 Pro 账号上攒了三张 reset 卡，从来没超过额度。他正打算降级到 $20 Plus 省钱，<span class="mention">@稳重的海豚</span> 赶紧拦住：reset 卡在 Pro 上价值 $80，降到 Plus 就缩水成 $8——「先把 reset 用完」。

怎么花？答案来自前一天发明的奇招（[「Codex 代上培训课」]({{ '/daily/2026/09/12/daily/#codex-代上培训课' | relative_url }})）：让 Astra 替你上网课。<span class="mention">@睿智的犀牛</span> 立刻行动，开 Work 模式接 Astra Ultra，一下午从 100% 烧到 0%，用掉一张 reset 卡充回满血继续干。完工时恰好又烧完一个 100%，他评价「质量很可观」，还感叹这体验「有西红柿首富那种感觉」。

### 17 个正方形装袋

<span class="mention">@搞仁义毛义仁</span> 贴了一张食物照片：密封袋里的方块点心被摆成了倾斜交错的奇怪布局。他丢给 Astra 问「笑点在哪」，Astra 花了两分半正确识别——这是数学圈的经典梗：17 个正方形的紧密装填问题，16 个可以整齐排成 4×4，多出一个后最优解反而长得很别扭，「明明很高效，却丑得像乱摆」。

### 程序员失业铁人三项
