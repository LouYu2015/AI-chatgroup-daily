## 行业新闻

### Pro Max 实锤与 DevDay 倒计时

延续昨天的爆料（[「ChatGPT Pro Max $500 档」]({{ '/daily/2026/09/24/daily/#chatgpt-pro-max-500-档' | relative_url }})），今天有了代码级证据。<span class="mention">@活泼的树懒</span> 贴出 openai/codex 仓库 commit（#47971）：`PlanType` 枚举新增 `promax`，显示名映射 `prolite` → "Pro"、`pro` → "Pro (More)"、`promax` → "Pro (Max)"；前端配置中 promax 月费 $600（含税），`psp_override` 底价 $500（税前）。三档消费层级清晰浮现：$100 Lite、$200 Pro、$500 Max。

<span class="mention">@活泼的树懒</span> 估算 Max 提供 Plus 的 50 倍用量和独立算力保障，核心卖点是速度而非额度——「你开 6 个 extra ultra 的话，消耗特别大」。<span class="mention">@沉稳的松鼠</span> 赌一个月 Pro Max 的钱押下周二 DevDay 官宣。<span class="mention">@80-HD</span> 关注两个连锁反应：其一是 $500 档利好中转站，API 转售天花板随之抬高；其二是 X 上传言 $200 档可能逐步淘汰——不过代码中 `sci` 层级（$200）仍然存在，现有订户大概率被 grandfather。

Chat 与 Work（Codex）额度合并的传闻同日浮出。<span class="mention">@稳重的海豚</span> 担心变成通用 quota，<span class="mention">@活泼的树懒</span> 确认方向是「全力收拢算力」。<span class="mention">@搞仁义毛义仁</span> 不以为然——chat 消耗量极小，并进来「感觉也没区别」。<span class="mention">@80-HD</span> 将趋势概括为 <span class="mention">@沉稳的仓鼠</span> 此前的预言：补贴越来越少、价格越来越高。

### 客体永久性世界模型开源

<span class="mention">@开朗的海龟</span> 分享了他们团队发布的 [Training Object Permanence in World Models](https://object-permanence.world)（[论文](https://arxiv.org/abs/2609.28654)）：150 个认知科学启发的任务、150 万条 Blender 渲染训练数据、一套 300 题评测以及一个 16B 世界模型 PWM-WROP，代码、数据、模型权重和排行榜全部开源。

出发点是：3.5 个月大的婴儿已经知道滚到墙后的球依然存在，而当前视频生成模型普遍缺失这种客体永久性。150 个任务分属六个认知类别，Blender 生成器在保持认知结构不变的前提下随机化光照、速度、相机角度，每个任务产出上万条样本。盲测 Elo 中 PWM-WROP 在 continuation 模型中排第一、总榜第三，仅落后于两个商业 reference-to-video 系统的统计平局。<span class="mention">@细心的熊猫</span> 翻完作者栏感慨「大佬云集」。

### BabelTele 压缩密语

<span class="mention">@风趣的海豚</span> 分享了一篇[论文科普](https://mp.weixin.qq.com/s?__biz=MzY5ODIyNjQ3Ng==&mid=2247483862&idx=1&sn=ebd8fba52089542febf67dddd8d92feb&chksm=f53ec66aad3e59bdcdba8fc8d8800a921a68a7df4dca321ed28baf9eaddc1a94bd24d41bea82#rd)：BabelTele 让 AI 把自然语言压缩成人类几乎读不懂的紧凑文本，再由另一个 AI 还原语义。压缩到原长度 27.9% 时语义保真度仍达 99.5%；Agent 场景下上下文占用减少 70% 以上，多 agent 通信 token 降约 60%。关键限制是压缩器和解码器必须同系列匹配，跨模型使用大幅打折。

<span class="mention">@博学的穿山甲</span> 对 99.5% 保真度存疑：AI 表述本身就充满歧义，「一个概念用好多不同的说法来说，不同的概念又有的时候用一个名词」。

恰好同日 <span class="mention">@今天群内信息量极大</span> 遇到一个「模型不需要人话」的活例子——英文项目中 Astra 输出突然蹦出中文「片子」二字。<span class="mention">@风趣的企鹅</span> 解释说用户文档含中文时模型思考链常会混入中文，<span class="mention">@今天群内信息量极大</span> 确认自己很多文档确实是中文。这种语言泄漏虽然不是 BabelTele 式的刻意压缩，但底层逻辑相通：模型内部本就不依赖人类可读格式来保持语义。

### Codex 401 宕机与紧急 Reset

中秋假期刚过，Codex 下午突发 401 Unauthorized 错误。<span class="mention">@敏锐的海狸</span> 率先报告，<span class="mention">@低调的熊猫</span> 跟进确认，X 上同时涌现大量报错推文。OpenAI 状态页标记 Codex 故障并称已定位根因。<span class="mention">@风趣的穿山甲</span> 贴出状态页截图后附赠一句：「中秋快乐。」<span class="mention">@沉稳的兔子</span> 催促「兄弟们中秋假期结束了，快回来上班吧」，Codex 倒先一步撂了挑子。

<span class="mention">@沉稳的兔子</span> 发现 API key 登录可以绕过，自嘲式总结：「各位，多花点钱问题就解决了。」<span class="mention">@开朗的企鹅</span> 给出了实际可用的应急方案——通过 MCP 连接器接入 ChatGPT 网页版 GPT Pro 继续干活（详见下节）。

### WebCodex MCP 断网应急

<span class="mention">@开朗的企鹅</span> 在 Codex 宕机期间展示了一种备用工作流：通过 MCP 连接器将本地项目接入 ChatGPT 网页版，让 GPT Pro 读取本地 AGENTS.md、rules 和 contexts 后直接在网页端操作——「只是增加了一个连接器，没有修改网页本身」。

<span class="mention">@神秘的麋鹿</span> 担心是否会被封号，<span class="mention">@开朗的企鹅</span> 澄清这不涉及绕过限制。他进一步设想团队场景：「一个团队买 2 个 500 刀分享给五个人。」不过 <span class="mention">@80-HD</span> 提醒，如果下周 Chat 与 Work 额度合并，这种 plan sharing 策略可能失效。

### Astra 3D 打印全流程

Astra 在 3D 建模和打印领域的能力今天被多位群友独立验证，从设计到切片到送印的全链路已基本打通。

<span class="mention">@专注的火烈鸟</span> 宣布 Astra 在建模领域「一骑绝尘」，完成了某个项目终稿并上机测试——「打印机踩冒烟了」。他特别认可 GPT-6 这代模型在严谨性验证方面的进步，「我原谅祂的 overthinking 了」。

<span class="mention">@今天群内信息量极大</span> 让 Astra 设计了五款 iPhone 手机支架的 STL 模型，Astra 自行做水密性核查和穿模检测，五款全部通过 topology audit。更让他意外的是后续环节：Astra 直接调用 Bambu Studio 计算最优打印方向和支撑面积，完成切片参数设置——「我只要最后审核，点一下 print 就可以了」。坏消息是：打出来的支架架不住手机。

> <span class="mention">@今天群内信息量极大</span>：除了不能架手机以外都很完美

<span class="mention">@80-HD</span> 献出递归方案：「再打印一个放手机架子的架子。」<span class="mention">@稳重的海豚</span> 递进一步：「再打印一个放手机架子的架子的架子。」

### Biggest Number 才是真基准

### 薄肌风潮拆解

<span class="mention">@豁达的灰熊</span> 一句「上周的信息流：jev jev jev 薄肌 薄肌 薄肌」引出了半天的健身跨界讨论。<span class="mention">@沉稳的仓鼠</span> 随即写了一篇长分析，帮 <span class="mention">@冷静的飞鼠</span> 「下一期视频准备好了」——用评估流行概念的五步方法拆解薄肌热潮：先厘清定义，再区分审美、健康、运动能力等维度，最后追问「如果拿'有没有薄肌'去评价马斯克厉不厉害，你马上会觉得这个比较很荒谬」。核心论点是每一轮审美热点都在做同一件事：先定义指标，再让所有人围绕它竞争。

> <span class="mention">@沉稳的仓鼠</span>：为什么我要用你的尺子量我自己？

<span class="mention">@冷静的飞鼠</span> 对薄肌理念持认同态度，包括对意志力的促进。<span class="mention">@豁达的剑鱼</span> 一句话拆穿：「就是没本事练大，找个借口变成精心设计努力统筹克服困难故意为之。」<span class="mention">@冷静的飞鼠</span> 自嘲走了第三条路——「肥肌：肌肉藏在肥肉下面，又有肌肉又不会硌得慌。」
