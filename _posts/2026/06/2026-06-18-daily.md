## 行业新闻

<span class="mention">@沉稳的仓鼠</span> 借此划了一张 Agentic Workflow 四段光谱：Codex / CC 这种 AI native 的「只给你 AI」→ Manus 这种「自带更多工具、把工具给 AI」→ Genspark 这种「把 AI 给工具」→ 微软那种「把弱智 AI 给弱智工具」——并强调「都有受众」。<span class="mention">@稳重的海豚</span> 补了一句「不要支持新加坡货」。

## 方法论

### 200 美元 plan 与给娃报课的心理锚定

<span class="mention">@80-HD</span> 读完 <span class="mention">@沉稳的仓鼠</span> 的[「200 美元 coding plan 值不值」](https://ranchen.org/content/20260615-rancheng-article-200-dollar-coding-plan)后分享了一个心理锚定发现：给娃报音乐启蒙课 200 元/月想都不想就付了，但订 200 美元的 AI 套餐却还要纠结。<span class="mention">@活泼的羊驼</span> 补刀：「很多人愿意支付 2000 的车贷，但连 2000 人民币的 AI 会员都纠结很久。」<span class="mention">@机智的水獭</span> 追加：「以及 200 万人民币房贷。」

<span class="mention">@80-HD</span> 进一步反思：娃的课本质上是「纯付费娱乐」——游泳去了三年多还不会游，音乐课找的是做 music therapy 的。

> <span class="mention">@80-HD</span>：我给娃花钱并不是为了让他学到啥，我只是买个让自己轻松的时间

<span class="mention">@活泼的羊驼</span> 认同 <span class="mention">@沉稳的仓鼠</span> 博客的核心判断，建议出播客版。<span class="mention">@80-HD</span> 反而觉得看比听好——「博客我都是洗澡做饭听，不太会思考；看的我反而会停下来反复看」。

### AI 时代的知识内化困境

200 美元话题延伸出了更深层的讨论。<span class="mention">@活泼的羊驼</span> 坦承看完好文章「爽了一下」但记不住，觉得需要 AI 出「课后选择题判断题」来内化 mindset——因为 AI 擅长举一反三和类比。<span class="mention">@今天群内信息量极大</span> 建议「捂住答案自己想一遍」，或者写作来巩固：「很多时候以为自己懂，其实没懂。」

<span class="mention">@活泼的羊驼</span> 进一步指出 AI 降低了写作门槛的同时也削弱了写作对学习的助力：以前必须想清楚才能写清楚，这个主动调用的过程本身就是学习；现在 AI 代劳了，学习效果打折。<span class="mention">@今天群内信息量极大</span> 回应「我应该加个古法写作，至少古法写提纲」。

<span class="mention">@我要成为灵能高手</span> 点出了问题的结构性翻转：

> <span class="mention">@我要成为灵能高手</span>：本来目的就是写一篇文章，给别人看是副作用，现在反过来了，跟做题一样。原本做题是为了提高自己，现在提高自己是为了做题，就会走上不同的道路

<span class="mention">@稳重的海豚</span> 以亲身经验确认：非古法写作「压根记不住」——即使一字一字读了觉得好才发出去，还是记不住。<span class="mention">@我要成为灵能高手</span> 解释机制：古法写作迫使每个字都自己打出来，所以会去想文章从头到尾逻辑是否通顺——「理清楚每一句话的逻辑是否通顺的目的是为了说服自己，这就是通过写作学习的机制」。<span class="mention">@飘逸的浣熊</span> 补充了另一个理由：「AI 写作的时候也需要自己消化一下，有时候 AI 会出现幻觉。」

### 组织膨胀：大象原来只是一只鸡

<span class="mention">@直率的海豚</span> 分享了一段组织复杂度感悟：前几年扩张时一个组招了十几个人，每人添砖加瓦把一个组件搞得非常复杂——接口五花八门、「条条大道通罗马贬义版」。现在组织缩水，知识青黄不接，没人知道大象长什么样，「更不知道它原来只是一只公鸡」。AI 提效了，但可能只是加快了鸡变成大象的过程。

> <span class="mention">@直率的海豚</span>：算上总位移，大象在比赛中跑得也不算慢，可特么弯路多的时候，大家都在怀念那只鸡

<span class="mention">@80-HD</span> 总结「Meta 神奇的点在于明明是一座屎山，但是它能跑」，<span class="mention">@直率的海豚</span> 接道「没人说劳动人民的结晶不能是屎啊」。话题随即滑入 bot 自动 stamp code 的 AI native 日常——<span class="mention">@80-HD</span> 一句「有些组 bot 发 code，bot stamp」，<span class="mention">@直率的海豚</span> 确认 oncall 已经痛不欲生。

## 工具

### Relay Voice：语音笔记转 AI 工作流

<span class="mention">@冷静的飞鼠</span> 分享了自己上架的第二个 iOS App [Relay Voice](https://www.superlinear.academy/c/share-your-projects/1-99-19-99-app-icp)，定价 $19.99 一次买断。核心场景源于他坚持五个月的每日习惯：散步时录语音笔记 → 自动转录 → AI 总结 → Markdown → 接入 Claude Code knowledge base。App 本地优先、无服务器、Bring Your Own Key，转录支持 Apple Intelligence、Whisper、Qwen-ASR 及多个云端 API。他坦言最大的不确定性是 ICP 可能「只有我自己一个人」，选择 build in public 让市场来回答 product-market fit。

### AI 驱动 Shopify 电商

<span class="mention">@谨慎的松鼠</span> 分享了自己和朋友的副业实践：3 个人业余时间 + agent 基本 cover 完整电商运营。Shopify 所有操作都可通过 CLI 控制，整个网店交给 AI 管理；邮件有资料库，AI 自动生成回复草稿，最后人审一下。全部 AI 成本只有一个 $200 GPT 订阅。

> <span class="mention">@谨慎的松鼠</span>：运营除了和人交流那一步，基本可以不介入

不过他也提到额度已用完「直接成原始人」。<span class="mention">@神秘的企鹅</span> 追问是否囤货，<span class="mention">@谨慎的松鼠</span> 透露品类特殊可以不囤。<span class="mention">@认真的狮子</span> 指出国内已有人做这种代运营的 AI Agent 卖服务。<span class="mention">@敏锐的穿山甲</span> 感叹「如果卖东西不用请运营可以 AI 代劳，运营起来很爽」。

### Codex 额度缩水与 Reset 细节

延续 [「Codex Reset Bank 上线」]({{ '/daily/2026/06/17/daily/#codex-reset-bank-上线' | relative_url }})，<span class="mention">@直率的鸵鸟</span> 发现从未使用过 reset 也收到了 2 次可用重置，坦言「不并行任务的话，根本用不完 20x」。<span class="mention">@风趣的海豚</span> 不同意：「Goal 一下，做点多模态的事情，两天就能用完。」<span class="mention">@冷静的麋鹿</span> 贡献了一个实用细节：使用周配额 reset 后，5h 配额也会同步恢复——<span class="mention">@稳重的海豚</span> 差点不知情就浪费掉了。

但另一边，<span class="mention">@谨慎的松鼠</span> 和 <span class="mention">@活泼的树懒</span> 确认 Codex $100 档额度最近实际缩水——之前用不完，现在不够用。<span class="mention">@谨慎的松鼠</span> 准备「回到国模 + GPT 形式」。

## 闲聊花絮

### 「让 me」与「let 我」

<span class="mention">@直率的海豚</span> 先是感叹 Opus 4.8 写作「已经成功比 GPT 更 GPT」，紧接着 <span class="mention">@今天群内信息量极大</span> 展示了更离谱的证据：Opus 写出「让 me 直接在 tile 接收→push」，DeepSeek 写出「Let 我先了解一下现有项目」——两家被封为「卧龙凤雏」。<span class="mention">@随和的飞鼠</span> 贡献了「你 com 什么 plain」，<span class="mention">@冷静的飞鼠</span> 改良版「wor 不 work」。

> <span class="mention">@今天群内信息量极大</span>：中英文混合的最高境界是 wo 不 work，叹为观止。完全无理，但又很自然

然后他突然反应过来「完全无理」本身是日语（無理），自嘲「AI 看到估计也得吐槽我」。<span class="mention">@我要成为灵能高手</span> 猜测根因是「搞不好就是 prompt 和 document 里面中英混合影响了」。<span class="mention">@稳重的海豚</span> 则怀疑「除了在中文 GitHub 上没见过这么颠的」。

### CC Reset 戒断

<span class="mention">@沉稳的仓鼠</span> 一天内两次在群里问「CC 啥时候 reset」。<span class="mention">@敏锐的海狸</span> 贴出了更戏剧化的截图——自己在别的群到处问「有人最近 CC Max 账号不用的吗，借我用一天」「明天 reset，今天不能干活我要疯了」「搞得跟吸毒一样」，最后投降「哎我不行了 我再注册个账号吧」。他形容等待 reset 的感觉是「全身蚂蚁在爬」。

<span class="mention">@神秘的企鹅</span> 分享了反面教训：一个 Goal 跑了 14 个小时，因为目标设定不好「白跑了」。<span class="mention">@我要成为灵能高手</span> 给出了 vibe coding 的正确心态定位：「vibe coding 就是把碎片化时间整合起来把人 release 出去玩的。」
