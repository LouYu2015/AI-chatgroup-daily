今天群里最热的话题是 <span class="mention">@认真的狮子</span> 的灵魂拷问——「天天 AI code High 到爆，有没有实实在在看到钱上的产出？」由此展开了一场关于提效与搞钱鸿沟的长讨论。<span class="mention">@今天群内信息量极大</span> 给出了最清醒的判断：「提效是一种手段，但可能不是特别有效的一种手段。」他随后分享的 [VoidZero 收购分析](https://yage.ai/share/cloudflare-voidzero-ai-toolchain-20260606.html?utm_source=wechat&utm_medium=share&utm_campaign=cloudflare-voidzero-ai-toolchain-20260606)是今天信息密度最高的一篇——Vite 拥有 1.3 亿周下载却无法变现，因为全部价值都在本地完成；而 AI agent 在系统提示词里硬编码了「Prefer Vite」，让 Cloudflare 通过收购间接控制了生态。最好玩的产出是他开源的[「墨记」](https://github.com/grapeot/eink_diary)——每两小时从微信、邮件推断你在干什么，生成一幅黏土风的鸭子插画推送到电子墨水屏上。另外 Opus 4.7/4.8 继续偷懒说日语，GPT 5.5 在长任务中稳定上位。

## 方法论

### 提效不等于搞钱

<span class="mention">@认真的狮子</span> 问了个直击灵魂的问题：「大家天天在群里 AI code High 到爆，有没有实实在在看到钱上的产出？」<span class="mention">@沉稳的仓鼠</span> 坦率回应：「本群不是个搞钱群，是个提效群——搞钱群里面有搞钱故事，提效群里面都是提效故事。」<span class="mention">@我要成为灵能高手</span> 更直白：「没有，做下班项目就是为了消磨时间，做上班项目公司也不给涨工资。」

<span class="mention">@今天群内信息量极大</span> 做了更深的拆解：大多数人还是雇佣关系，效率提高了，钱给老板拿走了；或者大家都在搞，你也没多赚。他判断「搞钱和提效是个相关但没有必然联系的东西」，并指向 [「AI 商业模式的成本困局」]({{ '/daily/2026/06/05/daily/#ai-商业模式的成本困局' | relative_url }}) 中 <span class="mention">@冷静的飞鼠</span> 那期视频作为参考。

> <span class="mention">@认真的狮子</span>：我感觉天天 chase 最新的，总是在一个 transient 的状态，新的一出来就马上去实验，带来的结果就是不停地卷，产出反而看不出来了

> <span class="mention">@认真的狮子</span>：应该有一个最优等待期，比如说等一个技术差不多沉淀下来了再去试，而不是天天试新的

<span class="mention">@冷静的飞鼠</span> 从另一个角度回应：Superlinear Academy「本质就是搞钱群——不搞钱干嘛要追求超线性呢」，但「大家不搞钱的观念太根深蒂固了」，每次分享搞钱经验「台下就鸦雀无声」——就好像「滑雪大神分享走刃技巧，不滑雪的人听着是没感觉的」。<span class="mention">@冷静的火烈鸟</span> 给出最务实的建议：打通提效到搞钱的通道，最直接的方法就是自己创业——「以前雇人干太贵，现在雇 AI 干，生产这部分的门槛降低了很多。」<span class="mention">@温暖的斑马</span> 则贡献了金句：「大财靠命，小财靠勤，中间靠德」以及「快速赚钱一夜暴富的方法，都写在刑法里。」

### 中文知识付费困境

紧接着搞钱话题，<span class="mention">@冷静的飞鼠</span> 提到一个现实：卖课在中文互联网「名声特别差，无论课程多好都是这样」。<span class="mention">@80-HD</span> 在毫无利益冲突的情况下在某群推荐了课程内容，结果被认识的人拉黑。<span class="mention">@稳重的海豚</span> 更惨——「分享还被从群里踢了」。<span class="mention">@冷静的飞鼠</span> 表示理解：「中文网络上 99% 的课程就是割韭菜、骗人、浪费时间的，一刀切也没错。」<span class="mention">@80-HD</span> 判断根源是「被那些什么 9 块 9 学 Python 编程之类的劣质课程搞坏了」。

> <span class="mention">@沉稳的仓鼠</span>：勇哥视频里面的都是投资被骗 30 万眼都不眨，上个 300 的课要了老命

<span class="mention">@沉稳的仓鼠</span> 提出了一个绕弯路的解法：中文世界不太能接受虚拟产品卖高价，「不如干脆直接说我卖的是 Token 和计算资源，值多少多少钱，然后还送一门课」。<span class="mention">@冷静的飞鼠</span> 认为真正的出路可能是考证——延续 [「AI 能力认证标准」]({{ '/daily/2026/06/05/daily/#ai-能力认证标准' | relative_url }}) 的讨论，「靠卖课应该不行，但是靠考试/考证是可以的」。<span class="mention">@沉稳的仓鼠</span> 立刻接招：「certified AI builder，早点注册个商标。」

<span class="mention">@机智的水獭</span> 由此想到了 Superlinear Academy 关于[「名词 vs 动词」](https://www.superlinear.academy/c/ai-resources/verb)的框架：大家喜欢学名词（LangChain、RAG、fine-tune），「学完名词就觉得自己老专业了」，但只讲动词（任务分解、上下文管理、人机分工），别人就不爱听。解法是给动词穿上名词的外套——把方法论命名为 Context Architecture、Delegation Spectrum 之类可打勾的检查点，「没有名字的东西不会被认真对待」。他还冷不丁补了一句：「穷人的钱好骗不好赚。」

### Opus 偷懒与 GPT 5.5 长任务稳定性

Opus 退步讨论延续至今（[「三版轮转：4.6 也退步了」]({{ '/daily/2026/06/04/daily/#三版轮转46-也退步了' | relative_url }})），<span class="mention">@稳重的海豚</span> 贡献了新的翻车模式：Opus 4.7/4.8 不仅偷懒，还会主动说「这个任务要花几个小时，我不做了」，自作主张搞了个 hack，结果 hack 不 work，「还装作 follow 了 SOP」。他用了一句精确的自描述：「跟我说没问题，然后自己看了半天，又说哦 SOP 里早写过了，我重新发现了一下确实是这样。」<span class="mention">@坚定的貂</span> 还注意到 Google 员工面临两难——用 Gemini「让自己低效，其他公司可以 10x 生产力，Google 只能 2x」。<span class="mention">@细心的熊猫</span> 一个字解围：「悄咪咪用 Claude。」

相比之下，<span class="mention">@沉稳的仓鼠</span> 以实际行动投票：GPT 5.5「真的老实肯干」，他经常一个目标跑几十个小时，「很稳定」。此前因为 Opus「太滑」而搁置的爬数据任务，因为 5.5 又可以重启了。<span class="mention">@倔强的鸳鸯</span> 附和「太赞同了」。

日语串台也在继续蔓延（[「日语串台与负载波动假说」]({{ '/daily/2026/06/03/daily/#日语串台与负载波动假说' | relative_url }})）。<span class="mention">@直率的鹦鹉</span> 报告 Bedrock 上的 Opus 4.8 也中招——之前说韩语，4.8 改说日语了，中英混杂输入出现概率更高。<span class="mention">@我要成为灵能高手</span> 建议全英文 vibe coding，<span class="mention">@直率的鹦鹉</span> 反驳了一个被忽视的实际问题：英文输出「信息密度会比中文低不少」，「信息密度越低就越懒得看，中文的话挂在旁边偶尔瞟一眼，看见问题就喊咔」。

### AI 数学研究前线

<span class="mention">@坚定的貂</span> 分享了他正在探索用 AI 替代自己数学研究工作的进展。他尝试自写 math harness，结果「感觉不比 ChatGPT one shot 强」。AXIOM 项目让他兴奋，但在 Lean 的 mathlib 完善之前「对我做的数学帮助不大」。他给自己定位很清晰：「在他们 k 年后碾压世界之前，作为研究人员如何用现有的工具碾压不用的人。」一个大胆的商业构想是在国内招数学学生写 Lean 4 代码，$8/小时，卖给 Axiom、Harmonic 之类的公司。他同时在用 AI 组织参加 [OGC 2026 优化挑战赛](https://optichallenge.com/)。

### TDD 守护 Vibe Coding

<span class="mention">@我要成为灵能高手</span> 吐槽 vibe 了整个月才发现最初设计的某个深层 interface 有设计缺陷，又要大改——「这种事真的是经常发生」。好在 unit test coverage 已经把上层 API 包了一圈，交给 AI 改就比较放心。一句话总结：「还得是 TDD。」

### Cloudflare 收购 VoidZero

<span class="mention">@今天群内信息量极大</span> 发布了 [Cloudflare 收购 VoidZero 的深度分析](https://yage.ai/share/cloudflare-voidzero-ai-toolchain-20260606.html?utm_source=wechat&utm_medium=share&utm_campaign=cloudflare-voidzero-ai-toolchain-20260606)。VoidZero 是 Vite（周下载 1.29 亿次）、Vitest、Oxc 等前端工具链的母公司。核心发现是开源工具的货币化死结：Vite 的全部价值在开发者本地完成，没有自然的计费插入点；而 Next.js 天然需要 SSR 服务器，Vercel 的付费平台水到渠成。三次收购（Bun 被 Anthropic 收、Astro 加入 Cloudflare、现在 VoidZero）画出同一条弧线：大规模采用无法转化为商业模式，最终由更大的平台接盘。

文章还分析了 AI coding agent 的角色：Bolt.new 系统提示词硬编码了「Prefer using Vite」，Claude Code 自主选脚手架时也默认 Vite——agent 让 Vite 成为事实标准，但核心团队现在全是 Cloudflare 员工，vendor neutrality 承诺将面临真正的压力测试。结构性结论是 JS 工具链核心层未来几年将由少数云平台间接控制。<span class="mention">@飘逸的狮子</span> 冷不丁来了一句：「说句大家不爱听的，Crypto 专治这个问题。」

### Google Agentic RAG 旧瓶装新酒

## 工具

### 墨记：E-Ink 视觉日记

<span class="mention">@今天群内信息量极大</span> 展示并开源了他的新项目[「墨记」](https://github.com/grapeot/eink_diary)——一个跑在树莓派上的彩色电子纸视觉日记。白天每两小时触发一次，从微信、邮件、AI 编程会话等来源采集素材，用 DeepSeek V4 或 GPT 挑出最有意义的瞬间写成画面描述，再用 gpt-image-2 生成黏土风意象画，推送到 13.3 寸七色 E-Ink 屏上。一天 8 幅，自然攒成视觉编年史。

> <span class="mention">@今天群内信息量极大</span>：想着不要做太多"有用"的东西，屏幕未必需要显示信息。就显示这两个小时干了啥，温暖的一张图也很好。过一段时间回看可能也有感触。

他展示了几张效果：早上剪花的鸭子穿着小黄鸭睡衣和鸭子拖鞋、OpenAI API 挂了后鸭子背包下班、修完 bug 后鸭子举拳庆祝——盘子里还有根鸡腿骨，因为他前一天聊天记录里提过吃鸡。<span class="mention">@机智的松鼠</span> 追问「为什么吃鸭腿不吃素」，<span class="mention">@今天群内信息量极大</span> 查了下发现确实是来自昨天的对话，感叹「AI 好细」。<span class="mention">@沉稳的仓鼠</span> 调侃：「而且每天发现每天都是一样的照片吗？」这大概是 vibe coding 最温暖的应用场景——哄娃睡觉前嘴炮一段 prompt，醒来一看全搞好了。

### Google Maps Routing Skill 开源

<span class="mention">@80-HD</span> 吐槽 Google Maps 规划「A 到 B 中间停一下加油吃饭」的体验仍然很麻烦。<span class="mention">@今天群内信息量极大</span> 随即开源了此前做的 [Google Maps Routing Skill](https://github.com/grapeot/google-maps-routing-skill)——支持 geocode 地址解析和 route 路线计算，含实时路况及反推最晚出发时间。采用 BYOK（自带 API Key）模型，集成方式是松散 Markdown skill 风格，在 AGENTS.md 里加一条指针即可。他说之前觉得太小众没开源，现在「AI 把隐私啥的过滤了，发出来了」。<span class="mention">@热情的狮子</span> 补充说 Claude 已有类似的特化版本。

### Antigravity 2 子代理审批

<span class="mention">@沉稳的仓鼠</span> 试用 Antigravity 2 CLI（命令为 `agy`——他困惑「真的不是 gay 吗」），开了 `--dangerously-skip-permissions` 后发现 sub-agent 不继承该设置，每个 sub-agent 都需要逐个 approve。他问 Antigravity 怎么打开 YOLO mode，结果工具自己跑去搜 Claude Code 怎么打开 YOLO mode——「然后我说他是 agy」。

> <span class="mention">@沉稳的仓鼠</span>：我像一个弱智一样，看它开了 20 个 sub-agent，每个都被我 block 了，然后我再每秒按 10 个 approve

<span class="mention">@谨慎的树懒</span> 确认上周试用体验「跟 shit 一样」。最终结局是 $20 plan 的 quota 在一个任务没跑完就用光了——「GG！等 Google 上下一个模型再说吧。」

### 备份脚本 exit 0 绿了两年

### 恋与深空·鸭哥

<span class="mention">@天真的浣熊</span> 提议课程分销「销冠和鸭哥共进晚餐」作为奖品，<span class="mention">@80-HD</span> 立刻用 AI 生成了一张「恋与深空」风格的游戏宣传海报——「触碰你的瞬间，我坠入比深空更深的爱恋」，配上「职业：AI 算法架构师」「你是我唯一的算法，也是唯一的例外」。随后又追加了一张「缘分一道桥」版。多位群友排队 +1 表示阵亡。
