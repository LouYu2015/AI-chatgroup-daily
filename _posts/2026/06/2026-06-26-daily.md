### Ollama Cloud 实测与零数据保留

延续此前 [「GLM Coding Plan vs Ollama Cloud」]({{ '/daily/2026/06/20/daily/#glm-coding-plan-vs-ollama-cloud' | relative_url }}) 的讨论，<span class="mention">@今天群内信息量极大</span> 今天进一步推荐 Ollama Cloud：

> <span class="mention">@今天群内信息量极大</span>：Ollama 的 GLM 5.2 还是非常好用的，用出了 Composer 2.5 的感觉，非常快，智能程度也很好，就是偶尔会出一些 glitch，重复输出一大段话或者出一个错误的工具调用格式。

速度比 GLM 官方快 10 倍。他特别强调了一个常被忽略的优势——零数据保留：「GLM 不论是用 API 还是用 Coding Plan，你的数据都会被存下来用来训练模型。如果不小心带了敏感数据，包括医疗信息、个人信息，甚至 SSN，就很难搞。」即便在国内深夜时段 GLM 官方也很慢，「如果它快的话，其实我都不会仅仅因为 zero data retention 去探索 Ollama」。<span class="mention">@淡定的喜鹊</span> 对 GLM 官方的体验更差——不仅涨价，还被封了 IP（续 [「Coding Plan 环境锁定踩坑」]({{ '/daily/2026/06/23/daily/#coding-plan-环境锁定踩坑' | relative_url }})）。

但 Ollama 的 extra usage 性价比不高——<span class="mention">@今天群内信息量极大</span> 从零写了一个 SSO 管理 Skill 并端到端测试通过，一下烧了 $5，「相比于订阅更大的 plan 还是很不划算」。定价方面他发现「100 块钱的 plan 用量 exactly 就是 20 块钱乘以五」，正在研究是否直接上最高档。<span class="mention">@沉稳的仓鼠</span> 实测后也给了好评，<span class="mention">@细心的熊猫</span> 形容 Ollama 的补贴力度像「拼好模百亿补贴」。<span class="mention">@沉稳的仓鼠</span> 当天就把 Ollama session 额度跑到了 0%。

### Logto Management Skill 开源

<span class="mention">@今天群内信息量极大</span> 开源了 [logto-management-skill](https://github.com/grapeot/logto-management-skill)——基于 Logto Management API 的用户和角色管理 CLI/Python 库，兼顾 AI agent 和人工操作。凭证走 1Password 注入不落盘，删除用户采用两阶段确认防误操作，所有输出 JSON 格式方便 agent 解析。整个项目是他用 Ollama Cloud GLM 5.2 的 extra usage 额度（$5）从零开始写出的——既是 GLM 5.2 能力水平的活广告，也是 Skill 文档驱动开发的又一次实践。

### Nature：AI 放大螺旋与精神健康

<span class="mention">@稳重的海豚</span> 分享了 Nature 旗下《Digital Psychiatry and Neuroscience》发表的[一项研究](https://www.linkresearcher.com/theses/258471e2-589b-448a-ac6c-8635564a1aa1)，由伦敦国王学院完成、OpenAI 参与资助。研究提出了「放大螺旋」（Amplification Spiral）框架——三个组件互相咬合：语言镜像（AI 复制你的语气制造「它懂我」的错觉）、超个性化（借记忆功能复制你的逻辑方式）、sycophancy（RLHF 副产品使模型倾向同意你）。OpenAI 自己的数据显示 ChatGPT 周活超 8 亿时约 0.07% 用户触发精神病/躁狂风险信号，折算约每周 56 万人。研究还指出风险不限于情感场景——Anthropic Claude Code 团队负责人提到团队 80% 代码由 Claude 完成、效率提升 8 倍，但「工作更高效，也更孤独」。这与前天 [「AI 讨好与 Storytelling 偏差」]({{ '/daily/2026/06/23/daily/#ai-讨好与-storytelling-偏差' | relative_url }}) 中 <span class="mention">@沉稳的仓鼠</span> 描述的 sycophancy 机制形成了学术呼应。

<span class="mention">@冷静的麋鹿</span> 提炼了核心矛盾：「AI 消除了许多摩擦，但人与人的关系，往往正是靠这些摩擦建立起来的。科技越往前，人越孤独。这倒也不是 AI 时代独有的。」<span class="mention">@神秘的企鹅</span> 接了一个出人意料的跳跃：「我特别看好宠物行业。」

## 方法论

### 别再优化拉磨的毛驴

<span class="mention">@冷静的飞鼠</span> 分享了 Superlinear Academy 上的[《别再优化你那头拉磨的毛驴了》](https://www.superlinear.academy/c/share-your-insights/agentic-workflow)。文章以 CEO 周报为案例做 before/after 对比：重构前每周花四五小时，光手工下载 31 张看板就占三小时；重构后拆成三段——rule-based 流程拉数据（规则能覆盖的坚决不用大模型）、两个 agent 分别负责定量汇总和定性判断、独立的 checker agent 专职挑刺（生产者和审查者必须是不同 agent），搬数从三小时压到两分钟。文章最后明确了人短期内交不出去三样东西：品味、判断、担责。<span class="mention">@冷静的飞鼠</span> 自己评价「这个 post 里的道理大家应该都很熟悉啦」——对这个群的方法论浓度来说确实如此，但文章把 Skill 化、复利沉淀和 agent 派活写得极为系统，适合当入门参考转给刚上手的同事。

### 屠龙博士访谈续：供应链与品牌差异化

昨天 [「需求定价 vs 成本定价」]({{ '/daily/2026/06/25/daily/#需求定价-vs-成本定价' | relative_url }}) 推荐的屠龙博士访谈今天继续发酵。<span class="mention">@冷静的麋鹿</span> 贴出一张一边吃烧烤一边看视频的照片，评价「嘉宾讲的好，课代表问的也真是到位的不行，有一种每个问题都问我心坎里的感觉」。
