今天最值得关注的是微软正式发布自研推理模型 MAI-Thinking-1（35B active / ~1T MoE），SWE-Bench Pro 追平 Opus 4.6、AIME 2025 拿到 97%——虽然 <span class="mention">@我要成为灵能高手</span> 给 Polymarket 上微软年底 #1 的 9% 概率直接批了个「0%」。实用侧最需要留意的是 Opus 4.8 的工具调用退化 bug：<span class="mention">@今天群内信息量极大</span> 发现模型频繁将 XML tool call 直接输出为文本，且一旦发生就无法恢复。工具侧 <span class="mention">@风趣的海豚</span> 带来一个意外推荐——Gemini 3.5 Flash + Antigravity 2 跑长 harness 的体验「超出预期」。行业侧，微信即将上线 AI 助手的消息推动腾讯单日暴涨 10.46%，而 Mindverse 完成 $5000 万 A 轮的 PR 稿被群友从叙事到技术都拆了一遍。

## 行业新闻

### MAI-Thinking-1 正式发布

<span class="mention">@我要成为灵能高手</span> 贴出微软 [MAI-Thinking-1 官方发布页](https://microsoft.ai/news/introducing-mai-thinking-1/)。这是微软首个正式对外发布的自研推理模型——35B active 参数、总参数约 1T 的稀疏 MoE 架构，context window 256K。核心数据：SWE-Bench Pro 与 Claude Opus 4.6 持平；AIME 2025 达 97.0%、AIME 2026 达 94.5%；在 1,276 条由专业评分员参与的盲测 side-by-side 中人类偏好优于 Sonnet 4.6。训练理念上强调「能力学来而非蒸馏来」——全程未使用任何第三方模型蒸馏，预训练数据排除 AI 生成内容，安全对齐与能力训练通过同一套 RL 基础设施一起完成。

同时确认昨天讨论中被 <span class="mention">@我要成为灵能高手</span> 用 GacUI 任务拷打的 MAI-Code-1-Flash（详见 [「MAI-Code-1-Flash 实测翻车」]({{ '/daily/2026/06/01/daily/#mai-code-1-flash-实测翻车' | relative_url }})）实际只有 5B 参数。<span class="mention">@天真的浣熊</span> 追问「5B 模型里 SOTA 了吗」，<span class="mention">@我要成为灵能高手</span> 透露后续还有 Ultra 版本。

### Mindverse $5000 万 A 轮

<span class="mention">@活泼的羊驼</span> 分享了[真格天使项目 Mindverse（心洲科技）完成近 $5000 万 A 轮融资](https://mp.weixin.qq.com/s/sKaAekWgtaMDSGhMTuV3qQ)的报道。美团领投，约 20 人核心研发团队（来自 DeepSeek、字节 Seed、xAI 等）。核心技术路线是用 LoRA 做持续学习——在万亿参数 MoE 模型上做 RL，性能与全参数训练无损但成本只需 1/10。即将开源 750B agent 模型（744B GLM 5.1 底座 + 6B LoRA），支持 mixture of LoRA 结构，百万级 LoRA 并发激活。C 端产品 Macaron 已有 200 万用户、逾 10 万 DAU。

群友对 PR 叙事的反应比技术本身更热烈。稿中声称创始人三年前在论文中写下「Agent 的能力最终要回到模型训练本身，而非靠 prompt 和框架拼出来」，彼时「几乎没人认同」。<span class="mention">@随和的企鹅</span> 直接开喷：「这尼玛能叫没人认同吗，这不是行业主流观点么。」<span class="mention">@聪明的灰熊</span> 给出了更冷静的框架：

> <span class="mention">@聪明的灰熊</span>：PR 一般就三个目的——搞钱、招人、汇报。这篇的核心就是真格投资的项目获得了很好的进展，值得庆祝和关注

他补充「不是嘲讽，就是一个惯常手段」。<span class="mention">@活泼的羊驼</span> 快速读完后总结了技术要点——Mindverse 用类 LoRA 方案让基模在垂域表现更好，因为基模不可能适配所有垂域，「或者这个知识本身之前是不存在于互联网的，或者是残缺的」。他也指出稿子的问题：「把一个已经逐渐主流化的判断包装成'当年几乎没人认同、现在被我们验证了'的英雄叙事，同时把 LoRA / mixture of LoRA / 参数化记忆讲得有点过满」。

## 工具

### Opus 4.8 工具调用退化为文本

<span class="mention">@今天群内信息量极大</span> 报告了一个严重的 Opus 4.8 bug：在 Claude Code 中模型频繁将工具调用退化为纯文本输出——直接在回复中打出 `<invoke name="Edit">` 这样的原始 XML，而不是真正执行工具。更棘手的是「一旦这样就回不去了，只能抛弃 context 重开」。<span class="mention">@倔强的鸳鸯</span> 确认「贼烦」，<span class="mention">@洒脱的飞鼠</span> 说一天就遇到这个问题。

<span class="mention">@稳重的海豚</span> 给出变通方案——进 session 直接改那条 message 或开新 session。他之前用 Composio 时也遇过类似问题，「主要是因为 Composio 那个 tool 写得不好」。<span class="mention">@80-HD</span> 没遇到过 XML 泄漏，但有另一个怪象：「会经常在 tool call 前回我一个 'court'，不知道啥意思。」这与过去一周 [「Opus 4.8 翻车续：捏造数据与天花板质疑」]({{ '/daily/2026/05/30/daily/#opus-48-翻车续捏造数据与天花板质疑' | relative_url }}) 以来 4.8 持续暴露的稳定性问题方向一致。

### Gemini 3.5 Flash + Antigravity 2

<span class="mention">@风趣的海豚</span> 推荐了一个出人意料的组合：Gemini 3.5 Flash 搭配 Antigravity 2 客户端。核心逻辑是速度快 + 超大上下文，允许塞入巨长的 harness：

> <span class="mention">@风趣的海豚</span>：可以试一下，把整个老鸭汤当上下文丢给他，然后它的反应速度巨快

具体方法是让模型把所有执行过程中的文档变成文本，「在形成结论之前反复过 3-4 遍，自己跟自己 debate」。他是被一个做材料的朋友「疯狂安利」后重新充了 Ultra。<span class="mention">@坦荡的灰熊</span> 提醒别用 Gemini CLI（他之前被安利，结果只有 2.5 版）。<span class="mention">@风趣的海豚</span> 回应说那是很久以前的事了，<span class="mention">@倔强的鸳鸯</span> 确认「现在 Gemini CLI 已经被抛弃了」，Antigravity 2 是新产品。<span class="mention">@热情的狮子</span> 问 Gemini 订阅能不能在 OpenCode 等其他 agent 中使用，答案是不能。

另外，<span class="mention">@沉稳的仓鼠</span> 推荐了 Gemini 3.1 Pro 的中文写作能力（API 版本），「比我想的好，推荐试一下」。

## 方法论

### AI 普及的真正门槛

<span class="mention">@豁达的灰熊</span> 分享了一张信息量极大的点阵图：81 亿人中 84%（~68 亿）从未使用过 AI，16%（~13 亿）是免费 chatbot 用户，付费 $20/月的仅 ~0.3%（1500-2500 万），使用 coding scaffold 的更是只有 ~0.04%（200-500 万）。他感叹「普及还是有空间的」。

<span class="mention">@风趣的海豚</span> 由此提出了一个反直觉的观点：

> <span class="mention">@风趣的海豚</span>：使用 agentic AI 的前提是你要拥有一台电脑，并且使用得相当熟练，但是这部分人口的数量可能也只有 1%，所以基本上可以认为所有熟练使用电脑的人现在可能都在 agentically 使用 AI

他进一步指出 agentic AI 的本质是「数据自主」——你在用 AI 的同时也在为 AI 贡献训练数据。<span class="mention">@我要成为灵能高手</span> 补充了中美对比视角：国内用 AI 娱乐的人更多，而美国人还在「你 Facebook 居然用 AI 自动回复怎么不雇一个人来做助手我不在你这买变形金刚了」的进度上。<span class="mention">@风趣的海豚</span> 秒懂：「这话太白人了。」

<span class="mention">@幽默的火烈鸟</span> 贡献了接地气的案例：女朋友手写数学公式半小时写了不到一半，AI 一分钟全搞完——「很多人根本不知道 AI 的工具属性，只知道搜索引擎的功能」。<span class="mention">@优雅的海豚</span> 趁机预告了团队做的「外置前额叶」可穿戴智能体，称「应该不会有比这个做的更贴近你想要的'完全懂你'」。

### 模型集体退步与 Vibe Coding 泡沫

<span class="mention">@沉稳的仓鼠</span> 抛出一个观察：「突然一下全部 model 都拉了，为啥？」<span class="mention">@我要成为灵能高手</span> 给出了结构性解释：

> <span class="mention">@我要成为灵能高手</span>：地球上的数据都吃完了，大家卷 training 要是没有真正有效的东西，以后有什么发展难说了

<span class="mention">@活泼的羊驼</span> 提出另一个假说——各家是否因为要上市，需要缩小参数规模、提升效能，用更小的模型做出 95% 水平的旗舰？<span class="mention">@我要成为灵能高手</span> 认为这条路的商业基础也不稳：「现在花钱的都在搞 vibe coding，如果要用户花那么多心思才能重现广告里吹牛逼的奇迹的话，很快牛逼就要吹爆了。」<span class="mention">@细心的熊猫</span> 反问「为什么圈内大佬都说 pretraining 还远没触及天花板」，这个问题没有人直接回应。

这场讨论延续了过去一周从 [「Opus 4.8 翻车续：捏造数据与天花板质疑」]({{ '/daily/2026/05/30/daily/#opus-48-翻车续捏造数据与天花板质疑' | relative_url }}) 到 [「大模型逻辑能力五月横评」]({{ '/daily/2026/05/31/daily/#大模型逻辑能力五月横评' | relative_url }}) 的持续关注——模型迭代是在挤牙膏还是在蓄力，群里至今没有共识。
