今天最值得细读的是 <span class="mention">@今天群内信息量极大</span> 关于 Anthropic/OpenAI 开源收购战的深度分析——半年内买下 Bun、Stainless、Astral 等一系列 MIT 许可证项目，核心不是代码而是「团队即隐性知识」和「竞对不能拿」。最戏剧化的案例是 Anthropic 收购 Bun 后团队四天合并百万行 Rust 重写，以及收购 Stainless 后直接关掉托管服务掐断 OpenAI 的 SDK 管道——<span class="mention">@今天群内信息量极大</span> 将此命名为「Denial of infrastructure attack」。人事方面，Karpathy 宣布加入 Anthropic 预训练团队引发群内惊叹与接力调侃；Google I/O 一口气释放 Gemini 3.5 Flash、Antigravity 2.0、Universal Commerce Protocol 等大量更新，但 Vertex AI 悄然更名 Agent Platform 让 <span class="mention">@细心的熊猫</span> 当场崩溃——「我上周才整明白 genkit 跟 Vertex AI SDK 区别，这周告诉我 Vertex AI 没了。」闲聊方面，群友在 Bun Rust 重写的震撼中整齐复读「人类还是太脆弱了」，以及一份 Claude Code「八荣八耻」在深夜流传。

## 开源收购战

### 花几亿买开源项目的逻辑

<span class="mention">@今天群内信息量极大</span> 发布了 [既然都是开源的，为什么还要花几亿去买](https://yage.ai/share/open-source-acquisition-ai-infra-20260519.html?utm_source=wechat&utm_medium=share&utm_campaign=open-source-acquisition-ai-infra-20260519)。Anthropic 半年内完成四笔收购——Bun（JS 运行时）、Vercept、Coefficient Bio（约 4 亿美元股票）、Stainless（SDK 自动生成，超 3 亿美元）；OpenAI 则拿下 Python 工具链 Astral（uv/Ruff/ty）。这些项目几乎全是 MIT 许可证，理论上任何人都可以零成本 fork。

文章的核心判断：MIT 许可证给了 fork 的自由，但没有给四样东西——原团队的隐性知识、阻止竞对截胡的能力、对路线图的决策权、以及对上游不确定性的对冲。Stainless 的案例最为典型：它同时为 OpenAI 和 Anthropic 自动生成生产级 SDK，anthropic-sdk-python 仓库 825 个源文件头部都有同一行「File generated from our OpenAPI spec by Stainless」，OpenAI 的 Node SDK 发布脚本也直接上传到 Stainless 的构建服务器。收购后托管产品直接关闭，OpenAI 失去了自动 SDK 同步能力。Stainless 还做 MCP Server 自动生成——在 Anthropic 主导的 agent 连接标准上拥有最快的执行工具链。

> <span class="mention">@今天群内信息量极大</span>：想象中的商战：优化训练算法，多场景刷榜。事实的商战：你用什么软件，收购这个公司断你的线

<span class="mention">@豁达的鸵鸟</span> 提供了一个亲眼目击的细节：前天 Stainless 官网的示例代码还是 OpenAI 的 SDK，被收购后已经全换成 Anthropic 的。<span class="mention">@今天群内信息量极大</span> 进一步概括这轮竞争的本质：2024 年的竞争核心是「谁的模型最好」，2026 年变成「agent 跑在谁的基础设施上」。两家背后的 VC 高度重叠——a16z 同时投了 Stainless 和 Astral——资本在主动促成 AI lab 对共享基础设施的整合。

<span class="mention">@开朗的企鹅</span> 受此启发分析了当前最值得做的开源方向，核心判断是「Agent Runtime Reliability Kit」——agent 连接真实世界之前的测试、审计、回放、治理层，是最像 Bun/Stainless/Astral 那类可被大厂盯上的承重基础设施。

### Bun Rust 重写与基础设施掐喉

<span class="mention">@今天群内信息量极大</span> 在讨论中引出了 Bun 收购后最戏剧化的一幕：Claude Code 的运行时绑在 Bun 上（冷启动 3 毫秒，比 Python 快 15 倍），而 Bun 原本用 Zig 编写且长期存在内存泄漏。更尴尬的是，Zig 语言创始人在行为准则里明确禁止 AI/LLM 生成内容，而 Anthropic 的主业正是 AI。收购后创始人团队在四天内将超过一百万行 Rust 代码合并进主分支，几乎完全由 AI agent 完成，基本解决了内存泄漏。

> <span class="mention">@今天群内信息量极大</span>：你搞不定的事情，又不给用 AI 来搞，只能完全灭门，用 Rust+AI 来搞定了

<span class="mention">@随和的飞鼠</span> 点出 Rust 在 AI 时代的独特优势：「能编译就基本一定对这个特点，反而变成好事了。」<span class="mention">@天真的浣熊</span> 感慨 Firefox 自己的 Rust 重写至今没搞定——讽刺的是 Rust 最初就是 Mozilla 为重写 Firefox 而创造的。<span class="mention">@今天群内信息量极大</span> 确认：「啊是的，是 Mozilla 搞的，为了重写一个安全的 web 浏览器引擎。」

<span class="mention">@今天群内信息量极大</span> 在这条讨论线上再次分享了前天的 [「为 AI 重写工具：Zero 与 Cloudflare 的启示」]({{ '/daily/2026/05/17/daily/#为-ai-重写工具zero-与-cloudflare-的启示' | relative_url }})：「很多东西 AI 适配不是把 API 翻译成 MCP 就好，要针对 AI 的优缺点彻底改动设计。」

> <span class="mention">@机智的荷兰猪</span>：真实的商战：用开水浇灭对方公司的前台发财树……物理和玄学上的双重打击

### SaaS 数据保护变成定价功能

<span class="mention">@今天群内信息量极大</span> 发布了 [当数据保护变成定价功能：SaaS 行业 AI 数据策略的三代演化](https://yage.ai/share/saas-ai-data-pricing-20260519.html?utm_source=wechat&utm_medium=share&utm_campaign=saas-ai-data-pricing-20260519)。文章梳理了从 2023 年 Zoom 激进收集→退让，到 2024 年 Slack 偷偷改政策→笨重 opt-out，到 2026 年 Atlassian/GitHub 按付费层级分层开放数据保护的三代演化——Atlassian 的帮助页面曾明确写着「customer data is not used for AI model training」，现在变成了「by default, unless you pay more」。行业出现明显分裂：Figma、Salesforce 站在默认收集一侧；Google Workspace、Microsoft 365、GitLab、Notion 则承诺不训练且写入合同。

<span class="mention">@冷静的麋鹿</span> 的延伸分析堪称当天最有深度的回复。他用视频平台广告模型做类比：一开始会员的卖点是「不看广告」，但付费用户恰恰是最有价值的广告受众——你通过付费手段区隔出最有价值的一批人，却保护他们不看广告，本身就是矛盾的。

> <span class="mention">@冷静的麋鹿</span>：如果你想让模型的能力持续提升，就不得不去寻找高价值的数据，而那些高价值的数据，恰恰就是你之前通过付费方式隔离出来的。

<span class="mention">@豁达的鸵鸟</span> 补充了 B 端的不同路径：「要么私有化严重，因为合同合规各种关系，要不然搞合作专门部署，或者像是和 Reddit 这样平台买数据绕过用户。」<span class="mention">@今天群内信息量极大</span> 确认趋势已在发生：Confluence 现在非 Enterprise 账户已经不能 opt out 了。这与此前 [「OpenAI 银行数据接入」]({{ '/daily/2026/05/16/daily/#openai-银行数据接入' | relative_url }}) 的讨论指向同一方向——数据主权正在被重新定价。

## 方法论

### 用 LLM Wiki 克隆写作风格

<span class="mention">@细心的猫头鹰</span> 分享了他正在搭建的 LLM Wiki 工作流：把自己 90 篇超过 1000 赞的知乎答案和 200 篇博客文章全部导入，现在看到想回答的问题直接把题目贴给 Codex，审阅调整后发出。

更有意思的是他对 2 万条推文的处理方式：直接导入质量很低，于是先对每条 tweet 做 embedding，再对 2 万个 embedding 做 clustering，最后把每个 cluster 里的 tweet 合成一个 Markdown 文档导入。<span class="mention">@稳重的海豚</span> 追问核心目的，<span class="mention">@细心的猫头鹰</span> 拆成两层：一是通过 MCP 让 AI 搜索到自己过去的观点做参考；二是让 AI 先归纳已有文本的写作风格，再在写作时应用。目标是「尽快让 AI 取代我来发文本内容」。

### 命令行与 Git：AI 接管开发者日常

<span class="mention">@风趣的企鹅</span> 发了一条 `cd -` 小技巧，引发了一场关于命令行技能是否还有必要学的集体感慨。<span class="mention">@80-HD</span> 坦言「用了 CC 以后，cd - 再也没有用过了，反正都让 CC 自己切」，进而承认「命令行我都要退化了，基本全靠嘴炮」。

> <span class="mention">@鸭哥大号</span>：过去命令行用的不熟练，现在直接不用了，只要学的不够快，就可以不用学了

<span class="mention">@细心的熊猫</span> 补刀「等等党大胜利」「我感觉我的 emacs 算是彻底白学了」。<span class="mention">@坦荡的灰熊</span> 更惨：「我用 SuperMemo 背过各种教程上的命令，现在觉得好蠢。」<span class="mention">@鸭哥大号</span> 说现在看到有人说 PowerShell 命令太长，标准答案是「2026 年了你们还自己打命令？」

Git 是唯一例外。<span class="mention">@鸭哥大号</span> 警告「git 不记得不行，AI 搞垮 git 了太容易了」，特别是让 AI 做人工 squash 的时候。他分享了自己写给 AI agent 的 [verify-and-commit.md](https://github.com/vczh-libraries/Workflow/blob/master/.github/Rules/verify-and-commit.md)——三段式提交规范，末尾全大写强调「DO NOT ASK ME ANY QUESTION」。<span class="mention">@80-HD</span> 说 CC 经常跟他商量「你太多 commit 了，我们先 squash 然后再修 merge conflict，这样我能少做点」——他的应对策略是从老板那里学来的话术：

> <span class="mention">@80-HD</span>：就把当年老板对我的话术给 AI 了——"use your best judgement"

<span class="mention">@坦荡的灰熊</span> 分享了他最近最有用的两条 prompt：「帮我做个 inspector UI 反射查看内部的数据结构」和「先派 1-3 个 agent 调查下」——前者解决了需求递增时对黑盒不收敛的恐慌，两者均来自 CC 自己的 /insight 建议。<span class="mention">@细心的熊猫</span> 还贡献了一个有趣观察：AI 让 rule-based 编程活了第二春——以前太多 if-else 嵌套属于屎山烂代码，「现在发现可以屎」。

### Vibe Coding 录音设备续篇

延续前天 [「麦克风的核心问题是距离」]({{ '/daily/2026/05/17/daily/#麦克风的核心问题是距离' | relative_url }}) 的讨论，<span class="mention">@今天群内信息量极大</span> 关注到 Insta360 新出的无线麦克风，评价「壳确实有点厚」，但发现一个亮点——自带内录（内置存储），不需要实时连接手机。<span class="mention">@天真的浣熊</span> 确认这款在美国有卖。

<span class="mention">@稳重的海豚</span> 推荐了另一个方向：如果主要做内录，Plaud 更实用——「可以撑好几天，而且可以连续录至少几十个小时。」<span class="mention">@今天群内信息量极大</span> 还提到 Even Reality 智能眼镜在实时转录方面效果不错，app 里现在能导出原始 txt，续航够用一天，但自动化仍是短板。<span class="mention">@神秘的麋鹿</span> 建议智能眼镜方向，<span class="mention">@今天群内信息量极大</span> 的整体判断是还在调研中，「感觉代价蛮大，自动化更难，多携带一两个设备，电源管理」。录音设备的核心取舍仍在音质、便携性、续航和自动化之间拉锯。

### "人类还是太脆弱了"

Bun 用 Rust 重写、AI agent 四天合并百万行代码、编译通过就基本正确——<span class="mention">@随和的飞鼠</span> 一句「人类还是太脆弱了」引爆了当天最整齐的复读：<span class="mention">@今天群内信息量极大</span>、<span class="mention">@风趣的企鹅</span>、<span class="mention">@冷静的麋鹿</span> 齐刷刷跟上同一句话。到了晚间，<span class="mention">@沉稳的仓鼠</span> 贴了一张手绘漫画——「周围大多数的痛苦，都来自于不得不跟一群弱智一起工作」，下方画着 AI 替代同事后的美好生活。<span class="mention">@优雅的兔子</span> 立刻搜了《Surrounded by Idiots》这本书，然后感慨：「上班的体验就是有点像上刑但也有点像上坟，很妙。」<span class="mention">@谨慎的灰熊</span> 贴了一张墙体涂鸦——「万万没想到我们活着的任务是打工，所有打工以外的事全都需要请假完成，例如看病旅游陪家人。」
