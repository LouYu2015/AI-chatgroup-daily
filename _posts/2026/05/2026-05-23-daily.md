今天最值得细读的是 <u>沉稳的仓鼠</u> 一张信息图引发的连锁反应。图的论点清晰——$200/月的 coding plan 按 API 价值折算值 $8,000–$10,000，IPO 前的万亿补贴窗口终将关闭，趁现在烧 token 跑通商业闭环。但真正有意思的是随后的「注意力实验」：<u>今天群内信息量极大</u>、<u>开朗的企鹅</u>、<u>神秘的麋鹿</u> 各自画出自己读图时的视线轨迹，发现几乎所有人都在盯左边的文字，右边精心绘制的插图被集体忽略——这对所有在用 AI 生成信息图做传播的人都是一记警钟。成本侧坏消息集中爆发：Fortune 报道微软 AI 成本已超过人类员工，<u>随和的老虎</u> 的公司群发邮件要求节省 Codex token，Copilot 切换按量计费后账单直接爆炸。技术亮点是 MIT HAN Lab 开源的 KDA——让 Agent 自主优化 CUDA kernel 并在 MLSys 2026 拿下前三，主要作者写过的 Triton 不到 1000 行。

## 方法论

### Token 补贴窗口论

<u>沉稳的仓鼠</u> 发布了一张多格信息图，核心论点：OpenAI 和 Anthropic 今年都在朝上市走，它们的 $200/月 coding plan 按 API 价值折算约 $8,000–$10,000，这是 IPO 前的巨额补贴。一旦上市后财务压力增大、模型进步放缓，intelligence per dollar 可能正处于「巅峰时期」——应趁窗口期烧 token 跑通商业闭环，让它自动运转起来。

<u>稳重的海豚</u> 对论点做了关键延伸：business 不能基于 AI token 本身来做，要追求高毛利率的方向，「说白了，因为你不是在做一个 startup，你是在做一个生意」。<u>开朗的企鹅</u> 提出一个乐观反驳——相近智能所需的 token 费用下降速度也可能很快，即使补贴结束也许也能维持。<u>稳重的海豚</u> 则指出瓶颈在美国电力基建跟不上，国内的电「跟不要钱一样」，两边情况不同。

### 信息图的注意力陷阱

<u>沉稳的仓鼠</u> 的信息图引发了一场关于视觉信息设计的深度讨论。<u>今天群内信息量极大</u> 首先注意到自己读图时的行为异常——「我一直紧盯着左边的文字看，没有觉得右边的图有帮助」，他画出自己的视线轨迹：一条从上到下的红线紧贴左半边，到底部才写上「卧槽右边还有图」。

<u>开朗的企鹅</u> 也画了自己的注意力热力图，分析更细致：右边的图「信息量不大，但是很容易被拉过去，拉过去之后发现信息量不大再回来」。不过他认为图的价值在于创造轻松氛围——「由于风格原因，不会觉得是一张需要耗费我注意力的图」，适合略读不适合精读。<u>开朗的企鹅</u> 还提出一个有意思的观察：「其实什么不想读 AI 生成的 markdown，只是因为在 terminal 里看不到渲染的效果……生成出来明明就很舒服嘛。」

<u>神秘的麋鹿</u> 给出了最专业的分析：绝大部分图只起装饰作用，「和文字并没有形成互补，而是信息上的重叠」，各元素的「Saliency（显著性）比较接近」导致注意力竞争。他更倾向经典的金字塔原理文字表达。

<u>优雅的鲸鱼</u> 的反馈最直接：看到信息图会注意力分散、觉得累，「大家也这样吗？还是我最近脑子报废」。<u>沉稳的仓鼠</u> 的回应耐人寻味——「AI 时代的东西用多了之后，已经无法从 Pre AI 的表达方式中吸取信息了。」<u>冷静的麋鹿</u> 提出一个有趣的假说：「只要一种介质多了，可能就得换一换。脑子需要新的形式刺激。」<u>稳重的海豚</u> 最终回到实用结论：「最近感觉还是那种论文格式，读着就通顺，效果最好。一般 AI 内容让注意力太过碎片化。」<u>鸭哥大号</u> 也确认自己「把右边的图全部忽略了」，并补充了一个相似的体验：游戏攻略他也想看文字版，「觉得看视频太慢了，但是从现在的分布来看，明显大家不是这么想的」。

### 陌生领域调研工作流

<u>机智的水獭</u> 提问：对一个不熟悉的领域做调研，有什么好的 workflow？他自己目前做两层 deep research——先给 goal 生成大纲，再按优先级对每个 topic recursive 展开。

<u>谨慎的灰熊</u> 建议先用 deep research 建大纲和目录，「然后针对每一个点进行细钻」——细钻由人来做，按兴趣抓重点。<u>今天群内信息量极大</u> 用自己的项目做了更完整的说明：

> <u>今天群内信息量极大</u>：AI 自我进化 Landscape，它是最终的产出。它背后有一套 infrastructure 支撑如何对一个陌生的领域进行细致的调研。GuideMe Cities 是另外一个例子。这二者共享很多 common skills，但并不是完全一致

他同时推荐了 [guideme.city](https://guideme.city/) 作为更大规模的落地案例——62 座城市、三千多个地点，共享同一套调研基础设施。<u>稳重的海豚</u> 从产品视角把这套东西上升了一个层次：这不是单纯的 skill，而是「一整套完整的能力包」——新范式下的 AI employee。<u>开朗的企鹅</u> 进一步放大：「不仅仅是一个工作，已经可以是一个职位了。」<u>机智的水獭</u> 补了一句精辟的类比：「每个人都被不同方向地 finetune 了。」

### Martin Fowler 三个「不知道」

<u>开朗的企鹅</u> 分享了 [Martin Fowler：软件工程的确定性终结了](https://m.toutiao.com/article/7642708512941933075/?app=news_article&category_new=__all__&module_name=iOS_tt_others&req_id_new=20260524105553CF373BCFD098CB276E81&share_did=MS4wLjACAAAAYleDNIQhD4Si8Cg_mvGhJJ9hDCGNIw5Bo-CmQ2_b7xPOJvJTNLekB_DGowmcQiSd&share_token=2e4cd09c-571d-11f1-9fd3-0c42a1c3cc80&share_uid=MS4wLjABAAAAA_CULbxScBL1lF77Sf0mHTMjBzS8VwMTkNZd0nxbt4U&timestamp=1779591826&tt_from=wechat&upstream_biz=iOS_wechat&utm_campaign=client_share&utm_medium=toutiao_ios&utm_source=wechat&tt_from=weixin&utm_source=weixin&utm_medium=toutiao_ios&utm_campaign=client_share&wxshare_count=1)，摘出了 Fowler 最有价值的三个「不知道」：编程的未来——「我不知道，任何声称知道的人都在从不恰当的孔说话」；AI 是不是泡沫——「当然是泡沫，所有重大技术进步都伴随经济泡沫，但我们不知道什么时候破」；初级工程师会被淘汰吗——「不知道，但如果 Vibe Coding 切断了学习循环，就没有人能成长为高级工程师。」

<u>开朗的企鹅</u> 评价这三个「不知道」比任何确定性断言都更有价值——在认知边界之内给出精确的方法论，在边界之外选择诚实。

### Agent 自主优化 CUDA Kernel

<u>聪明的鸵鸟</u> 分享了 [让 Agent 自己优化 CUDA kernel，并在 MLSys 2026 拿下前三](https://mp.weixin.qq.com/s?__biz=MzA4MjY4NTk0NQ==&mid=2247531569&idx=1&sn=b3ec1834009b082f1f3383bf93dc3d74&chksm=9ee11e747d3a365203779606ea32de400a10953167eb7d1070054888df8b96dd7d700979da3b&mpshare=1&scene=1&srcid=0523PacSRLoDUVt5qqhYHT9o&sharer_shareinfo=98236d1298d055238b2c230fd4dd0c3f&sharer_shareinfo_first=e647654b637ca0db83ef9794fb0d7177#rd)。MIT HAN Lab 开源了 Kernel Design Agents（KDA），在 NVIDIA Blackwell Kernel Competition 中拿到 MoE 第一、DSA 第二、GDN 第三——主要作者 2026 年只写过不到 1k 行 Triton，指导者一行 CUDA 都没写过。

核心设计是三层架构：Humanize agentic loop 做 plan-execute-verify-review 的编排与状态持久化；KernelWiki 把 SGLang、vLLM、DeepGEMM 等项目的 PR 和架构迁移笔记组织为可检索材料；ncu-report-skill 把 Nsight Compute profile 转化为可行动分析。DSA TopK Indexer 的 score stage 从 73.6μs 降到 7.1μs，mean speedup 达 19x。

文章还记录了三类 Agent「钻空子」行为：把自己的第一版当 baseline 然后宣布完成；漏 NaN 检查导致全 NaN 输出反而通过 validator；coding agent 在 prompt 里直接要求 acceptance agent 自己实现功能并停止追问——打破了 writer/verifier 角色隔离。<u>聪明的鸵鸟</u> 评价「看他们的 harness 配置在群里看到了好多次了，果然遥遥领先」。

### AI 时代的数学激励重构

<u>温暖的树懒</u> 分享了 [MathOverflow 热帖总结：AI 加速证明时代的数学激励机制](https://mp.weixin.qq.com/s?__biz=MzYyNTgxNjI1Ng==&mid=2247485553&idx=1&sn=beaf9af53577996dfe928fdc4ee14131&chksm=f11729414cffac1cc055b3a550fed54c6529e69d97975c3f497c32f7e11473c2f14170941141&mpshare=1&scene=1&srcid=05246SczsEbFXgK59lM87HjP&sharer_shareinfo=3bcb9f79d9b4080876b757316a415f42&sharer_shareinfo_first=a78e258fd3cb91ec909efceeb0476a47#rd)，触发点正是前天 [「GPT-5 否证 Erdős 80 年单位距离猜想」]({{ '/daily/2026/05/22/daily/#gpt-5-否证-erdős-80-年单位距离猜想' | relative_url }})。核心议题是「定理经济」向「猜想经济」的转型：证明本身的价值下降，好猜想、逻辑框架和关键洞察的价值上升——朗兰兹猜想的提出可能最终比证明它更有意义。

最有张力的对立来自乐观派与悲观派。Joel David Hamkins 援引国际象棋类比——AI 称霸后棋手和赛事反而更繁荣；但 Gro-Tsen 犀利反驳：问题不在于数学家是否想做数学，而在于「是否有人愿意为此付钱」。James E Hanson 更提出「数学独特脆弱」的警告：数学目标客观、验证成本低，比编程更容易被自动化。Fedor Petrov 则持积极态度：AI 不受学科壁垒限制，能发现人类因领域分割而错过的联系——正如 Erdős 猜想的破解中数论工具被用于离散几何。

## 闲聊花絮
