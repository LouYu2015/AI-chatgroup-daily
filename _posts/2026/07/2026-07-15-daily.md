## GPT-5.6 实测第七日

### 一周 1B：$100 与 $200 的同款账本

### Fable 失色：降智疑云与退 A 保 O

### 脚踏板装备学：解放双手约等于不用脑子

### 手机遥控 codex：opencode 双端胜出

<span class="mention">@洒脱的狐狸</span> 的痛点：主力开发机是没有桌面的 Linux，平时用 macOS 上的 Codex desktop 通过 SSH connection 遥控；一个多月前手机 ChatGPT 还能接管 desktop 名下所有 SSH remote，某次更新后失效了。他不喜欢在手机上敲命令行，之前折腾过 GitHub 上的 codex-remote 还自己改造过，结果 codex cli 协议升级后又坏了——应急为主的需求养不起一个要经常维护的工具。

方案征集很快收敛：<span class="mention">@沉稳的仓鼠</span> 指路 codex app 自带 remote control、可遥控各机器上的 codex（<span class="mention">@稳重的海豚</span> 确认好用）；<span class="mention">@天真的浣熊</span> 给出 tmux + tailscale + Terminus 组合；<span class="mention">@今天群内信息量极大</span> 的最终答案是 opencode + iOS client，多 server 无缝切换、附加功能多，Android 也有[原生客户端](https://github.com/grapeot/opencode_android_client/)，release 里直接下 apk。<span class="mention">@80-HD</span> 认领同款：绝大部分 codex 流量都走 opencode，「主要是手机口嗨很方便」，但提醒 A 社订阅走 opencode 算违反 ToS——<span class="mention">@今天群内信息量极大</span> 确认 A 社的确实没办法。性能上 <span class="mention">@沉稳的松鼠</span> 反馈同样 workload opencode 比原生 codex 慢很多，<span class="mention">@80-HD</span> 说慢一些但能接受，<span class="mention">@今天群内信息量极大</span> 补充 opencode 现在也有 fast 模式了。

顺带曝光了工作形态的变化：<span class="mention">@今天群内信息量极大</span> 现在主力是三折叠手机加 iPad，电脑很少用；<span class="mention">@洒脱的猫头鹰</span> 期待华强北今年出一款 iOS 三折叠。<span class="mention">@神秘的企鹅</span> 的观后感代表沉默的大多数：「学不过来，根本学不过来。」

### 容忍度此消彼长：从 Garry Tan 离婚梗说起

<span class="mention">@天真的浣熊</span> 贴出 Garry Tan 两条帖子的残忍对照：1 月那条沉迷 Claude Code 连干 19 小时、凌晨 5 点才睡的推，和最近官宣结束 14 年婚姻的声明——<span class="mention">@活泼的斑马</span> 的读法直击要害：「因为 claude code 离婚了？」<span class="mention">@今天群内信息量极大</span> 由此想起 <span class="mention">@沉稳的仓鼠</span> 上周那篇文章（见 7 月 11 日 [「《AI 杀死了我容忍弱智的能力》」]({{ '/daily/2026/07/11/daily/#ai-杀死了我容忍弱智的能力' | relative_url }})）：AI 相处多了，对人类甚至伴侣确实也有影响。<span class="mention">@神秘的企鹅</span> 认领对客户和合作伙伴的容忍度都在下降；<span class="mention">@天真的海豚</span> 的推论反而乐观——「情商更重要了。因为更稀缺了」。

<span class="mention">@细心的熊猫</span> 是罕见的反例：容忍度反而提高了，因为所有东西都能自己手搓。以前同事合并搞坏 branch 只能生闷气，现在 Claude 一秒修好；此前依赖同事维护的 pipeline 三个月坏一次、每次都得求人，现在全自己搓了，「和同事的关系融洽多了」。他把同样的逻辑推广到 FSD——车自己开之后再没因为开车和对象吵过架，下一步期待家用机器人消灭家务吵架；<span class="mention">@80-HD</span> 被种草，准备约老婆去试。

技能退化的隐忧随之而来：<span class="mention">@80-HD</span> 担心 FSD 用多了会不会不再会开车，「跟 agent 用多了就不太会古法编程了一样」。<span class="mention">@细心的熊猫</span> 认为开车是肌肉记忆，像滑雪，一年没滑上雪俩小时又会了；<span class="mention">@稳重的海豚</span> 则诚实认领了编程侧的退化：

> <span class="mention">@稳重的海豚</span>：脑子都不转了。你要现在让我手写这些算法，我写不出来，只能跟你说个大概
