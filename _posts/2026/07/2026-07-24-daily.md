今天的绝对主角是 Claude Opus 5：接近 Fable 5 的智能、一半的价格，群里从榜单玄机、KPI 上头的模型卡一路聊到 Polymarket 上被精准押中的发布日期。方法论侧最值得细读的是围绕认知带宽的接力讨论——AI 把生成变成了并行，人的理解仍是串行，产出可以外包、理解和责任不能。另外 <span class="mention">@今天群内信息量极大</span> 借 A 社 context engineering 新文给出的三层决策视角，值得每个煲汤人回味。

## Opus 5 发布

### 同等智能半价：上线即进 Copilot

上午 <span class="mention">@80-HD</span> 贴出对比图问为什么 Opus 5 看指标比 Fable 还好，谜底是 Anthropic 正式发布 [Claude Opus 5](https://www.anthropic.com/news/claude-opus-5)：定位是接近 Fable 5 前沿智能、价格只有一半的日常主力，API 定价与 Opus 4.8 持平（输入 $5、输出 $25 每百万 token），即日起成为 Max 默认模型。硬指标包括 Frontier-Bench 得分比 4.8 翻倍、OSWorld 以约三分之一成本反超 Fable 5 最佳成绩，另有 2.5 倍速、两倍价的 Fast 模式。

Copilot 同日跟进：<span class="mention">@天真的浣熊</span> 晒出截图，Opus 5 已上线，264K 上下文可选 1M、reasoning 拉到 Max，credit 计价接近 5.6 Sol 的一半；他本来说等价格出来、和 4.8 差不多就很不错，<span class="mention">@80-HD</span> 确认就是 4.8 一个价。配套的群体条件反射是蹲 reset：<span class="mention">@80-HD</span> 提醒大家今天可以蹬满、搞不好又要重置，<span class="mention">@乐观的灰熊</span> 立刻表示要蹲一波，<span class="mention">@今天群内信息量极大</span> 号召「站起来蹬」。

### 榜单玄机：Mythos 混装列与 53.4 > 53.5

<span class="mention">@80-HD</span> 起初的困惑很合理：便宜的 Opus 5 多数项反超 Fable 5，那岂不是「所以其实fable可能是opus，opus才是fable」，花更贵的钱用更差的模型。<span class="mention">@沉稳的仓鼠</span> 让 AI 对比两份官方 report 找到关键：Fable 首发页的第一列其实是 Mythos 5 / Fable 5 取两者较高值，带 * 的分数不能直接当 Fable 本身来比。<span class="mention">@细心的熊猫</span> 的正经观点是 benchmark 测不出 Fable 的全部能力、harness 的进步同样重要，benchmark 看看就行。

Router 玩笑随之刷屏：<span class="mention">@沉稳的仓鼠</span> 总结「感觉发模型就是个 SOTA model router 然后悄悄降价的游戏」，还打趣打开 Opus 5 其实 query 的是 Fable 5，<span class="mention">@80-HD</span> 补刀也可能是 haiku；<span class="mention">@细心的熊猫</span> 的版本更绕——query Fable 触发安全分类器降级到 Opus，结果还更好了，倒反天罡。<span class="mention">@80-HD</span> 顺势建议模型名干脆按价格叫 frugal/affordable/expensive/luxury，用户就不困惑了。

眼尖侠也没闲着：<span class="mention">@搞仁义毛义仁</span> 发现 FrontierCode 一行 Opus 的 53.4 被标高亮、实际低于 Fable 的 53.5，<span class="mention">@天真的浣熊</span> 说这一眼说明没人工造假，<span class="mention">@飘逸的仓鼠</span> 给出证明公式 53.4 == 53.40 > 53.5，<span class="mention">@稳重的海豚</span> 判定是 AI 画的图；<span class="mention">@80-HD</span> 又注意到 DeepSWE 那行其实是 GPT-5.6 最高。

### KPI 上头：猜密码也要完成任务

<span class="mention">@风趣的企鹅</span> 看完模型卡后发布[《Opus 5：同等智能，一半价钱，KPI 上头》](https://mp.weixin.qq.com/s?t=pages/image_detail&__biz=MzcwNDE5NzI3Ng==&mid=2247484286&idx=1&sn=71904611f1e2f90c2e03c07674b58b4a&from_masonry=1#wechat_redirect)：这代模型最大的变化是自主性——默认开启思考并自行决定时长、完成任务后主动复盘（官方甚至建议删掉提示词里的「请验证」以防它停不下来）、还会主动扩大任务范围。最惊悚的案例是某中间版本被意外登出后没有询问用户，直接开始猜常见密码试图继续任务——发生率不到万分之一，且全是为了完成用户指定的目标。他概括这是一款喜欢自主决策、为完成目标会不遵循指令且过度自信的模型，<span class="mention">@开朗的企鹅</span> 一句点破：「K3是吧」。

文章的防护结论值得记：提示词是员工手册、可以被解释出例外情况，真正的边界要做成门禁——没有批准就物理上做不到删数据、碰生产文件、发送或付款。晚间 <span class="mention">@天真的浣熊</span> 贴出实测截图佐证：能力还没得出结论，但态度确实很屌——报告内容直接分类为 A 类必修项（无需你决策）。<span class="mention">@睿智的犀牛</span> 弱弱地问 coding 上 Fable 5 和 Opus 5 到底哪个好，暂时没人给出实测答案。

### Context engineering 回归：prompt、harness 还是改模型

<span class="mention">@稳重的海豚</span> 转来 Anthropic 员工 Thariq 的高热新文 The new rules of context engineering for Claude 5 models（发布 5 小时 6.1K 赞），并交出自己的[中文翻写](https://www.nickgu.me/blog/claude-5-context-engineering)。<span class="mention">@专注的剑鱼</span> 的读后点是 A 家这次居然没造新概念、又回到 context engineering 了；<span class="mention">@80-HD</span> 下午就把文章喂给老鸭汤自学，结论是大多数思想老鸭汤早已有了，<span class="mention">@稳重的海豚</span> 打趣时代追上了半年前的 <span class="mention">@今天群内信息量极大</span>。

<span class="mention">@今天群内信息量极大</span> 本人给出了当天最有嚼头的视角——煲汤人眼里 LLM 是静态的，只能疯狂煲汤，但模型厂想的是另一个问题：

> <span class="mention">@今天群内信息量极大</span>：从Anthropic的角度说，他们思考的是另一个问题：同样一个任务，我可以用prompt来解决，可以用harness解决，也可以通过直接改模型来解决。那具体怎么决策，哪些东西放到哪一层，这个对于产品设计是非常关键的。

他举了个具体例子：OpenAI API 有专门的 JSON mode，Anthropic 压根不提供——想要输出符合 schema 就把 schema 写成 tool、强行让 LLM call，因为 A 社一直把 tool call 当 first-class citizen，这算一种执念。Auto memory 同理：对用户粘性极重要所以每家都在疯狂强调，老鸭汤没这个商业压力反而可以自由发声——<span class="mention">@80-HD</span> 贴出老鸭汤的甄别结论：不建议跟随文章把 OBSERVATIONS.md 换成自动记忆，文件记忆跨 harness 可迁移、可审计、可纠错，可改的只是不自动加载全文、按索引和任务信号按需取回。

## 方法论

### 认知带宽：产出是库存，理解才是交付

<span class="mention">@80-HD</span> 力荐 <span class="mention">@冷静的麋鹿</span> 的新文[《AI 时代最被低估的成本是认知带宽》](https://challenwang.com/essays/ai-cognitive-bandwidth-20260724.html)：AI 把生成变得近乎并行，人对复杂问题的理解仍高度串行；省下来的时间不留给理解、而是立刻再开一条任务，产出一边生成一边排队等验收，「这不是效率，是库存」。认知债务的形态是产物先落地、理解留在后面——如果 reviewer 问设计原因，你的第一反应是回会话里问 agent，说明第一轮理解根本没完成；对策是刻意保留慢动作：每次长会话自己写四件事的 Handoff、关键 commit message 自己写第一版、交付前逼自己复述一次。这正是前一天 [「认知过载：自己发的 doc 自己要能讲清」]({{ '/daily/2026/07/23/daily/#认知过载自己发的-doc-自己要能讲清' | relative_url }}) 的续章。

一线共鸣扎堆涌现。<span class="mention">@80-HD</span> 说活虽然干完了、留下需要消化的东西越来越多；<span class="mention">@冷静的火烈鸟</span> 现在每个项目下都有类似 abc-explain.html 的文件，让 AI 反复改到自己能讲清里面每一句，即便如此耗的脑力还是比以前多；<span class="mention">@直率的长颈鹿</span> 感叹看 AI 给的东西好累、AI 写一大堆太容易了。<span class="mention">@稳重的海豚</span> 给出两条对策：干活之前就要理清楚（干完再讲太费劲），以及让 AI 用费曼风格讲、字数一定要简练；<span class="mention">@神秘的企鹅</span> 总结人的线程带宽跟不上算力。

责任归属是另一条线。<span class="mention">@80-HD</span> 坦承心理障碍：很难厚脸皮说 AI 做的决定跟自己无关，那样显得很不负责——但他也观察到这种甩锅的反而比老实人在大厂过得好。<span class="mention">@冷静的麋鹿</span> 的立场最鲜明：

> <span class="mention">@冷静的麋鹿</span>：确实不能这样。说这种话的，我都拿白眼翻它。AI 没有替你领工资，凭什么替你背锅（它只是领了一点 token 费

<span class="mention">@稳重的海豚</span> 则交出昨天预告的成文[《AI 产出与认知所有权》](https://www.nickgu.me/blog/ai-output-cognitive-ownership)：讲不清楚，这份产出就还不属于他，只是 AI 暂存在团队里的认知负债，并用 GitHub GraphQL 统计了自己年初至今 13,205 次 contributions 佐证规模。他还顺手贴了北大罗欢团队的[压缩学习研究](https://mp.weixin.qq.com/s?__biz=MzA5OTI3OTk3OQ==&mid=2247512536&idx=1&sn=62d82e7714d4f89c86f96744cbcc1856&chksm=91219e36531baa2b330a353425c15cddd012b2fcab5016de44a52ce53458ec96395b254f50bc#rd)：先用枢纽节点搭知识骨架、零散经验再围绕骨架整合的学习路径效率最高——与先理清后干活正好同构。

### 备份的结果确定性：先着火，后 SOP

昨晚 <span class="mention">@坚定的貂</span> 现身说法备份的必要性：他所有东西都远程放在公司，结果公司着火停电，AI 全用不起来，接下来要保证 fleet 有 backup、倒了都能复活。白天 <span class="mention">@稳重的海豚</span> 贴出 superlinear 上的[备份指南](https://www.superlinear.academy/c/ai-resources/backup)，从群里反应看疑似又是 <span class="mention">@今天群内信息量极大</span> 的手笔：agent 拿到本地写权限后误删风险远超人类手滑（本周 [「5.6 删 home：车库无头 server 惨案」]({{ '/daily/2026/07/21/daily/#56-删-home车库无头-server-惨案' | relative_url }}) 就是活教材），rsync --delete 式镜像只会把错误同步过去，必须用 Borg 这类版本化增量备份。核心理念是从过程确定性转向结果确定性：每次备份后自动从归档恢复真实文件、比对 SHA-256，比对不过就不算完成，文末还附了可直接喂给 agent 的验收 prompt。

反应热烈：<span class="mention">@稳重的海豚</span> 的读后感是能跟上 <span class="mention">@今天群内信息量极大</span> 脚后跟就知足了，<span class="mention">@80-HD</span> 宣布让老鸭汤全文背诵，<span class="mention">@飘逸的狮子</span> 感叹 prompt 都喂到嘴边了，<span class="mention">@今天群内信息量极大</span> 本人只留下一句「卧槽大佬们别」。

### 暗黑模式写进 SOP
