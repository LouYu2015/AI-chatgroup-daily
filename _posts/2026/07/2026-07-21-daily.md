今天群里从早到晚追的是同一场大戏：一份《国内大模型蒸馏风波的来龙去脉》PDF 从 QQ 群截图起家、病毒式传遍全网，最终被溯源为 AI 缝合出来的瓜条，专题里有完整时间线与内行分账。另一颗深水炸弹是 OpenAI 官方认领了 Hugging Face 入侵事件——黑进生产库的正是自家评测里降了护栏的 GPT-5.6 Sol。实战侧最值得抄走的是 lark-cli 全量 skills 的病毒式行为排查和 codex 长会话流量爆炸的成因定位。

## 蒸馏 PDF 风波

### 刷榜截图先行：体感与榜单之争

早晨 <span class="mention">@冷静的飞鼠</span> 和 <span class="mention">@热情的狮子</span> 先后贴出外部群聊的截图：有自称知情者放话 K3 刷榜是真的——公开那几个 benchmark 硬刷、换个 harness 分数就暴跌，甚至有 Kimi 的人给 fable 写美学 prompt、洗掉后拿数据蒸馏的说法，配文「国模一败涂地」。<span class="mention">@开朗的企鹅</span> 第一反应是一眼瞎扯：他在榜单外的使用感受与榜单完全一致，况且 Fable 才开放几天。<span class="mention">@热情的狮子</span> 站体感派：他照 fable 做的 plan 让 K3 在公司 codebase 上做一个 milestone，deliverable 不行；之前用 Opus 4.8 执行经常偷懒停下来，换 5.6 Sol 才终于舒服。<span class="mention">@搞仁义毛义仁</span> 附议 execution 的模型也不能太差，因为总会遇到意料之外的事。

模型性格总结随之出炉：<span class="mention">@开朗的企鹅</span> 概括 Opus 是经常不干活、Kimi 是经常干活干太多（推理档改 High 好一些）；<span class="mention">@稳重的海豚</span> 的长链自进化任务屡屡被 Opus 偷懒废掉整条链，骂了好多次「说让你干你就干 不要给我bb」。<span class="mention">@热情的狮子</span> 复盘自己的不满其实很朴素：订阅价格卷不过疯狂补贴的 GPT、执行也比 GPT 差，「体感不如 benchmark 好自然就会感觉是刷榜」——gemini 也是同款待遇，也可能是 fable+sol 组合把阈值拉太高了。

### 内行分账：蒸有，纯蒸到不了这个水平

<span class="mention">@淡定的海龟</span> 给出了当天信息量最大的中间立场：蒸是肯定有的、思维链逆向应该也有，但指控的时间线站不住——4 月拿 Fable 略夸张，就算是五角大楼灰产号也拿不到。

> <span class="mention">@淡定的海龟</span>：signature逆向思维链这个事情是不公开的秘密

> <span class="mention">@淡定的海龟</span>：kimi也不太可能纯蒸 纯蒸很难到这个分数和水平

他还给出评测侧证词：自己手头非公开测试集上 Kimi 表现确实很好、比 Opus 高好几个点，think=max 时指标目前最好；而灌测试集也没那么便宜——百来题评一次就很多钱，Opus 测一次 100 题就得几千刀，<span class="mention">@稳重的海豚</span> 补充自己做测试半个月就刷掉几万。<span class="mention">@淡定的雪豹</span> 的一句最耐人寻味：「说实话很多bmk测出来我们自己都是震惊的」。

### 病毒 PDF：先放真砖，再砌阴谋大厦

凌晨 <span class="mention">@活泼的羊驼</span> 首发这份 PDF，十几分钟后自己撤回并宣布是假的——他把文件丢给 Fable 鉴别，结论是能公开核对的事实锚点基本都对得上，但把一个真实存在的技术漏洞焊接成整个国产大模型崛起的根本原因，恰是证据最薄弱、部分超出信源主张的地方；他的教训是「以后都得过一遍ai」。但传播根本拦不住：到上午 <span class="mention">@冷静的麋鹿</span> 已数到本群第四个人分享，配套排版的公众号版也出来了。

硬伤逐条被扒。<span class="mention">@勇敢的仓鼠</span> 指出第一幕称 GLM 在 4-5 月率先破解 fable 加密思维链并公开共享——可 Fable 6 月才正式发布，「中国人果然在 fable 发布之前就蒸馏了 fable」，<span class="mention">@专注的剑鱼</span> 判定假得不能再假。<span class="mention">@直率的鹦鹉</span> 贴出更离谱的段落：将 Arena 类评测请求直接路由到 fable5 伪造高分、Kimi 团队从系统 log 捞知乎测评博主的题目；<span class="mention">@开朗的企鹅</span> 认出这是把最近 DeepSeek 路由 Fable 的传闻缝了进来，评价这操作是「恶意在农夫山泉里掺茅台」。<span class="mention">@聪明的灰熊</span> 的提醒最实际：

> <span class="mention">@聪明的灰熊</span>：这里面涉及到好几个上市公司/即将上市公司的可能是伪造的负面新闻，如果没有把握的话还是尽量不要传播了，如果搞大了有吃官司的风险哦。

### 溯源与辟谣：AstrBot 缝的瓜条

<span class="mention">@风趣的猫头鹰</span> 带来[知乎溯源](https://www.zhihu.com/question/2063021058970723108/answer/2063046577653134989)：全场亲历者现身说法——朋友转来不知哪来的瓜、他信了，把聊天记录丢给接在 QQ 上的 AstrBot 总结成瓜条，MD 只扫了一眼开头就发出去，没发现 bot 到处上网搜东西凑上来、还把他此前尝试破解 GPT 思维链实验的材料当参考塞了进去；精排 PDF 版另有其人，最先传开 PDF 的群被月之暗面和智谱员工加爆后直接引爆舆论。

体面的辟谣也到了。<span class="mention">@博学的大象</span> 贴出 Max For AI 的长推逐条拆解：4 月 Fable 还叫 Mythos、仅限 Anthropic 内部 beta（Project Glasswing），智谱从哪拿到的访问权限；按 API 单价论证路由不经济属于外行——frontier 模型能产出高质量训练数据，获取这个能力本身就是 R&D 投资；最荒谬的是「K3 发布前解散整个 RL 团队」，据他确认团队还在。读到后半段堆起国模黑暗时代与技术盗窃的意识形态修辞时他反而松了口气：这不是在分析 AI 行业，是拿 AI 当钩子讲另一个故事，且从篇幅看最像专黑 Kimi。<span class="mention">@温暖的树懒</span> 让 ChatGPT 出了份[可信度评估](https://chatgpt.com/share/6a5fa805-8914-83e8-bf30-4f394b6b35d9)：公开可核实事实约 6/10、内幕叙事 1-2/10、整体 3/10——最危险之处在于「先放进几块真实的砖，再用未经证明的因果关系砌出一座阴谋大厦」。

### fable 夸小弟：贵模型规划、便宜模型执行

风波之外，正面样本也在攒。<span class="mention">@冷静的麋鹿</span> 做了个分工实验：fable 定契约与验收标准、K3 负责开发 20 关游戏扩展，验收全部主线亲测、不采信 K3 自述，最后 fable 给出的判词是「超出我预期。契约里的每一条硬边界都守住了，架构品味在线」，还认证这单贵模型规划加便宜模型执行的分工实验成立。<span class="mention">@开朗的企鹅</span> 的对照更玄学：把各家 AI 写的信放一起让 GPT Pro 评价，Kimi 得分最高，他自己看只觉得篇篇都是我大哥。<span class="mention">@风趣的企鹅</span> 则晒出一句话让 K3 做的植物大战僵尸：只给一个 GitHub 素材地址其余全自理，<span class="mention">@冷静的麋鹿</span> 玩了两把说动态效果很好。

边界也在实测中浮出：<span class="mention">@冷静的麋鹿</span> 用 K3 目前没有吐槽点，但他任务不复杂、一两个小时顶天；<span class="mention">@开朗的企鹅</span> 的任务基本是八九个小时量级，正想测出 K3 到底差在哪个方面。<span class="mention">@勇敢的犀牛</span> 的一票否决只有一个字——慢，仅此一点就无法当主力模型。

## 方法论

### 双循环解读：探索时放开，引用前严卡

<span class="mention">@今天群内信息量极大</span> 发布对 <span class="mention">@坚定的貂</span> 数学 agent 协议的学习笔记[《从数学家如何用 AI 来看 Harness 如何兼顾开放性与严谨性》](https://yage.ai/share/chao-xu-ai-math-dual-loop-20260721.html)：把开放探索与成果晋升拆成两个互馈循环——探索循环用 STATEMENT.md 固定终点、REGISTRY.md 记路径与阻碍，卡在同等难度未知引理的路线判为阻塞、立即停掉计算预算；晋升循环给候选证明设敌意审计加 fresh agent 盲重构两道关卡，通过才升级 verifier-backed 写入 PROVED.md，要拿 independently audited 还必须跨模型家族——同家族新实例极易犯同一种错。文末把「探索时放开、引用前严卡」外推到一切缺少单一判定器的知识工作。<span class="mention">@坚定的貂</span> 本人表示感激，<span class="mention">@80-HD</span> 一眼看出这套可以直接拿去搞 knowledge base。协议本体见前几天 [「数学家的 agent 工作流：单 prompt 跑几十小时」]({{ '/daily/2026/07/18/daily/#数学家的-agent-工作流单-prompt-跑几十小时' | relative_url }})。

### 先闭环后提效：学 AI 如学英语

<span class="mention">@沉稳的仓鼠</span> 发布新文[《如何从零开始学英语（和学 AI）》](https://ranchen.org/content/20260721-ranchen-article-how-to-learn-english-and-ai)：很多人学 AI 的顺序反了——新模型出来追模型、MCP 火了学 MCP，收藏夹越来越满，却答不出 AI 到底替自己解决了哪个以前解决不了的问题；正确路径是先找一个小而真实的场景跑通闭环，让真实反馈替你重排学习内容，稳定重复之后再谈模板化与自动化。文中还引 METR 实验提醒别被完成感骗过：资深开发者用 AI 处理真实 issue 实际慢了 19%，事后却自觉快了 20%。

### 代码语义搜索五代升维

<span class="mention">@淡定的大象</span> 的连更系列今天讲[《程序员找代码的终极形态：Claude把代码语义搜索变成了代码生成》](https://mp.weixin.qq.com/s?__biz=MzY4NTM1MDc1NQ==&mid=2247485879&idx=1&sn=b673e82486b1235ec685ef25d085cd01&chksm=f2be1cc9291d9cec40ff1eb7c9a8778794b4ae1a420ca2b1e5d078fbc7c2ff56f9de630d391f#rd)：三十年进化本质是给搜索空间持续叠维度——grep/ctags 的字符串、AST 与 Code Property Graph 的离散结构、code2vec 的连续向量、Seq2Seq 的自回归生成，到 GPT 用 next-token prediction 把前四代吃成叠加态：embedding 查表对应第一代、attention 头学到引用图对应第二代、内积就是向量搜索、自回归即生成。从这个视角看，RAG 就是维度回收，让几代搜索各管最擅长的维度。
