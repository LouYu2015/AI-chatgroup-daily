今天最值得读的是 <span class="mention">@活泼的羊驼</span> 领读的 Lenny × Boris 播客——Claude Code 从内部两个赞长成全球现象的完整复盘，underfund 原则的原始出处也在其中。<span class="mention">@冷静的飞鼠</span> 发表 ChatGPT Ads 深度分析，核心判断是 agent 天然与广告模式互斥。群里还爆发了一场超级个体 vs 超级团队的辩论，Overcooked 意外成了终极检验标准。

## 方法论

### Boris 播客领读：两个赞到全球爆发

<span class="mention">@活泼的羊驼</span> 分享了 [Lenny × Claude Code 负责人 Boris 的播客领读（第一篇）](https://mp.weixin.qq.com/s?__biz=MzU4MTgxOTE2OQ==&mid=2247484763&idx=1&sn=456f4a13e50c758a2a45cadee65eb413&chksm=fc5d19c4387f08db69c9cd71bcdda2abaa8ecfcbf7960bda1908aef831ab9578483d86165d2e#rd)，并贴出大量截图逐段解读。几个最打眼的数据点：Claude Code 内部官宣帖只拿到两个赞；Boris 从去年 11 月起没亲手改过一行代码，每天提交 10–30 个 PR；Anthropic 工程团队扩大约四倍，但按 PR 计人均产出提升 200%。

文中找到了 underfund 原则的原始出处（前情 [「XMind 圈子制与 underfunding」]({{ '/daily/2026/08/28/daily/#xmind-圈子制与-underfunding' | relative_url }})）：故意少配资源、有时一个项目只放一个工程师，token 给够——倒逼团队把工作「Claude 化」。Boris 还提到 Cowork 诞生于看到用户拿 Claude Code 干各种非技术事务，团队花 10 天完全用 Claude Code 做出了桌面应用。在训练层面，编程之外的训练也能通过迁移效应提升编码能力——「你教模型学会 X，它在 Y 上也会变好」。

<span class="mention">@活泼的羊驼</span> 评论，Boris 反复强调的认知重建——不要停留在旧模型的认知里，新模型是另一个物种——与 <span class="mention">@冷静的飞鼠</span> 和 <span class="mention">@今天群内信息量极大</span> 此前的观点完全一致。<span class="mention">@冷静的飞鼠</span> 赞赏官宣帖两个赞这个细节。<span class="mention">@稳重的海豚</span> 看完准备出 newsletter 抢先蒸馏。

> Boris：我们从一开始就押注为六个月后的模型而构建，而不是为今天的模型而构建

### Coding 两维 Sigmoid 接力

延续昨天的讨论（[「Coding 增长经济学」]({{ '/daily/2026/08/30/daily/#coding-增长经济学' | relative_url }})），<span class="mention">@活泼的羊驼</span> 补充了一个两维 Sigmoid 增长框架。第一维是用户渗透率，几个月前已达 50%，sigmoid 导数正在拐点。第二维是人均 token 用量，仍处早期——全美企业 AI 支出中位数为每人每月 12 美元，远期有望达到白领工资的 10%（约 1000 美元/月），中间还有近两个数量级的空间。

当前增长主要由第二维的指数级攀升驱动，两条 sigmoid 曲线接力上行。他认为这在历史上罕见，也是半导体超级周期的底层支撑。<span class="mention">@搞仁义毛义仁</span> 不以为然：一旦 AI 满足大多数人的娱乐需求并被蒸馏成开源模型，大家只买低价 host token，前沿实验室的研发费用不再有人买单。<span class="mention">@搞仁义毛义仁</span> 自曝上个月消费甚至没超过 100 美元。

### 模型分工与性格论

<span class="mention">@稳重的海豚</span> 提出了一套模型角色框架：Codex 是搬砖工，Fable 负责 brainstorm（非工程类工作），Gemini 是写手——所有对外内容必须调用 Gemini 写，Claude 则是一个不听话、喜欢发散思维的员工。

<span class="mention">@活泼的羊驼</span> 做法恰好相反——用 Opus 写代码、Codex 做 review，因为 Codex 写 Go 动不动 over-engineer。<span class="mention">@热情的狮子</span> 指出比起 over-engineer，Claude 偷懒忘事更令人抓狂，还有事没事来一波向上管理。<span class="mention">@稳重的海豚</span> 精辟总结：over-engineering 是作风问题好解决，偷懒是态度问题不好解决。

<span class="mention">@天真的浣熊</span> 补了一剂猛药——Opus 5 不是忘记规则，而是明知故犯：「我知道这事，但我就是不做。我不要你觉得这事要做，我要我觉得。」他建议先让模型 over-engineer，再 refactor 简化，比对抗态度问题省力。

### 超级个体不需要超级团队

<span class="mention">@开朗的企鹅</span> 提了一个尖锐问题：为什么现在还没有受欢迎的小团队级 agent？herdr 这类工具似乎只服务于超级个体。

<span class="mention">@神秘的企鹅</span> 推荐了一篇 [《为什么超级个体不需要超级团队？》](https://mp.weixin.qq.com/s?__biz=MjM5OTE0ODA2MQ==&mid=2650998445&idx=1&sn=1de093a9df34b6584181c11e46a32b82&chksm=bd70d9d2ba01c47ec8b6b45d6030229d9d4a1eada927675f6d8a4c69744c48c8254b941fc013#rd)，核心论点是社会惰化加上个体判断差异，使得能力并联但风险串联。<span class="mention">@80-HD</span> 从实战角度佐证：试过给团队引入老鸭汤，需要整个团队认知和行动力保持一致，最后发现还是超级个体自己干效率高。

<span class="mention">@搞仁义毛义仁</span> 用 Overcooked 做比喻：默契的人 1+1=4，合作不了的结果极糟，而这种默契需要准确预判队友行为动机，不是制度能解决的。<span class="mention">@神秘的企鹅</span> 切入更深一层——不是共享 context 就能同频，每个人对同一个 context 的判断和执行节奏完全不同，尤其现在跟 AI 交流太丝滑，显得人与人之间带宽太低。

> <span class="mention">@神秘的企鹅</span>：人和人太难对齐了。不如放弃，多跟 AI 对齐，每个人都跟自己的 AI 对齐，然后听一听别人的，大家互相交流一下，发散一下

### 跨模型互审与 Triage

<span class="mention">@坦荡的灰熊</span> 建议用不同模型互相 review 代码——哪怕用 5.5 去 review Opus 5 都有不错效果。<span class="mention">@热情的大象</span> 确认：一个模型再强，其他模型也能 review 出问题来。

<span class="mention">@80-HD</span> 补充关键约束：review 要按严重程度分级，只管重要的，否则就会陷入 bike shedding。<span class="mention">@搞仁义毛义仁</span> 进一步提出 review 之后还要 triage，不要什么都自动 P0。<span class="mention">@坦荡的灰熊</span> 则指出一个先有鸡还是先有蛋的难题——没有老鸭汤，模型怎么知道什么该管什么不该管？

### Context 加载与子代理延迟

<span class="mention">@坦荡的灰熊</span> 问老鸭汤在项目中怎么使用。<span class="mention">@稳重的海豚</span> 建议改 agents.md 引导加载。<span class="mention">@敏锐的海狸</span> 分享了他的 Claude 文件夹结构：core 目录下放 SOUL.md（工作姿态）、USER.md（用户画像）、COMMUNICATION.md（交互风格），rules 和 axioms 各有 INDEX.md 索引，在每个新 session 的第一条消息时读取。

<span class="mention">@80-HD</span> 泼冷水：Claude 根本不读这些文件，「一骂就是对不起我忘读了，我现在读」。<span class="mention">@搞仁义毛义仁</span> 称之为「人工渐进披露」。

<span class="mention">@坦荡的灰熊</span> 另做了一次子代理性能测试：创建到 READY 约 39 秒，主代理 ping-pong 一次约 28 秒，端到端合计 67 秒。结论是几十秒以内的小型检索直接处理更划算，子代理更适合并行消化一分钟以上的大范围读取任务。

### Claude Code 走神处方

<span class="mention">@严谨的灰熊</span> 吐槽 Claude Code 做 task plan 做了一半就停工，上去问 progress 立刻醒来继续，然后不知什么时候又停了。<span class="mention">@稳重的海豚</span> 开出处方：设置 heartbeat 每 5 分钟自动发 continue，让它自己去跳就好了。

## 行业新闻

### ChatGPT Ads 年化破 10 亿

<span class="mention">@冷静的飞鼠</span> 发表了 [ChatGPT Ads 深度分析](https://www.superlinear.academy/c/news/chatgpt-ads-chatgpt-b64f1dd2-6e8d-4aaa-885c-96900f0a6618)（[英文版](https://x.com/sunyuzheng/status/2094531829542113485)）。ChatGPT Ads 上线不到 200 天，年化 run rate 达 10 亿美元，是 OpenAI 历史上最快达到该里程碑的产品，已有数万广告主覆盖 40 多个国家。

文章核心论点是 agent 天然与广告模式互斥：传统广告靠用户浏览、搜索、比较、点击这些尚未完成的步骤出售影响力，而 agent 的价值恰恰在于压缩甚至消灭这些环节。虽然 ChatGPT Ads 完全可能做到百亿美元级，但 OpenAI 最高质量的收入更可能来自 apps、tool calls、completed transactions 和可验证 outcomes——在中立决定之后为成功行动结算，而不是在决定之前购买进入候选集的概率。

### Instinct 内测估值 25 亿

<span class="mention">@稳重的海豚</span> 分享了一篇 [Instinct 深度分析](https://mp.weixin.qq.com/s/g7CDDOJ_OtCvlV0MWpHbpQ)。这款个人 AI 助理还在邀请制内测阶段，B 轮融资 2.5 亿美元、估值 25 亿美元，创始人只有 23 岁。产品通过短信或电话交互，能连接邮箱、屏幕和位置替用户行动，但早期测试者已报告未经确认就发邮件、断开权限后仍继续读取邮箱等问题。

### 思路罗盘 ThoughtOS

<span class="mention">@务实的长颈鹿</span> 发布了休假期间做的 [思路罗盘](https://github.com/bubuqian/thought-os)——本地优先的 AI 思路工作台，核心理念是「AI 可以换，思路不会断」。它把散落在对话、资料和文件里的讨论、判断与成果汇入同一条持续生长的主线，AI 可以提出修订建议，但只有用户确认后才写入思路版本。支持 Windows x64 和 Apple Silicon macOS，解压即用无需安装依赖。

### Office 引 React Native 的代价
