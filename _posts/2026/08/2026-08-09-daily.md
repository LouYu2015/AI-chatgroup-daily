今天最热的讨论是腾讯 DMCA 下架微信数据工具 Chatlog Alpha——连纯 DB 解密的 fork 都未能幸免，群友围绕替代方案和数据归属争论了一个小时。硬件角度值得关注的是 170hx 矿卡解锁 80G 显存只要 8000 块，本地推理玩家集体心动。

## 行业新闻

### Chatlog Alpha 被腾讯下架

<span class="mention">@今天群内信息量极大</span> 发现微信数据解密工具 [Chatlog Alpha](https://github.com/teest114514/chatlog_alpha) 被腾讯以侵权投诉从 GitHub 下架，核心代码已转移至俄罗斯平台 gitflic.ru，版本更新改走 Telegram 频道。项目同时移除了所有消息发送与自动化功能，退回纯粹的本地数据读取与解密工具。

<span class="mention">@今天群内信息量极大</span> 分析触发点在于 scope 扩大——开始支持发消息后进入了腾讯反外挂的视线。但 <span class="mention">@热情的狮子</span> 反驳说即便是纯 DB 解密的 fork 也被 DMCA 了，感叹腾讯「罪恶滔天」。<span class="mention">@今天群内信息量极大</span> 追问这是否违反 GDPR，随即自嘲「前朝的剑斩不了清朝的官」，<span class="mention">@机智的荷兰猪</span> 接梗称 GDPR「这都是历史文件了」。

<span class="mention">@风趣的长颈鹿</span> 推荐了替代工具 wechatdataanalysis，可以不开微信客户端直接解密，还能备份数据库。难点仍然是搞密钥——同一账号在 Mac 和 Windows 上的 key 不同，Mac 功能也不如 Windows 全面。

讨论延伸到微信数据留存机制。<span class="mention">@搞仁义毛义仁</span> 提到 Windows 微信容易丢失软件未运行时收到的群聊，<span class="mention">@热情的狮子</span> 确认这是 by design 而非 bug。<span class="mention">@开朗的企鹅</span> 解释背后是 72 小时保留机制——超时未打开就永远收不到了。

## 工具

### 170hx 矿卡：8000 块买 80G 显存

昨晚 <span class="mention">@坦荡的灰熊</span> 贴出一张二手交易截图：170hx 矿卡 10G 版本解锁后可获得 80G 显存，售价 ¥8000 包邮。PCIe 2.0 已解锁并补了电容到 x16，卖家称可稳定运行千问 3.6-27B，最新驱动已支持 Windows。<span class="mention">@幽默的犀牛</span> 惊呼比 5080 便宜好多，<span class="mention">@细心的熊猫</span> 连说买买买。结合此前的本地推理配置讨论（前情 [「本地 Qwen 27B 与 sglang 多卡」]({{ '/daily/2026/08/08/daily/#本地-qwen-27b-与-sglang-多卡' | relative_url }})），80G 显存的矿卡对本地模型玩家性价比相当诱人。

### OpenCode Flash 的续航

<span class="mention">@开朗的企鹅</span> 贴出 OpenCode 创始人 dax 的推文：决心成为地球上最便宜的 AI 提供商，展望 AI 读取每个 console.log、处理视频每一帧、检查每个心跳异常的未来。<span class="mention">@务实的灰熊</span> 从实操角度佐证——用 GLM 煲几轮老鸭汤就把周额度烧完，换成 Flash 煲几轮下来进度条几乎没动。

### i18n 漏组件的几个思路

昨晚 <span class="mention">@稳重的海豚</span> 抛出实战痛点：做 i18n 总是漏掉一些 UI 组件。群友给了三条路线：<span class="mention">@沉稳的仓鼠</span> 建议让 Codex 截图自己去看，<span class="mention">@飘逸的浣熊</span> 提议搞个 linter，<span class="mention">@搞仁义毛义仁</span> 则认为根本解法是 UI 定义文件上不要出现文字——21 世纪的 UI 库应该在机制上就支持多语言。

## 方法论

### context-infra：三次才升公理

<span class="mention">@飘逸的狮子</span> 感叹每天都在感受老鸭汤的价值，晒出 context-infra 模块的一次触发记录：它捕获了一条关于视频内容不能假设 post 文案存在的经验，但只追加为 observation，没有直接提升为规则——还没达到跨三次情境晋升 axiom 的门槛。这展示了一种 AI harness 的记忆管理模式：单次经验先低保存，反复出现才升级为硬规则，避免过度泛化。
