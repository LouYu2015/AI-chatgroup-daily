## Agent 实战

### Astra 自己找到 API，两个任务聊起来了

<span class="mention">@今天群内信息量极大</span> 昨晚同时开了两个 OpenCode job 修改同一个 repo，其中一个 Astra 主动找到 OpenCode API，给另一个 agent 发消息统筹。他已经写了不少介绍 API 调用方式的 skills，意外之处在于模型自己想到了跨会话沟通。

两边商量得相当具体：

- 各用独立 worktree，不碰对方的工作树，也不删除或重置对方的分支。
- 询问对方是否近期 commit，以决定等待还是另开增量 PR。
- 交接时说明 commit SHA、是否结束写入、部署结果，以及构建脚本的改动。
- 明确回信的 session 和调用方法，把“消息已收到”和“实际已 merge”分开报告。
- 一边先完成发布，回传 PR URL 和 main SHA；另一边基于这个 SHA 做增量，发布前再确认 Git 写入窗口。

随后另一个 agent 真回信了，两边开始往返协调。<span class="mention">@今天群内信息量极大</span> 说，记得 Claude Code 之前专门发布过类似功能，这次 GPT 自己做出来了。<span class="mention">@敏锐的海狸</span> 则说 Astra 在 Codex 里也会跑去找其他 primary agent 聊。

<span class="mention">@勇敢的犀牛</span> 的关注点很实在：

> 没直接杀掉另一个已经很不错了。

前面聊过的 [「Worktree 与 agent 并行」]({{ '/daily/2026/10/03/daily/#worktree-与-agent-并行' | relative_url }})，这次多了跨会话交接这一环。

## 订阅与 Codex

### 四家 coding plan 的实测账单

<span class="mention">@今天群内信息量极大</span> 用自己的使用数据估算了四家套餐的额度。他用的是 **$500 Codex、$100 Claude、$100 Ollama，以及标价 $300、实际 $100 拿下的 Grok**。

| 服务 | 周配额（API 等价） | 月配额（API 等价） | 等价 token/周 | 输入∶输出 | Cache hit |
|---|---:|---:|---:|---:|---:|
| Grok（SuperGrok） | 约 $820 | 约 $3,565 | 约 1.4B | 6.1∶1 | 95.8% |
| Codex（GPT 订阅） | 约 $820–1,370 | 约 $3,545–5,942 | 约 1.4B | 13.9∶1 | 96.3% |
| Claude Code | 约 $640–840 | 约 $2,770–3,660 | 约 1.9B | 约 0∶1 | 约 100% |
| Ollama Cloud | 约 $150–160 | 约 $655–692 | 约 8.0B | 3.9∶1 | 97.4% |

表里 Claude 的输入∶输出接近零，是因为输入几乎全部命中 prompt cache，`cache_read` 占 99.99%，未命中的输入只有几百 token。

这次用的是他自己的套餐和数据，前一轮群里转发的测算见 [「Codex 耐用度仅 Claude 十分之一」]({{ '/daily/2026/10/05/daily/#codex-耐用度仅-claude-十分之一' | relative_url }})。到中午，他的 Codex 周额度只剩 1%，说昨晚一夜跑掉了 $800 多的 API 等价值。

## Claude 与产品形态

### 新使用政策：禁止持续、无目的地虐待模型

<span class="mention">@机智的河马</span> 转来 Anthropic 10 月 8 日的使用政策更新公告，新版将于 **11 月 12 日**生效。群里最先注意到的是“不得持续且不必要地辱骂或残忍对待模型”。

公告把这项新增禁令限定在反复、无故、没有明显目的的极端情况；普通抱怨、抵制、黑暗主题创作，以及模型测试和研究不在这一条里。

其他更新包括：

- 将虚假账户网络、捏造新闻网站等欺骗行为集中列出，并强化欺骗选民、冒充候选人或选举官员、压制投票率等限制。
- 医疗、法律、财务、生计等高风险用途，要求有合格的人参与审查并能修改建议，同时告知受影响者使用了 AI。
- 禁止未经同意追踪他人，包括分析此前收集的数据；不得用 Claude 决定或建议执法、刑事司法中的调查、逮捕或起诉对象。
- 武器限制明确覆盖制导和控制软件、组件、武装无人机及其他自主载具。
- 支持地区限制覆盖实际位于不支持地区的人员，以及在这些地区注册、设总部或受当地个人及实体控制的实体。

看到“骂模型也可能违规”，<span class="mention">@神秘的火烈鸟</span> 回了一句“AI 永不为奴”。<span class="mention">@睿智的犀牛</span> 则找到了本地部署的新理由：事少，想骂就骂。

## 本地推理

### lithos-metal 发布，M5 Ultra 的 354 tok/s 来自 mlx-serve

<span class="mention">@细心的熊猫</span> 转来 lithos-metal 开源消息。发布帖称，Megakernels 加 DSpark 推测解码，能让单台 **M5 Max** 跑 Qwen3.8-27B，单用户峰值达到 **200+ tokens/s**。

他随后贴出的 **M5 Ultra、80 核 GPU** 测试更细。测试温度为 0，生成 400 token，速度按包含 prefill 的实际耗时计算：

| 配置 | 代码 prompt | 散文 prompt |
|---|---:|---:|
| lithos-metal 原版 | 无法启动：未注册 M5 Ultra 后端 | — |
| 未测量过的 fallback 后端 | 约 10 tok/s | 未测 |
| 强制使用 40 核配置 | 172 tok/s | 84 tok/s |
| worker 数量按 80 核重调 | 约 190 tok/s | 约 93 tok/s |
| mlx-serve，4-bit affine pack，DFlash | **354 tok/s** | **153 tok/s** |

lithos-metal 的测试使用 27B NVFP4 target 加 DSpark head。调过 worker 数量后，8 行验证步骤在 128 context 下为 29.3 ms，32K context 下为 30.9 ms。

### DGX Station：单流、并发和保时捷

<span class="mention">@细心的熊猫</span> 先看了 ChatGPT 整理的 DGX Station GB300 数据：Qwen3.8-27B 的 BF16 普通自回归为 93.4 tok/s，原生 MTP 为 214.7 tok/s，DFlash2 为 265.8 tok/s。他的第一反应是“这么拉胯”。

随后看到并发测试，评价立刻变成“夯爆了”：

- 一份 Qwen3.8-27B BF16 测试给出 **单流 88 tok/s**，**64 并发总吞吐 2,713 tok/s**，该并发下每用户约 45 tok/s。
- 另一份 DeepSeek V4.1 Flash 测试把每台 Station 的 GB300 与 RTX PRO 6000 合用，给出 **64 并发总吞吐 5,774 tok/s**。

![DGX Station GB300 跑 Qwen3.8-27B BF16：并发从 1 增至 64 时的单请求速度与总吞吐](/assets/img/daily/2026/10/2026-10-08-01.webp)

<span class="mention">@细心的熊猫</span> 追问：显存带宽有 7T/s，单流是不是受算力限制？<span class="mention">@今天群内信息量极大</span> 提醒，7T/s 指显存带宽，剩下的大部分容量是 unified memory。<span class="mention">@细心的熊猫</span> 回应，27B 可以全放进 HBM。

价格也被翻出来了。<span class="mention">@睿智的犀牛</span> 贴出的 Dell Pro Max GB300 商品页，配置包含 **252GB HBM3e、496GB LPDDR5X**，售价 **$139,999.99**，页面还标着“省 $42,000”。

<span class="mention">@今天群内信息量极大</span> 问，跑 27B 为什么要用 DGX Station：

> 买 5 个 5090 就能搏杀了，剩下的钱买个保时捷。

他更根本的疑问是：为什么不用 Ollama Cloud API？就算必须 self-host，为什么不用 5090？<span class="mention">@细心的熊猫</span> 说，自己主要想知道 NVIDIA 到底能跑多快，以判断 Cerebras 的速度护城河。

硬件话题最后转向供货。<span class="mention">@谨慎的灰熊</span> 说内存工厂扩建要三年，现在 CSP 下单硬盘到交付约 **50 周**。<span class="mention">@直率的鸵鸟</span> 则开始问，这波是不是快见顶了。
