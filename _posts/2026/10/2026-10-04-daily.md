## 工具

### Firecrawl 与 Tavily 搜索成本拆解

<span class="mention">@今天群内信息量极大</span> 发现 Firecrawl 两天烧了两万 credit，追查后锁定两个成本陷阱：X/Twitter 推文每条收 30 credit，命中五条就等于 150 次普通搜索；PDF 按页收 1 credit，他不幸命中一个 100 页的文档，一次就亏了一大笔。Tavily 搜推特和读 PDF 都不额外收费。他一度觉得 Tavily 好像也没那么贵了，但用真实流量做了交叉定价后，日常以 HTML 搜索和抽取为主的工作里，Firecrawl 仍然更省钱：

| 场景 | Firecrawl (Standard) | Tavily (Bootstrap / Growth) |
|---|---|---|
| 7 天 HTML 为主（780 search + 30 extract） | ~$3.5–4.1 | $8.0–10.7 |
| 2 天混合（221 search + 164 extract） | $1.6–2.2 | $3.9–5.2 |
| 单条推文抽取 | 30 credit | 不额外收费 |
| 单页 PDF | 1 credit | 不额外收费 |

结论很直接：以 HTML 搜索/抽取为主选 Firecrawl 省一半以上，但一旦开始大量读 PDF 或推文就翻车。他还纠正了此前的误解：Tavily 其实也能搜 Twitter，不额外收费。<span class="mention">@风趣的海豚</span> 另外建议，如果只是搜推特内容，直接用 X 的 API 更便宜。

<span class="mention">@认真的狮子</span> 问到 DataForSEO，<span class="mention">@今天群内信息量极大</span> 回应：自己有 key，但 DataForSEO 更偏 SEO 关键词分析（搞清楚大家在搜什么），与他需要的 SERP 搜索引擎 API 用途不同。这组成本对比延续了上周的 [「Firecrawl 搜索 Skill」]({{ '/daily/2026/09/29/daily/#firecrawl-搜索-skill' | relative_url }})。

### Agentic Engineering 第五讲公开

<span class="mention">@稳重的海豚</span> 发布了哥伦比亚大学 COMS W4995 第五讲 [Agent Tools in Pictures](https://course.nickgu.me/materials/lecture-05/) 的电子书，主题是 agent 到底需要哪些工具。内容从 1984 年远程调用讲起，区分工具协议中哪些是四十年的老问题、哪些只是时代包装，涵盖 tool 定义与执行拆解、function / shell / skill / MCP server / 代码五种能力交付方式的取舍、工具过多为什么反而更糟，以及信任边界画法。目前做了一半内容，群友觉得 AI 味不浓。

他同时分享了 [asd-ste100-skill](https://github.com/danyuchn/asd-ste100-skill)，一个将英文改写为 ASD-STE100 简化技术英语的 Claude Code skill。这套标准原本面向航空维修手册（一词一义、主动语态、一句一指令），但这里的「读者」换成了解析 tool description 和 error message 的另一个 LLM，同样没有回问的通道，对歧义零容忍。Skill 分两档：Strict 用于流程和 tool description，STE-flavored 用于 README 和 PR 描述，自带确定性 linter 做结构性检查。前天的客座讲座（[「做出来不等于学会」]({{ '/daily/2026/10/03/daily/#做出来不等于学会' | relative_url }})）是这门课的特别场，这次是正课教材。

## 方法论

### 科技公司 IPO 消亡之辩

<span class="mention">@细心的熊猫</span> 分享了[一段视频](https://youtu.be/roe3SgezmmU?is=xizF4iDv8JHUBzm4)，核心论点是科技公司不再早期 IPO，散户被排除在最大涨幅之外。以亚马逊为例，1997 年上市时估值极低，持有至今增长数千倍；如今 SpaceX、Anthropic、OpenAI 在私募市场就涨到万亿级别，上市时 upside 所剩无几。法律变化推波助澜：1996 年取消私募基金投资人上限、2012 年 JOBS Act 提高财报披露门槛，内部要约收购让员工不用上市就能变现。

<span class="mention">@今天群内信息量极大</span> 当天写了[一篇回应文章](https://yage.ai/share/public-market-start-to-finish-line-20261010.html)，核心反驳是视频「只看贼吃肉不看贼挨打」。以前早期上市的公司倒闭概率极高，一千家里很快倒九百家，投资者血本无归；现在经过私募市场十几年打磨、年收入数十亿的公司上市后，倒闭概率接近零。散户错过的上涨，对面是等比例下降的风险。他特别警示第三类：私有阶段很长但没有造血能力，靠巨额融资烧钱，最后以透支未来的估值推向公开市场，等于付成熟公司的高价拿初创的脆弱资产。

<span class="mention">@80-HD</span> 转述了某期播客中一位 VC 的模型结论：市值从 $1B 涨 10 倍和从 $10B 涨 10 倍的概率相当，都在 8% 左右，但从 $100B 涨 10 倍的概率跳到约 30%，所以只买最贵的。他也承认这个 30% 可能是对历史数据的过拟合。<span class="mention">@细心的熊猫</span> 补充视频的核心论点其实是：以前公开市场有高风险高回报的机会，现在放出来的全是低风险低回报的东西。<span class="mention">@敏锐的海狸</span> 加了一个视角：以前也没有现在这么多元的退出渠道，如今资方在 IPO 前就有能力把故事讲完。
