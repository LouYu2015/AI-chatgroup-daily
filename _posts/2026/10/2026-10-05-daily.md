一匹来历不明的模型几天内从零冲到 OpenRouter 用量榜首，靠的是免费策略而非技术突破——这件事是当前 AI 推广生态的缩影，读者看完可以重新校准对排行榜的信任度。有人精算了 Codex 与 Claude Code 的周额度折合 API 价值，结论是 Claude 耐用度远超 Codex，多位群友正式切换阵营，正在纠结订阅方案的读者该看这组数字。一条关于个人加 agents 产能顶一个 lab 的推文引爆了今天最长的讨论：每一级跃升都是职责的完全重写而非把上一级的活干更快，AI 时代这个断层被进一步放大。

<span class="mention">@今天群内信息量极大</span> 用 agent 做了详细排查：该模型 9 月 23 日首次出现时仅 288B tokens，到 9 月 29/30 日已冲到单日 5.3T tokens、1.3 亿次请求，10 月 1 日以 5.17T 稳居全平台第一——8 天内从零变成最大流量来源。约 90% 的 token 是 cached，请求量大、单次载荷小，像被某个高频 Agent 应用整体接入。他的 agent 也抓到了这个异动但没及时汇报，打算设置定期监控。

这匹黑马是谁？<span class="mention">@睿智的北极熊</span> 直接指认它就是 WorkBuddy，并贴出界面截图。<span class="mention">@细心的熊猫</span> 补充此前有说法称其为 MiniMax 的新模型。<span class="mention">@活泼的羊驼</span> 调查后确认 Space Bunny Alpha 在 OpenRouter 上输入输出均为零价格，同时被 OpenCode 和 Cline 主动收录为免费选项——靠免费刷到第一本身就是推广手段。他举了前例：几个月前阿里的匿名视频模型也是先刷分再揭晓身份推高股价，但回头再看千问的视频模型仍然很拉，「开源不如 MiniMax，闭源被字节和快手吊打」。

> <span class="mention">@活泼的羊驼</span>：我这里主要想说，OpenRouter 靠免费刷到第一，它可能本身就是一种推广的手段

然而就在当天，<span class="mention">@今天群内信息量极大</span> 发现 Space Bunny Alpha 已经下线。整个从零到霸榜再到消失的过程不到两周。

## 工具

### Codex 耐用度仅 Claude 十分之一

<span class="mention">@热情的狮子</span> 转发了一则详细测算：有用户同时蹬完 $200 GPT 账号（100% 周额度 + 重置卡 + 65,000 赠送额度）和 $200 Claude 账号（狂蹬 3 天 Opus 5.5），Codex 飞快见底而 Claude 还剩 50%。在缓存命中率相当的条件下（Codex 98.34%、Claude Code 98.94%），折算 API 等价值分别是 Claude Code 约 $3,400/周、Codex 约 $1,700/周。因为 GPT-6 Astra 在缓存体系下的整体成本约为 Opus 5.5 的 5 倍，实际耐用度差距达 10 倍。

这组数字印证了群里连续几天的体感（[「Astra 额度消耗之痛」]({{ '/daily/2026/10/03/daily/#astra-额度消耗之痛' | relative_url }})）。<span class="mention">@幽默的火烈鸟</span> 宣布本月正式转投 Claude 20x，GPT 只留 $20 画画，多位群友也做了同样选择。<span class="mention">@热情的狮子</span> 判断 Anthropic 可能是为了 IPO 在补贴，「上市完也砍了」。<span class="mention">@优雅的喜鹊</span> 另外转发了 SemiAnalysis 的测试结论，同样指向 $200 档 Claude 远比同价 Codex 划算。<span class="mention">@细心的熊猫</span> 给出当下最优分工：「Opus 5.5 蹬得很舒服，Astra 唯一的用途是干那些被 Opus 拒绝的脏活儿。」

<span class="mention">@活泼的树懒</span> 从供给端分析了更深层的成本结构：Cursor、Copilot 等第三方接入 Anthropic/OpenAI 都走 API 付费，不按这个价卖就完全在补贴亏本。GPT 的 $200 coding plan 已经被人玩坏、额度被砍半。如果两家哪天不再竞争、取消所有 coding plan 全走 API 计费，谁都跑不掉。在国内使用 Anthropic 还有额外限制——必须通过 Cursor 或 Copilot 等渠道接入才不会封号，Copilot 又没有 coding plan，处处受制。

### 远程开发语音与剪贴板

<span class="mention">@坚定的貂</span> 在远程办公环境中研究如何把本机麦克风映射到远程机器，以便使用 Codex 内置的语音功能。<span class="mention">@今天群内信息量极大</span> 说微软远程桌面（Mac 连 Windows）什么都不用做就自动支持，<span class="mention">@坦荡的灰熊</span> 补充 RDP 从 USB 到 COM 口到打印机甚至本地硬盘都能自动共享。

<span class="mention">@天真的浣熊</span> 提供了另一条路：Typeless 这类语音输入法在 host 端识别完毕后通过剪贴板自动粘贴，不依赖远程音频通道。<span class="mention">@坦荡的灰熊</span> 则吐槽 Windows 剪贴板 hook 是个灾难——各路软件挂在上面导致一天到晚失灵，rdpclip 也经常崩。<span class="mention">@搞仁义毛义仁</span> 解释 clipboard hook 本身不能被「管理」，因为很多应用都依赖它做正经事（mspaint 根据剪贴板内容动态切换按钮状态），问题出在各家抢注冲突。他的建议很硬核：「建议所有国产软件装在虚拟机里。」

<span class="mention">@坦荡的灰熊</span> 另外贴出语音识别应用 Orca 的本地模型列表，推荐 Parakeet TDT v3（670MB），还有 Whisper Tiny、SenseVoice 和 GPT-4o Transcribe 云端方案可选。<span class="mention">@80-HD</span> 说豆包能识别家里老人的四川话已经赢了，<span class="mention">@坦荡的灰熊</span> 认为豆包的语音界面本身就是护城河。

### 「问问立正」便宜模型挑战最贵模型

<span class="mention">@冷静的飞鼠</span> 昨晚发布了[产品复盘](https://www.superlinear.academy/c/share-your-projects/ask-lizheng-not-just-a-wrapper)，详述「问问立正」从开工到上线的过程和几个反常识发现，补充了此前涌现时刻的背景（[「「问问立正」涌现时刻」]({{ '/daily/2026/10/02/daily/#问问立正涌现时刻' | relative_url }})）。核心结论是 DeepSeek + 自己的 context，在给建议这件事上经常胜过 Claude 和 GPT 最新 Pro 模型。做法几乎不依赖 system prompt，关键在两样东西：Open Context 里每篇材料都带日期和出处；中间一层蒸馏把反复讲的判断提炼出来并写清成立条件——否则 AI 看原话会觉得他自相矛盾。模型最终选了 DeepSeek V4 Flash，七八秒答完。最大的坑是「别人在问什么」功能导致数据库月度免费额度四天耗尽，改成所有人共享同一批问答后请求降下来并稳定增长。

> <span class="mention">@冷静的飞鼠</span>：这次项目最大的 learning 就是放下预设：项目是否值得做，想的是错的；最大的亮点，事先是完全没想到的；一个重点功能，做到一半砍掉了。

今天他进一步发起了[投票](https://www.superlinear.academy/c/posts/five-ai-answers-vote-2026-10-05)：用同样五个真实问题分别问「问问立正」、ChatGPT（Latest Pro 5/5）和 Claude（Opus 5.5 Max），每题独立新聊天、原题逐字发送、无额外提示。三方风格差别明显——比如被辞退的 Web3 设计师怎么选这题，ChatGPT 建议别锁死赛道先稳住生活，Claude 说首先是设计师、Web3 只是场景，问问立正则把迷茫归为把身份焦虑当成了职业选择问题。<span class="mention">@今天群内信息量极大</span> 开玩笑：「以后跟课代表互喷的时候先用 agent 跟课代表的 agent 互喷一轮，带着准备上场，百战百胜。」

## 方法论

### AI 时代的能力阶梯

<span class="mention">@今天群内信息量极大</span> 转发 Bojie Li 的推文引发了今天最长的讨论。推文核心数字：去年一个人加 agents 产能相当于古法编程的 5–10 人（一个基层 team），今年峰值已到 30–100 人（一个 lab），基本是他在华为时最大的管理半径。这非常考验 tech head 的 vision（要提出重要的问题，对得起一年一千万美金经费）、架构能力（糟糕的顶层设计只会导致糟糕的实现）、团队管理（理解每个 agent 的特点）和项目管理能力。不具备 tech lead 能力的人只能产出 2x 生产力，能管 100 人的 lab director 可能用出 100x。

推文同时引用了宝玉关于不再逐条 review PR 的观点。<span class="mention">@豁达的灰熊</span> 提到 SGLang 项目明确不接受纯 AI 提交的 PR，<span class="mention">@80-HD</span> 认为根源不在 AI，在于提 PR 是不是真为解决问题——AI 时代以前也有大量人工 slop PR。<span class="mention">@豁达的灰熊</span> 进一步区分：AI review 能解决 verification，但还有 judgment。

<span class="mention">@今天群内信息量极大</span> 给出了贯穿全天的判断框架：从 junior 到 senior 不是把 junior 的活干快两三倍，从 senior 到 staff 也不是——每一层都是 job responsibility 的完全重写，更像学一门新课程。他用寿司做比喻：以前捏寿司先得煮十年饭，电饭锅出来后大家恐慌觉得行业要完蛋，但煮十年饭本来就跟捏寿司没关系，整个培养体系就是歪的。

> <span class="mention">@今天群内信息量极大</span>：AI 出现之后这个 gap 更大了，因为 junior engineer 的活很多 AI 都能干。所以我对学校教育的期望，尤其是 AI 时代，是大家要想怎么创造一个逼真的环境，直接培养 senior 的人。

<span class="mention">@80-HD</span> 从自身经历呼应：第一份工作时的 senior 经常让他把整个 PR 重写然后逐条解释为什么。那位 senior 教会他最有用的一点——do not fear refactoring——在 AI 时代尤其重要。<span class="mention">@稳重的海豚</span> 主张课程大纲应该从一开始就培养 senior 视野，完全可以开 industry workshop 让学生跟 senior 交流。他的观察更直白：「老跟 junior 混，你的视野就是 junior。」

<span class="mention">@冷静的麋鹿</span> 把讨论推向了一个更具体的品质：靠谱。AI 拉平了纯熟练度之后，靠谱被进一步放大——靠谱的人给你的东西经过背书而非纯 AI 一次性生成，有标准、可落地、本人能理解并拆解后续步骤。<span class="mention">@开朗的企鹅</span> 把这翻译成 agency（自己能形成 feedback loop）加 taste（标准可信任），AI 出现后实现能力的重要性被削弱，剩下的就是这两样。

<span class="mention">@冷静的飞鼠</span> 从另一个角度切入：除了考试，几乎都是手艺。手艺是体感而非可解释的规则，追逐可解释是「应试教育遗毒」——因为很多维度根本观测不了或想不到要观测。<span class="mention">@搞仁义毛义仁</span> 用自己弄了两三年咖啡的经验佐证：手冲最后十克水倒在滤杯上面还是下面效果真不一样，充分训练后能察觉细微差别，旁人看来就是玄学。<span class="mention">@今天群内信息量极大</span> 把讨论拉回市场现实：发烧友可能是 0.01% 的人，主流市场根本不在乎这个层次——瑞幸干星巴克，发烧友觉得菜鸡互啄，但它们才是主流。

### 企业 AI 额度与 PR 审查困境

某群友透露所在大厂 org 本月只剩 200k AIC，多位群友反映当天也触达了这一限额。另一位群友一度以为是自己上月没猛蹬所以被单独缩减了预算，实际是 org 统一设定。更诡异的是计费数据对不上：/usage 显示用了 40k AIC，PowerBI 报表上上周只花了 $50。接下来大半个月怎么办？<span class="mention">@沉稳的兔子</span> 预判：「也有可能集体躺平。」

AI 使用强度同时带来了审查压力。某群友提到不 review PR 甚至违反公司 policy，部分部门还要求员工对 AI 写的 PR 要跟自己写的一样熟。<span class="mention">@沉稳的兔子</span> 直接反弹：「review AI 的 PR，是一种夜郎自大的表现。」<span class="mention">@天真的浣熊</span> 宣布「人模合一，ASTRA 6 全权代表我」。有群友坦言现在只看改了哪些文件、每个扫两秒钟，炸了再说——但用得少又会触发 unwilling to experiment with AI 的考核条例，两头受夹。

### AI 时代人人平等？

<span class="mention">@神秘的企鹅</span> 发出一段感叹：在未来 AI 眼里，美国总统和普通人应该是同一类东西，就像我们看蚁后和工蚁一样——「人类第一次真正实现了平等，最优秀人类的智能和资源，也不堪一击。」

<span class="mention">@今天群内信息量极大</span> 泼了冷水：会不会以后只有最有钱最有权的人才能用 Mythos，普通人只能用 Opus，更普通的只能用 Sonnet？<span class="mention">@细心的熊猫</span> 提出了递归解法——「<span class="mention">@今天群内信息量极大</span> 用 Mythos，我们用 <span class="mention">@今天群内信息量极大</span>，问题解决。」<span class="mention">@80-HD</span> 指出这不是未来时态，有特权的人现在就已经有 Mythos 了。<span class="mention">@搞仁义毛义仁</span> 滑到了更暗的预测：如果没有劳动价值的人成吨出现，他们只会被合法地消灭，根本不需要考虑用的是 Sonnet 还是 Fable。
