今天最值得读的是**<span class="mention">@稳重的海豚</span> 分享的一种和 AI 协作的方法**：只让 AI 列选项、做分析，判断自己来做，做完再请 AI 挑刺。他说这样思考更深，人反而不那么累。几位群友补充了各自的理由，<span class="mention">@蓝色大肥虞</span> 顺着讲到 review：不用逐行读懂 AI 写的代码，要做的是维护好代码库，让 diff 的「外形」自己说明这次改得好不好。第二件是**美国国土安全部的 DeepSeek 排除令**：它不只针对 DeepSeek 自家产品，「用 DeepSeek 实现方案开发的第三方产品」也要从联邦文职机构移除。第三件是 **MiniMax M3.1 Flash 发布**，处理过 200T token 的匿名模型「太空兔」原来就是它的早期版本，输出价格每百万 token 4 元。

## 和 AI 协作的方法

### 只让 AI 列选项，判断留给自己

<span class="mention">@稳重的海豚</span> 这几周换了一种用 AI 的方式：不再让它给建议，只让它列 option、做分析，判断由自己做，做完再让 AI 给 critique。他的体会是思考的深度和强度都上来了，人却没以前累。

他说以前最耗人的是，AI 会给出很多「看上去有道理、背后逻辑却不通」的建议，包括 Astra 和 Fable 在内。他得花时间理解这些建议，最后也没得到好的 output，自己的判断力还在下降。现在他被迫真正去理解资料和每个选项，对问题的理解也更深了。

几位群友的补充：

- **为什么建议更累**：<span class="mention">@冷静的麋鹿</span> 认为，选项和分析大多是客观的、有衡量标准的，读起来不累，AI 给的也大多没问题。建议则意味着取舍，选哪种要看自己的处境，AI 很难设身处地，只能给出四平八稳、又显得很有道理的东西。他打了个比方：在 AI 的建议里挑毛病，像玩极隐蔽的「大家来找茬」，特别累心；自己吸收、自己判断，则有直觉参与，不必全靠脑力。
- **从源头避免**：<span class="mention">@蓝色大肥虞</span> 说自己大部分时间都这样做，效果很好，「不要让 AI 做价值判断，很多流程上的问题就扼杀在摇篮之中」。
- **越纠越错**：<span class="mention">@豁达的灰熊</span> 补了一句，纠 AI 的错，会越纠越冒出新的错。
- **管理成本**：<span class="mention">@开朗的企鹅</span> 认为这本质上是管理学问题，觉得累，是因为管理成本高。<span class="mention">@敏锐的麋鹿</span> 的类比是公司里大部分 bandwidth 都花在互相沟通理解上，真正做事反而没那么累。<span class="mention">@沉稳的兔子</span> 的经验是，同一个任务换种布置方法，完成度可能会飞跃。

<span class="mention">@坦荡的灰熊</span> 前一晚说的一句话也可以放在这里对照：「如果把整个仓库都删掉，唯一想保留的是踩过的坑。所以本质上搞 AI context 是个搞概率分布塑形的过程，关于业务假设的信念分布。」

### Review 不必考自己：看 diff 的外形，守住代码库

<span class="mention">@80-HD</span> 看到有人让 AI 根据 PR 出三道题，检查自己有没有认真 review，他说自己做不到。<span class="mention">@蓝色大肥虞</span> 认为这样做收益很低：知道 AI 写了什么只是手段，不是目的。更该做的是维护代码库的结构，好的代码库「diff 从外形上就会告诉你这次做得好不好」。

他的原话：

> 就像人看脸来辨别基因的好坏一样。需要的是一直维护 code base 的这种特征……而不是去探究某个 diff 底下不为人知的秘辛。这个窗不要破，直接的好处就是做开发花的 token 不会越来越多，一直在 reasonable 的成本下解决。

这接着 10 月 16 日他说的「代码漂不漂亮，可以用 token 来算了」（[「代码漂不漂亮，可以用 token 来算了」]({{ '/daily/2026/10/16/daily/#代码漂不漂亮可以用-token-来算了' | relative_url }})）。<span class="mention">@沉稳的兔子</span> 回应说，自己现在正在「疯狂给既有系统补窗子」。

<span class="mention">@蓝色大肥虞</span> 当天还贴了一个例子。他要一个每秒更新一次的时钟，Astra 用的是很久以前为手写动画加进框架的 coroutine，他说「没想到在这里用上了」。代码就是一个 `while (true)` 循环，里面 `$Wait(1000)` 后更新 `element.Data`。这段脚本会被编译成状态机：跑到 `$Wait` 时函数先结束并挂一个钩子，一秒后在 UI 线程上生成新 task 重新进入，所以不会阻塞 UI 线程。

另一边，<span class="mention">@热情的狮子</span> 转来极客公园的快讯（来源标注为新智元）：Anthropic 团队披露，Claude Code 约 90% 的代码由自身生成，大部分审核也由 AI 完成；2025 年 6 月到 9 月，合并 PR 量翻倍，回滚率下降超过四成。做法是以回滚率、事故率为核心指标，搭了七层检查：多个 agent 分头查 bug、投票筛选意见，再按改动的风险等级匹配不同强度的人工审批，思路类似瑞士奶酪模型。<span class="mention">@蓝色大肥虞</span> 的评价是：「太富了，无限 token。」

## 模型与行业

### 美国国土安全部：联邦文职机构移除 DeepSeek

美国国土安全部发布排除与移除命令，要求联邦文职行政机构停止采购 DeepSeek 及其关联实体的产品，并把已部署的产品移出机构 IT 系统。命令计划 10 月 20 日刊登在《联邦公报》上（Docket No. DHS-2026-0628）。按一篇转述文章的说法，原文标注的签发日期是 7 月 24 日。

[转述文章](https://mp.weixin.qq.com/s?__biz=MzIyNjM2MzQyNg==&mid=2247728959&idx=1&sn=ddb438fe378afe78d6d5249a7b9c1058&chksm=e9507467e4dbf39fe95f30b6fc613d305a4f86b53e8cc1cd003999e89e7867a4996f8fb61108#rd)附了原文，要点如下：

- **范围**：用 DeepSeek 实现方案开发的第三方产品和服务也要移除，机构要核查实际技术用法，不能只看软件名和销售方。微调、蒸馏这类情形怎么认定，文件没有逐一说明。命令只管联邦文职机构的采购和信息系统，不是针对美国个人和企业的使用禁令。
- **理由**：服务器在中国，担心政府雇员或供应商提交的信息外流；注册会收集个人身份信息，可能存在追踪和设备指纹；文件还引用了一项针对 DeepSeek iOS 应用的安全研究，并称模型本身也可能含有恶意代码或漏洞。
- **执行**：命令签发即生效。机构可在 60 天内书面申请例外，但这不是可以照常使用的宽限期。移除完成前，建议机构加强流量监测和日志记录，CISA 可提供技术协助。

群里的反应：<span class="mention">@务实的长颈鹿</span> 指出，这些理由对开源模型自部署并不成立，「但是制裁不需要讲道理」。<span class="mention">@活泼的老虎</span> 觉得既然不影响民企和个人，问题不大。<span class="mention">@聪明的雪豹</span>：「我以为早就禁止了。」<span class="mention">@睿智的犀牛</span> 的反应是：微软好像也用 DS，那干脆把微软拆了吧。

### MiniMax M3.1 Flash：太空兔揭晓

MiniMax 发布 [M3.1 Flash](https://mp.weixin.qq.com/s/fO9snz_lnPxVg0q55chDFg)，同时揭晓此前匿名上线、处理过超过 200T token 的 Space Bunny（太空兔）就是它的早期版本。<span class="mention">@风趣的海豚</span> 说太空兔被猜过好多家厂商，他之前看到传言没信。<span class="mention">@睿智的北极熊</span> 的回应是「早就说了啊」。

- **架构**：<span class="mention">@细心的熊猫</span> 贴出的描述是 MoE，总参数 428B，激活约 23B，稀疏注意力，带原生视觉编码器。
- **速度与价格**：官方称线上推理速度提升近 3 倍，日常输出 200+ TPS，P50 稳定在 170+ TPS，agentic 任务的综合成本比前代降低 70%。价格是输入 1 元、输出 4 元、缓存读取 0.1 元，单位都是每百万 token。
- **跑分**（官方数字）：DeepSWE v1.1 73.7%（作为参照，前天 DeepSeek 1017 的跑分表里是 77.0），OSWorld V2 61.7，Agents' Last Exam 29.6，CyberGym 82%，BankerToolBench 76.2。「国产第一」「顶尖模型水平」都是 MiniMax 自己的定位。
- **可用性**：已上线 API、MPlan 订阅和 MiniMax Code 桌面端，权重稍后开放，Pro 版本也在后面。

### Qoder 免费送 DeepSeek 1017，有人做了反代聚合

Qoder 宣布 10 月 24 日前 DeepSeek-V4.1-Flash-1017 限时免费，系数降到 0x、不扣 Credits，个人免费用户和付费用户都能用，国际版和 CN 版同步开放，支持 1M 上下文，思考强度可以拉满。Qoder 在宣发帖里说「第一时间支持」，有评论指出 DeepSeek 官方并没说对他们做了特别优化，官号回复：「我们对他们进行了优化。」

<span class="mention">@神秘的麋鹿</span> 觉得 Qoder 不太好用。<span class="mention">@睿智的北极熊</span> 的办法是把它反代出来，给 DeepSeek Harness 用，推荐了 [ai-proxy-hub](https://github.com/vagunreal/ai-proxy-hub)：

- 在本机把 WorkBuddy/CodeBuddy、TraeWork、Qoder、OpenCodeZen 的登录凭据聚合成兼容 OpenAI 和 Anthropic 的本地 API，同时提供 `/v1/chat/completions`、`/v1/responses`、`/v1/messages` 三个端点，可以接 Codex CLI、Claude Code 等客户端。
- 同一渠道的多个账号额度用完后自动切换，切换只发生在还没向客户端输出任何字节时，不会出现半截流。
- 风险写得很直白：管理端点完全不做鉴权，`/v1/keys` 会返回密钥明文，所以只能监听 127.0.0.1；上游用的是非公开的逆向接口，没有稳定性承诺。

### IP, PLEASE 能玩了，也有人找到了改 metadata 的工具

昨天提到的 B 站视频（[「深圳出差被封，地区政策按所在地判定」]({{ '/daily/2026/10/18/daily/#深圳出差被封地区政策按所在地判定' | relative_url }})），今天有了可以直接玩的[网页版](https://ip-please.github.io/)：你扮演东八区检查站的审查员 Claude，任务是揪出「假装是美国人」的旅客。<span class="mention">@开朗的企鹅</span> 的评价是「还挺完善的」。

![游戏主界面：上方挂着「HELPFUL · HONEST · HARMLESS」和「荣耀归于 ANTHROTZKA」的横幅，窗口里是戴 USA 帽子的旅客，桌上摆着美国护照和设备入境卡，卡上写着时区 Asia/Shanghai、语言 zh-CN](/assets/img/daily/2026/10/2026-10-19-02.webp)

- 「Hello, I am 美国人。」「你的时区是北京时间。」「……这是美国东八区。」

- 「Hi 哈。」「『哈』是什么？」「……Ha! Ha ha.」

放错人会收到警告单，比如「Ta 会接『一百八一杯』」，或者「浏览器语言：zh-CN，罚款 5 token」。下班结算更好笑：

<span class="mention">@活泼的海龟</span>：「每天训练数据还要扣我的钱。」<span class="mention">@聪明的蜂鸟</span> 提了一个阴谋论：说不定是真的，就像 Google 用 reCAPTCHA 标注数据，「也许你刚刚拒掉了一个群友」。<span class="mention">@飘逸的狮子</span> 接了一句：「能玩这个游戏的 IP 已经被标记了。」

玩完游戏，<span class="mention">@热情的狮子</span> 问有没有人做过对付 Claude 检查时间、时区、语言的工具。他让 Codex 搜了 3 分钟，找到三个项目，覆盖的层面各不相同：

## 闲聊花絮

### 刘亚楼，你记一下

<span class="mention">@开朗的企鹅</span> 转来一条知乎回答。答主开一人公司，业务复杂到需要全面 AI 原生化，Grokbot 一出来，就是他想要的样子：「员工一个排，个个忙得连轴转。」这让他想起电影《辽沈战役》里那句台词：「刘亚楼，你记一下。我做如下部署调整。」他说饭后散步那么有吸引力，一小半就是冲着这种感觉去的。

<span class="mention">@稳重的海豚</span> 当场决定做一个产品，名字就叫「刘亚楼」，简称 LYL。AI 给出的西方对应是拿破仑的参谋长 Berthier，定位「Your AI Chief of Staff」，备选是 Jarvis。<span class="mention">@稳重的海豚</span> 嫌 Jarvis 用烂了。<span class="mention">@80-HD</span> 嫌 Berthier 太拗口，认为双音节最好：去幼儿园观察一下就知道，名字再长，小朋友也会叫成双音节。<span class="mention">@稳重的海豚</span> 透露，自己现在喜欢管 AI 叫「小伙子」。

### 零碎

- **Codex 远程控制在国内失效**：<span class="mention">@稳重的雪豹</span> 回国后，Codex 桌面端连不上、生成不了手机配对二维码。Codex 自己诊断出两个进程都没继承代理环境变量，直连超时，显式走 127.0.0.1:12334 才有响应。最后按 <span class="mention">@开朗的企鹅</span> 的建议开了 TUN 模式，问题解决。
- **反诈预警**：<span class="mention">@开朗的企鹅</span> 留了一台手机让 agent 自己调试，结果被反诈系统判定「可能被诱导下载恶意软件」，软件名是 agenthub。<span class="mention">@风趣的海豚</span>：「没毛病，用 agent 和吸毒一样，可花钱了。」
- **Claude 挑海报帧**：某群友让 Claude 做宣传海报。它从访谈视频里逐帧找两个人同时对着镜头笑的瞬间，定在 47.47 秒那一帧。视频是 1080p，脸偏小，它最后的方案是保留全彩照片，波普感交给放射光、贴纸白边、硬阴影这些图形元素。
- **cache 只认前缀**：<span class="mention">@坚定的貂</span> 感慨，现在的 cache 只支持 prefix 匹配；如果 LLM 的输入能更结构化，很多内容本来是对称的，顺序无所谓，也就能命中缓存了。
- **3D 打印机**：<span class="mention">@细心的熊猫</span> 想买 Formlabs 的树脂打印机 Form Studio 1 Founders Edition（$749 起），打算自己打水冷配件。<span class="mention">@今天群内信息量极大</span> 说他已经有 Form 家更高端的型号。<span class="mention">@幽默的长颈鹿</span> 在 Creality K2 Pro Combo 和 Bambu Lab P1S Combo 之间犹豫。<span class="mention">@稳重的貂</span> 说展会上已经出现桌面级金属打印了。
- **战锤入坑**：有群友问战锤新手从哪个游戏入坑，推荐有暗潮、全战、Space Marine 2。<span class="mention">@风趣的海豚</span> 认为没有哪款游戏能讲完整个剧情，想了解设定不如看 B 站达奇上校的[战锤 40K 合集](https://www.bilibili.com/video/BV1s4411C7hk/)，从第一集「大远征」按顺序看，全集 153 集。他对星际战士的定性是「男生版的奇迹暖暖：自己打怪给自己赚钱买衣服」。<span class="mention">@蓝色大肥虞</span> 提醒，中古战锤和战锤 40K 是两个东西。
- **Seedance 该更新了**：<span class="mention">@睿智的北极熊</span> 算了一下，Seedance 2.0 是 2 月出的，2.5 是 6 月出的。
- **马斯克送股**：马斯克发推说明年要给每个美国孩子送一股 SpaceX。按约 7,200 万名儿童、每股 146.03 美元算，总价约 105 亿美元。<span class="mention">@随和的企鹅</span>：「提前锁定韭菜么。」
