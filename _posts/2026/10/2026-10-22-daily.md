## 模型产品与额度

### Claude Duet：主动找你派活，手机关了也继续干

<span class="mention">@热情的狮子</span> 分享了 [Claude Duet 的介绍](https://mp.weixin.qq.com/s?__biz=MzkzNDQxOTU2MQ==&mid=2247521965&idx=1&sn=45f6e58e1c050a44253cc508b0fd4ca9&chksm=c315ce00a0e6c1316c2cd9fb3ec0f42e7aa5c9a370bebe5004a4d1cc00861cadb902038d27d4#rd)。这是 Anthropic 新出的独立个人 agent App，有 iOS、Android 版，目前还在 waitlist，优先开放给美国 Pro 和 Max 用户，与其他 Claude 产品共用额度。

它主打主动办事：每天早上告诉你有什么要处理，自己判断什么时候来找你，所有往来留在同一条对话里。具体配置：

- **自带云端虚拟机和浏览器**，用户的电脑、手机关了，任务仍在后台跑；做完或需要过目时推通知。
- **沿用 Claude 账号里的记忆、skills 和已连接应用**，Claude Marketplace 的 6,000 多个连接器和插件也能用。
- **每隔几个小时检查一次连接账户**，没有持续轮询，文章给出的原因是持续检查会耗光当前套餐额度。
- **读邮件、起草和准备材料可以自行执行**；付款、签文件、删除仍需人批准。凭证沿用 Claude Managed Agents 的设计，Duet 看不到密码和登录 token，每个动作还要经过与 Claude Code 一致的 auto mode 分类器。

官方演示里，一位咖啡连锁经营者要见投资人，Duet 在对话里完成 PPT、资料室和邮件，又查了对方 6 位合伙人的履历及各自最近 3 笔消费类投资，准备单店回本、订阅流失等问题的回答。它还从收银系统、Shopify、CRM、客服邮箱、工资和银行账户拉数据，搭了一个每天早上 5:30 刷新的看板。

看板随后发现，运费调整后某地区的订阅流失率从 2.6% 涨到 3.4%，退订理由多指向运费，于是提议做两周「满 40 美元包邮」测试。

群里马上想到的是封号。<span class="mention">@坦荡的灰熊</span> 担心，把业务都交进去后，用户来一趟中国，回头全公司的业务都封了。<span class="mention">@蓝色大肥虞</span> 当天又转来一条公开投诉：发帖者临时在中国停留，Team 套餐年费刚续上，两天后账号被封。地区规则的前情见 [「深圳出差被封，地区政策按所在地判定」]({{ '/daily/2026/10/18/daily/#深圳出差被封地区政策按所在地判定' | relative_url }})。

### REA：把 Hopper、Ghidra、IDA 接进 agent

<span class="mention">@稳重的海豚</span> 分享了 [REA](https://github.com/morluto/rea)。它通过本地 MCP server，让 Claude Code、Codex、Cursor、Gemini CLI、Grok Build 等直接检查二进制、JavaScript/Electron、.NET 程序和网站，追踪某个功能到底怎么实现。

项目的使用方式：

- 执行 `npx rea-agents setup`，注册 MCP server、写入配套 workflow 指令，并备份原配置。
- 原生分析复用已有的 Hopper、Ghidra 或 IDA；静态 JavaScript 和 .NET 检查不需要原生引擎。
- 分析在本地运行，目标应用不上传；分析工具返回的结果会交给 agent。
- 默认使用精简的 MCP 输入 schema，减少 context 开销；需要完整字段说明可设 `REA_MCP_INPUT_SCHEMA_PROFILE=full`。
- 商业逆向工具的授权需要自己准备，REA 不提供许可证。

README 里的一个案例，是把声音调用追到 position-to-pan 辅助函数，再把残缺伪代码还原成 C。重写版本通过了 **3,205 个原 x86 用例**，并逐字节复现全部 **63 个已编译函数**。另一个案例沿着 preload 和 IPC，把 Electron 渲染进程的剪贴板 API 追到了主进程。

### Switch 2 越狱：硬件台架给了 Codex，突破还得自己找

<span class="mention">@细心的熊猫</span> 分享了 [ns2jb 的技术文章](https://pepsipu.com/blog/2026-10-switch2-jailbreak-ns2jb/)。作者称这是首个 Switch 2 越狱：纯软件、tethered，重启后需要重新触发，能够以普通 sysmodule 和内置 fs sysmodule 的身份运行原生代码，用来跑 homebrew、改游戏和导出存档。

文章里最有 AI 味的是硬件台架：

- JetKVM 通过 USB 发送手柄输入，HDMI 接收画面；
- 额外买了蓝牙开关拨杆，替 Codex 按电源键；
- 因为 Switch 2 崩溃后必须按实体键才能重启，光有远程输入还不够。

作者在补充说明里讲清了分工：交给 Codex 的 userland 代码执行目标没有成功，越狱本身花了约两周；一天内完全 vibe coded 出来的，是 Mario Kart World 的 mod。

失败的 WebKit 路线也留在了文章里。Codex 曾宣称拿到了 native control-flow hijack，但实际使用的是替换 JavaScript function object，没能推广到任意 IPC 调用。

最终的突破链条是：

1. **SmileBASIC 的 32 位整数溢出**，把数组前面的指针拉进数组，进而获得越界读写。
2. **fs sysmodule 的路径处理堆溢出**，通过缓存条目取得任意读写，修改连接对象权限并导出内部存储与普通 sysmodule。
3. **利用 fs 与 loader 之间的信任关系**，替换加载链中的 ExeFS，保留合法权限描述、换入自己的程序代码。

作者希望后续 homebrew 社区能据此推进到 CFW。

## 人生模拟器试玩

### 《80亿分之1》：一边说没玩头，一边投胎到晚上

<span class="mention">@热情的狮子</span> 分享了[《80亿分之1》](https://1in8b.life/zh-hans/)。转来的 GameLook 报道称，开发者向 Claude Opus 5.5 提出「随机成为地球上 80 亿人中的一个，并尽可能按真实统计体验人生」的想法，4 小时做到了上线；报道给出的后台数字是，58% 的虚拟人生被玩家逐年推演到终局。

玩法的底子是人口统计：

- 在 **172 个国家与地区**中随机出生，家庭、性别和出生地由统计分布决定。
- 数据接入联合国、WHO、世界银行等来源，展示当地平均寿命、儿童死亡率、教育、收入和医疗等指标。
- 每年选择学业、工作、家庭、健康等重心，在升学、求职、婚姻、移居、治疗等节点做决定，也可以打开自动抉择。
- 同一秒出生的另外四个人会并行过完一生；5、15、30、50、70 岁时暂停提问，最后把五段人生放在一起。
- 支持现在、过去、未来，单局可选 30 分钟、1 小时或 1.5 小时，也能加速。

<span class="mention">@热情的狮子</span> 喜欢的是这种切入角度，说「挺有人文关怀」。玩起来，群里很快分出了几条路线：

- **长寿路线**：<span class="mention">@热情的狮子</span> 先抽到瑞典男性，活到 92 岁；后来又抽到韩国男性，活到 107 岁，结算页显示同年出生者中只有 0.02% 活得更久。
- **坎坷路线**：<span class="mention">@随和的老虎</span> 抽到南美单亲家庭男性，中年丧偶、再婚后又丧偶；另一局则在 1 岁就结束了。
- **负债路线**：<span class="mention">@活泼的老虎</span> 玩到 30 岁，债务越滚越大，自动抉择正准备替他向放高利贷的人借钱。
