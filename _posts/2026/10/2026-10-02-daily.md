有 5090 加足够系统内存的人，M5 Ultra 可能真不用买了——Strata 推理引擎通过 MoE offload 让单卡跑起完整的 Qwen 3.8 Flash，decode 与 M5 Ultra 持平，正在考虑本地硬件的读者今天该看看这批数字。Kev 1.0 用逆向工程完整复现了 JEV 并开源，闭源决策模型的护城河一夜蒸发。Codex 全局重置姗姗来迟，高价账户额度没补满，群友们赶在 reset 卡过期前疯狂找活干。

## 本地推理加速潮

### NInfer NVFP4 社区量化

<span class="mention">@优雅的喜鹊</span> 分享了一份社区构建的全 NVFP4 NInfer 量化包——基于 QUASAR-QAT 感知训练的 Qwen3.8-27B 权重，集成 DFlash2 投机解码 drafter。在同一块 RTX 5090（600W）上对比 NInfer 官方 artifact：

| 指标 | 官方 NInfer | 社区 NVFP4 |
|---|---|---|
| DFlash2 decode 耗时 | 16.1 ms | 13.8 ms（≈+16%） |
| Prefill 16.7K | 11.3–11.5K tok/s | 13.7K tok/s |
| Prose decode | 175.6 tok/s | 204.2 tok/s |
| VRAM | 30.8 GiB | 27.0 GiB |
| GPQA-Diamond | 90.40% | 89.90% |

速度全线提升、VRAM 反而省了近 4GB，精度仅损失一道题。并发扩展表现：

| 并发 | 数字 | 代码 | 散文 |
|---|---|---|---|
| 1 | 310 | 280 | 193 |
| 4 | 1,208 / 304 | 1,120 / 281 | 741 / 189 |
| 16 | 3,385 / 215 | 3,218 / 206 | 2,141 / 139 |

（格式：聚合 / 每路 tok/s）

冷预填充在 6.7K 输入时达 ~7,400 tok/s，拉到 167K 仍有 4,697 tok/s，峰值功耗 406W。这些数字让 <span class="mention">@今天群内信息量极大</span> 直呼 WTF——他的 M5 Max 跑 Qwen 3.8 Flash 才 128K prefill 2,200、decode 76 tok/s，「这边 5090 dense model 都 200+ tps 了」。更尴尬的是 <span class="mention">@优雅的喜鹊</span> 自己的双 DGX Spark 跑同一个 27B 也只有 196 tok/s（参见前天的 [「DGX Spark TP=2 推理实测」]({{ '/daily/2026/09/30/daily/#dgx-spark-tp2-推理实测' | relative_url }})），被单张 5090 反超。作者的下一个目标是为 Qwen 3.8 Flash-Next 做同样的量化。

### Strata 单卡跑 MoE

<span class="mention">@今天群内信息量极大</span> 发现了开源推理引擎 [Strata](https://github.com/architectds/Strata)，它通过 MoE offload（将非活跃专家权重放入系统内存）让 125B 参数的 Qwen3.8-Flash-Next 在 12GB 以上显存的普通 PC 上流畅运行。引擎在 localhost 暴露 OpenAI / Anthropic 兼容 API，Claude Code 改一行 `ANTHROPIC_BASE_URL` 即可接入。

他在 5090 单卡上实测 Qwen 3.8 Flash：

| Prompt 长度 | 读 prompt | 写回答 |
|---|---|---|
| 4,096 | 1,687 tok/s | 146 tok/s |
| 32,768 | 3,119 tok/s | 167 tok/s |
| 128,000 | 3,001 tok/s | 152 tok/s |

对照他自己 M5 Max 跑同一模型（128K prefill 2,200、decode 76），decode 翻了一倍。<span class="mention">@细心的熊猫</span> 确认 M5 Ultra 大约是 M5 Max 的两倍多一点，也就是说 Strata 在 5090 上的 decode 已与 M5 Ultra 基本持平。代价是 3-bit 量化带来的精度损失：与官方 API 逐 token 比对，数学一致率 96.4%、代码 94.3%、自由写作 85.6%。模型下载约 70GB，首次启动可能卡死 PC 一到三分钟，同时只处理一个请求。

> <span class="mention">@今天群内信息量极大</span>：买 M5 Ultra 的主要原因是它模型比如 qwen 3.8 flash 装不到 5090 显存里去，强行 offload 会特别慢。结果这个 Strata 硬是用 MoE offload 实现了比 M5 Ultra 还快的 throughput。又找不到买的理由了。

<span class="mention">@细心的熊猫</span> 给出通用判断：「如果你已经有了内存和 5090，确实没必要买 Ultra；如果没有，那 Ultra 确实是好 deal。」两人还确认 Qwen 3.8 Flash 的一个架构特性：上下文拉满不掉速。<span class="mention">@细心的熊猫</span> 在 M5 Ultra 上跑到 74.5M token 上下文仍稳定 136 tok/s，5090 同样如此。

### 本地部署经济两难

数字之外，<span class="mention">@今天群内信息量极大</span> 算了一笔经济账：5090 约 3 万块，按 token 折算成 API 订阅价大约 300 年回本。<span class="mention">@直率的鸵鸟</span> 用 Qwen coding plan 另算认为几年就行，但关键分歧在利用率假设。

> <span class="mention">@今天群内信息量极大</span>：这里有两种口径。第一种假设百分之百的 utilization，大约十年左右回本。但这不现实——哪怕站起来蹬也很难 24 小时不停给 AI 活干，体验会非常差。现实是提交几个对话，嫌太慢就走了，卡跑完就空转。

他总结为一个两难：要体验好就要让显卡饿着，要省钱就要满载。对多数个人用户而言，本地推理的经济账目前还算不过来——但对已有硬件的人来说，Strata 这类工具至少让沉没成本活了起来。

### 「问问立正」涌现时刻

## 方法论

### 内容站广告变现打法

<span class="mention">@沉稳的仓鼠</span> 发布了[详细博客](https://ranchen.org/content/20261002-rancheng-article-content-site-ad-revenue)，复盘「做免费内容站赚广告钱」的全流程。核心模式：围绕长期搜索需求搭大规模分类体系（taxonomy），一千个页面月入一千美元，约等于每页每月一美元。他运营的 Open Exam Prep 覆盖两万多个考试、两百多万道免费练习题，免注册直接刷题。

几个关键判断。选广告不选订阅——他开过低门槛充值，半年没到 100 美元；订阅制 KPI 还会把产品优化到「希望用户用得越少越好」的方向。选网站不选 App，试错速度快。选老词不追风口，追风口本质是用时间换钱。竞争壁垒不在创意独占，在成本结构：同行雇一个全职一年十万美元，这个体量只能靠 AI 放大。

技术栈偏好 Vercel + Next.js，数据直接放代码库（静态文件放 public 目录不计入 Vercel 部署体积），不用数据库。广告首选 AdSense，审核难过退选 Adsterra。他点名最大对手不是别的站长而是 Google AI Overview——纯文字内容空间越来越小，要逐步转向图片、视频和小游戏，本质是谁能以更低成本供应更多 engagement hours。
